# SideNotes

面向 Windows 的本地快速记录工具：鼠标移动到屏幕边缘唤出侧栏，也可使用快捷键浮窗随手记录。内容包含临时待办、命令、链接、想法与截图，支持常用内容置顶和处理后归档。

交互原型已归档为只读。Windows 桌面端采用 Tauri 2 + React + TypeScript + Vite。

## 已确认方向

- 先 Windows，后续加入安卓与自主同步。
- 本地 SQLite，无产品账号体系；提供开放云端方案接入，如Onedrive、WebDAV等。
- 侧栏隐藏后界面完全消失，回到原 Windows 工作环境。
- 默认列表暂名工作区，两个入口共用记录与草稿逻辑。

## 历史文档

`docs\prototype\index.html` 归档原型入口；以这个实际运行的效果为准，其中的说明文档可能落后版本。
