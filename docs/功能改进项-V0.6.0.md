## 功能改进项

V0.6.0 Preview 改进项

1. 使用 `pnpm tauri dev` 启动应用之后，托盘中出现了两个应用图标，只有其中一个能够被右键点击；
2. 侧边栏拖动窗口边线无法调整窗口大小，并且会随鼠标移动选中页面中的文本；
3. 显示位置在屏幕左侧时左侧边和屏幕之间有空白边距；
4. 侧边栏出现和收起的动画，滑出是正常的，收起时窗口是向内凹陷淡出，而不是往内平移收起；移动的动画也太快了，希望能更平滑一点，并能通过配置项修改；移入移出的动画除了平移还需要加上透明度的变化；
5. 侧边栏在没有固定住的情况下，如果操作过界面元素，失去焦点时则不会自动收起
6. esc 的功能不完善，很多地方去按下 esc 没有体现【退出当前操作】的功能，比如搜索，还有其他的你自行处理
7. 新建卡片的默认高度太小，在默认情况下出现了滚动条；新建卡片的容器宽度占满了整个边栏，没有像上方元素一样流出间距；
8. 添加一些测试数据，大概二三十条的样子，以便更好地体现效果；
9. 主页的标签下拉菜单功能，和原型没有对齐；原型中的是选择标签过滤内容，你给出的是排序；
10. 搜索组件，如果没有输入内容，在失去焦点的时候需要自动收起；
11. 点开设置按钮，出现设置弹窗的时候，侧边栏会错误地全部隐藏；
12. 在设置页面进行一些操作之后，按下 esc 或者右上角的 x 无法正确关闭窗口，需要多点很多次；
13. 改造整个设置弹窗，是一个独立的弹窗页面，而不是寄宿在侧边栏中；其中的样式、布局、表现都要和原型重新对齐。
