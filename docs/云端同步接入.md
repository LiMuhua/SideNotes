# 云端同步接入

本文说明 0.8.1 起的云端同步（原名云端备份；现在做的是备份与恢复，之后的跨设备自动同步也用这个模块）要准备什么：群晖 NAS 只要在设置里连接；OneDrive 与 Google Drive 要先为 SideNotes 注册 OAuth 客户端，编进程序后才能登录；失败通知的邮件要一个 Resend 的 API 密钥。

## 一、群晖 NAS（WebDAV）

1. 在群晖的「套件中心」安装 WebDAV Server，打开 HTTPS（默认端口 5006）。
2. 在 SideNotes 的「设置 → 数据与同步 → 云端同步」选「群晖 NAS」，点「连接」，填地址（例如 `https://nas.example.com:5006`）、用户名与密码。
3. 外网地址只能用 https；本机与局域网地址（`192.168.x.x`、`*.local` 等）可以用 http。
4. 用 IP 访问、而 NAS 的证书是给域名的（例如 Let's Encrypt 的 `*.example.com`）时，连接时会列出证书上的名字与指纹，确认后按证书上的名字验证证书；证书续期后仍然有效。自签名证书系统不信任，要先装进 Windows 的受信任根证书，或在群晖上换成受信任的证书。

WebDAV 的根目录是 NAS 上的共享文件夹列表，SideNotes 不能在根目录新建共享文件夹。远程文件夹要选在已有的共享文件夹里面，或者先在群晖上建好同名的共享文件夹。

## 二、OneDrive 与 Google Drive 的 OAuth 客户端

登录要一个为 SideNotes 注册的 OAuth 客户端。客户端编号可以在构建时写进程序（`src-tauri/build.rs`），按以下顺序取：

1. 构建时的环境变量 `SIDENOTES_ONEDRIVE_CLIENT_ID`、`SIDENOTES_ONEDRIVE_TENANT`、`SIDENOTES_GOOGLE_CLIENT_ID`、`SIDENOTES_GOOGLE_CLIENT_SECRET`；
2. `src-tauri/oauth-clients.json`（不进仓库，格式见 [oauth-clients.example.json](../src-tauri/oauth-clients.example.json)）。

都没有时，设置页的登录弹窗里先填应用（客户端）ID（Google 还有客户端密钥），存在本机，不用重新构建。

点「打开登录页」后在浏览器里登录，浏览器跳回本机的回调地址时自动回填授权码；没有跳回来时（端口被拦、在另一台设备上登录），把地址栏里的网址或页面上的授权码粘贴到弹窗里。不能借用别的应用（例如 Koodo Reader）的客户端：登录页会显示那个应用的名字，Google 换令牌要用对方保存在它服务器上的密钥，OneDrive 也只给它自己的应用文件夹。

### OneDrive（Microsoft Entra）

1. 打开 [Microsoft Entra 管理中心](https://entra.microsoft.com)，进入「应用注册」，新注册一个应用。
2. 受支持的帐户类型选「任何组织目录中的帐户和个人 Microsoft 帐户」。
3. 重定向 URI 的平台选「公共客户端/本机（移动和桌面）」，填 `http://localhost`。登录时 SideNotes 在本机的随机端口上等回调，Microsoft 对 localhost 不比较端口。
4. 在「API 权限」里加 Microsoft Graph 的委托权限 `Files.ReadWrite`、`User.Read`、`offline_access`。
5. 把「应用程序（客户端）ID」填进 `oauth-clients.json` 的 `onedrive.clientId`；`tenant` 保持 `common`。

### Google Drive（Google Cloud）

1. 在 [Google Cloud 控制台](https://console.cloud.google.com) 新建一个项目，在「API 和服务 → 库」里启用 Google Drive API。
2. 配置 OAuth 同意屏幕：用户类型选「外部」；数据访问里加范围 `https://www.googleapis.com/auth/drive.file`；应用还在测试阶段时，把自己的 Google 账户加为测试用户。
3. 新建 OAuth 客户端，类型选「桌面应用」，把客户端 ID 与客户端密钥填进 `oauth-clients.json` 的 `google`。

注意：

- 范围只有 `drive.file`：SideNotes 只看得到、改得了自己建的文件与文件夹。远程文件夹的选择框里只列得出 SideNotes 建过的文件夹，网盘里原有的同名文件夹它看不到，会另建一个。
- 同意屏幕处于「测试」状态时，Google 发的刷新令牌 7 天后失效，到时卡片上的点变红，重新登录即可；发布应用后不再过期。

## 三、失败通知的邮件（Resend）

1. 在 [Resend](https://resend.com) 新建一个 API 密钥（只要发送权限）。
2. 要用自己的发件地址，先在 Resend 里添加并验证域名；不填发件地址时用 `onboarding@resend.dev`，它只能发给 Resend 账户自己的邮箱。
3. 在设置的云端同步里打开「失败通知」，点「通知邮件」，填收件邮箱、发件地址与密钥，先点「发送测试邮件」确认能收到，再保存。

密钥与 NAS 的密码、OneDrive 与 Google Drive 的登录凭据一样，用 Windows 的 DPAPI 加密后存在本机的应用数据目录（`cloud-secrets.dat`），不写进设置，也不随本地备份导出。换了电脑或 Windows 账户要重新连接、登录与填写密钥。
