# 组件

本文规定五套主题共用的组件：侧栏的各个部件、记录卡片、速记浮窗、设置窗口与基础控件。每个组件只引用令牌（见 [design-tokens.md](./design-tokens.md)）与结构差异（见 [DESIGN.md](./DESIGN.md) 第四节）；各主题的具体取值见主题文档。Playground 中「组件」页按当前主题渲染全部组件与状态。

## 一、侧栏

### 1.1 结构

侧栏自上而下：

| 部件 | 高度或尺寸 | 说明 |
| --- | --- | --- |
| 标题区 | `--sn-header-height` | 品牌标记与产品名；右侧是固定与收起按钮（版本号在底栏） |
| 页签 | `--sn-tab-height` | 随记、置顶与手动固定的标签，最后一格是菜单；条数只写在随记与当前页签上（2026-11-14 起，见 1.4；现有为工作区、置顶、归档三个页签，都带计数）。这一行最右边是搜索（第五次反馈曾移到筛选行，第六次反馈移回） |
| 整理提醒 | 按内容 | 记录超过阈值时出现：建议把同一类的记录固定为页签或合并成一条、七天内不再提醒、关闭（现有为工作区记录超过阈值时提醒去归档） |
| 筛选行 | 按内容 | 左边是标签下拉（选了标签时同时写条数）与「固定为页签」「合并」，搜索时换成结果的条数，有选中的卡片时换成「已选 N 条」与「合并」「移入回收站」；右边是多选与收起/展开全部（2026-11-15，见 1.5；现有为列表顶栏：左边条数，右边标签筛选按钮） |
| 新建卡片 | 按内容 | 常驻在列表之上（现有在归档页签中不显示，2026-11-14 去掉了归档）；在标签页签中带上「#标签 ×」 |
| 记录列表 | 剩余高度 | 只有这一部分滚动 |
| 底栏 | `--sn-footer-height` | 左下角是版本号（有新版本时带更新角标），右边是设置按钮，其余留白 |

侧栏朝屏幕内侧的一边是调整宽度的手柄：指针一移上去就变为左右箭头，表示可以拖动；高亮要等指针停留 400ms 之后，只是划过不会闪一下强调色（本次提出）。按下即可拖动，获得焦点时立即高亮，可用方向键调整。

### 1.2 面板与屏幕边缘

| 结构 | 主题 | 做法 |
| --- | --- | --- |
| 贴边整块（flush） | 终端 | 面板贴住屏幕边缘，朝屏幕内侧一条边框；贴边一侧的圆角取 `--sn-panel-radius-edge` |
| 浮动面板（floating） | 杂志、记录纸、Windows 11 | 离开屏幕边缘 `--sn-panel-inset`，四角圆角 `--sn-panel-radius`，一像素边框 |
| 分开的若干块（blocks） | 磨砂玻璃 | 没有整块面板：标题区与页签、列表顶栏、新建卡片、每条记录、底栏各是一块，块间距 `--sn-block-gap` |

面板底色 `--sn-color-panel`，投影 `--sn-shadow-panel`；半透明主题加背景模糊 `--sn-panel-blur` 与饱和度 `--sn-panel-saturate`。

### 1.3 标题区

- 左边是品牌标记与产品名。品牌标记就是应用图标，配色固定，不随主题变化，见第七节（本次提出）。
- 固定按钮按下时显示为选中；设置窗口打开期间，侧栏保持展开，固定按钮显示虚线圈，表示「临时固定」（现有行为 T31）。
- 收起按钮的箭头指向屏幕边缘；快捷键 Esc。
- 手机形态不显示固定与收起按钮。

### 1.4 页签

- 页签是「随记」「置顶」与用户手动固定的标签，最后一格是菜单（2026-11-14 本次提出；原来的「工作区」改名随记，去掉「归档」，规则见 [interactions.md](./interactions.md) 第十二节）。标签页签不写 #，名称最多显示 4 个字（`--sn-font-size-md` 的 4 倍宽），超出省略；条数只写在随记与当前页签上。
- 最后一格（2026-11-15 第六次反馈）：只占一个位置，样子固定。页签都放得下、后面还有位置时是「+」（弱化文字色的图标）；页签都放得下、只差「+」时不显示，不为它收起页签（第七次反馈）；真放不下时写收起的个数「N ▾」，个数用代码字体，这一格只有数字与小箭头的宽度（第七次反馈：此前沿用计数徽标的最小宽度，比需要的宽 12px，和一个两字的页签差不多）。不为写名字预留宽度，页签真放不下才收起，收到刚好放下为止。菜单与右键菜单相同，宽度按最长的页签名再留一点空白，列出收起的页签，末尾是「新建页签」。
- 末格（2026-11-16 第八次反馈）：放不下时，最后一个显示的页签与「N ▾」合成一格，两者之间不留页签间距，中间一条短竖线（边框色，上下各离页签边缘 `--sn-space-3`）。从菜单选的页签换进末格，带当前样式（下划线或浮起的胶囊）；名字放不下时缩短，末尾省略，最短留两个字。
- 当前页签始终显示名字（第七次反馈），本该收起时换进末格（第八次反馈）。条数只写在随记与当前页签上；页签栏放不下当前页签的条数时不写，不为它收起别的页签（第八次反馈）。
- 页签有两种形态：下划线（当前页签下方一条强调色的线）与分段控件（当前页签为浮起的胶囊）。磨砂玻璃在页签前加分区色圆点（随记 `--sn-color-mark-workspace`、置顶 `--sn-color-mark-pinned`，标签页签用原来归档的 `--sn-color-mark-archive`）。
- 页签按 WAI-ARIA 页签模式：左右方向键切换并立即显示，Home 与 End 到两端。
- 搜索在这一行的最右边：收起时只是放大镜，点击后搜索框从右向左展开到整行，盖住页签，页签淡出；收起是展开的倒放（第五次反馈曾放到筛选行，第六次反馈移回：放在筛选行像是只搜当前页签）。宽度变化用 `--sn-duration-slow` 的 1.25 倍（终端 200ms，与现有应用的 220ms 相近），页签淡出与输入框淡入用 `--sn-duration-normal`，输入框等宽度展开一段之后才出现。框内依次是放大镜、输入框（占位文字：搜正文，#标签 筛选，如「开发 #发布」；第九次反馈：写出两种写法可以同时用）、灰字联想的 Tab 按键提示与清空按钮（有内容时出现）；有搜索词时框保持展开。磨砂玻璃中页签栏本身是一块玻璃，展开的搜索框不带自己的边框、底色与底边的强调色线，只有放大镜、输入框与清空按钮（第八次反馈：框里套框）。

### 1.5 整理提醒、筛选行与搜索

- 整理提醒用警告色浅底（`--sn-color-warning-subtle`）。
- 筛选行（2026-11-15 本次提出：侧栏顶部保持两行，去掉筛选条）。左边是标签下拉：没选标签时写「# 全部标签 ▾」（条数已经写在当前页签上）；选了标签时写「# 产品 · 2 条」，条数用代码字体的弱化文字，▾ 换成一个清除筛选的 ×，两者合成一个强调色浅底的胶囊（`--sn-color-accent-subtle`、`--sn-color-accent-text`），不再出现两个 #。点胶囊打开标签菜单，菜单从下拉的左下方展开。
- 选了标签时，胶囊后面是「固定为页签」（这个标签还没固定时）与「合并」（筛出两条以上时）：强调色小号文字按钮，悬停时强调色浅底。
- 搜索时（第六次反馈）筛选行保留：标签下拉换成结果的条数（代码字体的弱化文字，与标签下拉里的条数同一种写法），只搜一个已有标签时后面同样是「固定为页签」「合并」。
- 筛选行右边是对整个列表的操作（第六次反馈），小号图标按钮，最右一个正好在页签栏放大镜的正下方：多选（勾选框图标；按下时强调色浅底，卡片出现勾选框，见 2.3；第七次反馈起不写条数）与收起/展开全部（两个尖角相对是收起、相背是展开；列表为空时不可用）。
- 搜的词正好是已有标签的名称时（第八次反馈），结果条数后面是「#开发 8 条」：强调色小号文字按钮，条数用代码字体的弱化文字，点它改搜这个标签。
- 有选中的卡片时（第七次反馈），筛选行左边换成「已选 N 条」（与搜索结果的条数同一种写法）与「合并」（两条以上时）「移入回收站」两个强调色小号文字按钮，代替标签下拉或结果的条数；「移到…」留在右键菜单里。
- 搜索结果按页签分组，置顶组总在最上面（第七次反馈）。组标题一行：页签的图标（随记是记录图标、置顶是图钉、标签是 #）、名称（中等字重，次要文字色）与条数（代码字体的弱化文字），右侧「转到 →」是强调色小号文字按钮。组标题与上一组的最后一张卡片之间多留 `--sn-space-2`。
- 搜索命中的文字用搜索命中的底色 `--sn-color-highlight`，文字颜色不变，不加圆角（第七次反馈）：不带 # 的词标在标题与正文中，「#标签」标在整个标签胶囊里（第八次反馈：文字不再标在标签上）。
- 末尾正在输入 `#标签` 时联想已有标签（现有行为，交互见 [interactions.md](./interactions.md) 第六节）。

标签菜单沿用现有应用（`TagFilter`）。宽度跟着内容走：最长的一项加上左右的内边距，条数与标签之间多留 8px（本次提出：此前固定为弹窗宽度的 0.6 倍，标签少时显得太宽）。自上而下：

| 部位 | 内容 |
| --- | --- |
| 首位标签 | 评分最高的标签命中搜索词或正被选中时，移到最上方，右侧是「管理」按钮（重命名、合并或从所有记录中移除） |
| 全部标签 | 清除标签筛选，右侧是当前页签的条数 |
| 候选标签 | 评分最高的六个标签（含首位），每项右侧是条数；悬停说明评分的权重：访问频率 40、近期访问 30、条数 4、置顶 3 |
| 底部 | 一项「搜索标签」，打开搜索框并预填 `#`；候选之外还有标签时，右侧写「另有 N 个」（本次提出：现有应用在按钮旁写一句提示，文字太长，会把菜单撑宽） |

没有标签时，候选位置写「输入 #标签 创建分组」；有搜索词但没有匹配的标签时写「没有匹配的标签」。

### 1.6 新建卡片

- 一个编辑区，占位文字两行：「记一条… 支持 Markdown、#标签」与保存方式。底部的工具栏一直显示：添加图片、引用文件、字数（终端为 Ctrl+Enter 按键提示）、保存（主要按钮，没有内容时禁用）。不随焦点收起展开，也没有收起按钮；点工具栏的空白处时焦点回到编辑区；长文在编辑区里滚动（2026-11-11 第二次反馈：此前获得焦点或有内容时才出现工具栏，点工具栏一行时卡片会收起）。
- 获得焦点时与编辑中的卡片一样：底色换成编辑底色 `--sn-color-editing` 并浮起，层级提到列表之上；边框不变，不用强调色，磨砂玻璃保留边缘受光。
- 草稿与速记浮窗共用。
- 在标签页签中，工具栏上有一个「#标签 ×」，强调色浅底的胶囊，保存时写进标签行，点 × 这条记录不带（2026-11-14 本次提出）。

### 1.7 底栏

五套主题的底栏相同（本次提出）：

- 左下角是版本号「v0.7.2」，字号 `--sn-font-size-xs`、弱化文字色。检查到新版本时，版本号右上角出现更新角标：强调色的小圆点里一个向上的箭头。
- 点版本号：有新版本时打开「发现新版本」，列出这次即将更新的内容，可以「立即更新」或「稍后」，「稍后」之后角标保留；没有新版本时打开当前版本的更新日志。
- 右边是小号的设置按钮，快捷键 Ctrl+,。
- 读取或保存失败时，版本号左边出现警告图标，说明换成「未能读取本地记录」或「本地存储失败」。
- 其余位置留白，不放条数与快捷键：条数已经写在页签与列表顶栏上，快捷键列在设置的快捷键页。底色叠一层 `--sn-color-panel-band`，与列表之间一条浅色分隔线。

现有应用的版本号在标题区，底栏左边是表示本地存储状态的绿色圆点；圆点取消，这个位置改为版本号与更新提示。

## 二、记录卡片

### 2.1 结构

```text
┌───────────────────────────────────────────────┐
│ 📝  标题，最多两行……………………       📌 06:04      │  ← 标题行
│     ………………………………………                              │
│ 正文预览，超过最大高度时底部渐隐                    │
│ #标签  #标签                                    │  ← 只在有标签时显示
└───────────────────────────────────────────────┘
悬停、选中或聚焦时，标题行右侧换成：[置顶] [复制] [更多] [收起]
```

| 部位 | 规则 |
| --- | --- |
| Emoji | 点击更换；宽 `--sn-icon-size` 加 `--sn-space-3`，高 `--sn-control-height-sm` |
| 标题 | 正文的第一行，去掉标题标记；字体 `--sn-font-title`、字号 `--sn-font-size-lg`、字重 `--sn-title-weight`；最多两行，超出部分省略 |
| 右侧位置 | 时间与操作按钮叠放在同一格，格宽取两者中较宽的一个。平时显示置顶标记与创建时间；悬停、选中或键盘聚焦时换成操作按钮。标题的宽度因此在悬停前后不变 |
| 时间 | 创建时间，字号 `--sn-font-size-xs`，弱化文字色；悬停在时间上显示创建与修改时间；点击时间收起或展开正文 |
| 操作按钮 | 置顶（排在最前）、复制、更多、收起（2026-11-14 去掉了归档或恢复）；已置顶时，置顶按钮的图标保持强调色文字色（`--sn-color-accent-text`），与平时的置顶标记同色，指针停在按钮上也不变；小号图标按钮，高 `--sn-control-height-sm` |
| 正文 | Markdown 渲染，字体 `--sn-font-note`、字号 `--sn-note-size`、行高 `--sn-note-line-height`；超过设置中的「卡片高度」时底部渐隐，双击查看全文 |
| 标签 | 小号胶囊，点击按标签筛选；没有标签时不占位置 |

Emoji、时间与按钮对齐标题的第一行。单行记录与收起的记录只剩标题行。

### 2.2 三种组织方式

| 结构 | 主题 | 做法 |
| --- | --- | --- |
| 窗格（panes） | 终端 | 标题行是带底色的标题栏（`--sn-color-card-head`），与正文之间一条分隔线 |
| 卡片（cards） | 杂志、记录纸、Windows 11 | 底色 `--sn-color-card`，边框 `--sn-color-border-subtle`，投影 `--sn-shadow-sm` |
| 玻璃块（tiles） | 磨砂玻璃 | 每块各自磨砂，边缘受光（`--sn-color-rim-top` 到 `--sn-color-rim-bottom`），顶部光泽（`--sn-color-sheen`） |

圆角 `--sn-card-radius`，内边距 `--sn-card-padding-x` 与 `--sn-card-padding-y`，卡片之间 `--sn-card-gap`。

### 2.3 状态

| 状态 | 表现 | 令牌 |
| --- | --- | --- |
| 默认 | 卡片底色、浅边框，右侧显示时间 | `--sn-color-card`、`--sn-color-border-subtle` |
| 置顶 | 一圈淡的强调色边框（强调色占 45%，混入浅边框色），比悬停暗，也没有悬停的叠加色、外圈与标题栏变色；悬停、单击与多选时照常按高亮显示（2026-11-15 本次提出：此前置顶卡片与普通卡片相同，只靠图钉区分） | `--sn-color-accent`、`--sn-color-border-subtle` |
| 转到 | 「转到」一条记录时，强调色外圈闪一下后淡去，约 1.3 秒（2026-11-15） | `--sn-color-accent`、`--sn-focus-ring-width` |
| 悬停与选中 | 强调色边框加一像素外圈，叠一层选中色；终端的标题栏换成选中色，顶部一条 2px 的强调色线（画在背景层里，两侧不留细缝）；玻璃块去掉边缘受光，不加光晕；编辑中的卡片不用这些高亮 | `--sn-shadow-card-active`、`--sn-color-card-active`、`--sn-color-card-head-active` |
| 多选 | 叠一层强调色浅底，强调色边框 | `--sn-color-accent-subtle` |
| 滚到列表边缘 | 卡片滚到列表的上边或下边时，在 `--sn-space-6` 内从不透明渐变到全透明，不再被一刀截断；只在那一侧还有内容时出现，刚开始滚动时一段一段移进来（2026-11-16 第八次反馈）。遮罩加在列表（滚动容器）上，与滚动一起合成，快速滚动时不落后；最右边滚动条的一列不变淡；列表放得下时没有遮罩（第九次反馈，见技术决策 DS-16） | `--sn-space-6` |
| 多选按钮按下 | 标题左边的 Emoji 换成勾选框（图标大小的方框，粗一点的强边框，小号对勾），勾选后填满强调色、对勾用强调色上的文字色；右上角的操作按钮隐藏，只留置顶标记与时间（2026-11-15 第七次反馈） | `--sn-color-border-strong`、`--sn-color-accent`、`--sn-color-on-accent` |
| 键盘焦点 | 卡片内侧一圈焦点环 | `--sn-color-focus`、`--sn-focus-ring-width` |
| 编辑中 | 一圈强调色边框，换成编辑底色并浮起；不叠悬停时的外圈，终端的标题栏换成选中色但不画顶部的强调色线（本次提出），见 [editing.md](./editing.md) | `--sn-color-editing`、`--sn-color-accent`、`--sn-shadow-editing` |
| 其余卡片变淡 | 有卡片在编辑时降到禁用透明度，悬停时恢复 | `--sn-opacity-disabled` |
| 收起 | 只剩标题行 | — |

悬停与单击共用同一种高亮，指针离开后最后高亮的一张保持高亮（现有行为 T66）；高亮的那一张就是 Ctrl+C 复制的对象。选中卡片中的时间与标签改用次要文字色，因为弱化文字在选中底色上达不到 4.5:1。

其中几项的写法：

- **明暗模式与主题**：选项卡片，每个选项是用对应主题与明暗的令牌画出的迷你侧栏；选中的卡片为强调色边框。
- **应用图标**：一行图标格，写法见第七节。
- **字体**：可以输入筛选的组合框，候选用各自的字体显示，「跟随主题」在最前并写出当前主题名，「系统默认」在最后；输入的字体不在候选中时提示并恢复原值。
- **字体预览**：字体与字号下方占满一行的一块，保留凹陷底色，文字居中，三行依次是中文与标点、英文大小写、数字与符号（含 `2026-11-08` 这样的连字符与 `->`、`!=` 等编程连字），用当前选用的正文字体显示。
- **移出后收起、回收站保留天数**：组合框，可以从常用值中选，也可以直接输入，超出范围时提示并恢复原值；指针停在框上转动滚轮按 100 毫秒、1 天加减。
- **快捷键**：一行是名称与按键；点击按键后按下新的组合即可，冲突时在按键左侧说明原因；改过的按键旁有单独的恢复按钮。
- **云端同步**（原名云端备份，现有应用第十一、十二轮反馈）：一律叫「同步」，云端存的每一份叫「快照」，不出现「备份」。同步发往每个连上了、选了远程文件夹的服务，所以分两段（技术决策第 70 条）。上面对所有服务：自动同步与失败通知一行（见下），上次同步（时间与下次自动同步）后面紧跟「立即同步」。下面是服务卡片（群晖 NAS、OneDrive、Google Drive，像标签页，离上面远一些、贴着下面一行），角上一个点表示连接状态：正常绿、正在同步的那家强调色闪烁、异常红并悬停显示原因。卡片下面一行是选中服务的账户、远程文件夹与快照份数，不折行：放不下时先让路径末尾省略，再让账户，名称、按钮与图标不缩。账户（群晖 NAS 在弹窗里填地址、用户名与密码后连接，证书上的名字与地址对不上时列出名字与指纹、确认后按证书上的名字验证；OneDrive 与 Google Drive 点「登录」直接在浏览器里登录，登录后自动完成，浏览器没跳回来时把地址栏里的网址粘贴进弹窗的授权码（文本框，空着三行高，随内容长高）；连上后写全账户，按钮变成断开连接或退出登录）与远程文件夹（按服务分别存、没有默认值，没连接或没选时是 `/`；路径加文件夹按钮，弹出逐层进入、可以新建的选择框，连上之后还没选就自动弹出）。自动同步（开关、频率：每小时、每天、每周、每月、自定义，再选时间、星期或日期，自定义直接写 crontab，输入框按写法的长短给宽度；不加问号）与失败通知（开关、收件邮箱与信封按钮，弹出「失败通知邮件」：收件邮箱、发件地址、Resend 密钥、发送测试邮件）同一行，前一项写全，放不下时由邮箱末尾省略。缺了配置时开关不打开，弹出选中服务的弹窗并在标题下写明原因；别的服务连着时，选中的没连接也照样同步。最后是选中服务的快照列表，逐份恢复。

窗口尺寸 880 × 560，高度固定（2026-11-14 本次提出：0.7.3 为 880 × 720，内容少的分类留下大片空白；2026-11-11 曾改为随内容 360–600，切换分类时窗口跳动），都受视口限制，不随字号变化，内容按字号缩放；手机上铺满屏幕。曾加宽到 960 让「其它」一组的三项在默认字号下排在一行；2026-11-11 明暗模式与主题的卡片收窄后改回 880，放不下的项折到下一行。设置页的按钮、下拉框、输入框与回收站的搜索框用常规尺寸（`--sn-control-height`），回收站每行的图标按钮与快捷键旁的恢复图标仍是小号。

| 复选框、单选、开关 | 图标尺寸 | 选中为强调色；开关是 `role="switch"` 的按钮 |
| 分段控件 | 高同按钮 | 单选组，方向键切换并立即生效；当前项浮起 |
| 下拉选择框 | 高同按钮 | 列表框按 WAI-ARIA 模式：方向键移动、首字母跳转、Enter 选定、Esc 关闭；展开或用键盘移到上面时与输入框一样显示底边的强调线 |
| 组合框 | 高同按钮 | 输入框右侧是展开按钮；输入框获得焦点时同时展开候选，按 Esc 关闭后再点输入框重新展开（与现有应用一致）。候选列表的样式与下拉选择框相同；上下都放不下时放到空间较大的一侧，在列表里滚动，不盖住输入框。可以直接输入，Enter 或失去焦点时提交，不接受的值提示后恢复原值；取值为数字时居中显示，可以用滚轮加减 |
| 问号说明 | 边长 `--sn-icon-size-sm` 的圆形按钮 | 悬停、获得焦点或点击时显示说明框，与工具提示同样用浮起的表面（现有应用的问号说明同样是卡片底色加浅色边框）。说明框比工具提示多一点强调：叠一层很淡的强调色（`--sn-color-accent-subtle`），投影用 `--sn-shadow-lg`，不会和设置页同样浮起的分组卡片融在一起（本次提出）。Esc 关闭；说明可以分行，带按键 |
| 滑块与数值输入框 | — | 滑块右侧带数值输入框，数值居中显示（本次提出）；两者都可以用滚轮加减，规则见 [interactions.md](./interactions.md)；字号松开滑块或滚轮停下后才应用（现有行为是松开后应用） |
| 快捷键 | 字号 `--sn-font-size-xs` | 每个键一个小框，圆角 `--sn-radius-xs` |
| 徽标与标签 | 圆角 `--sn-radius-chip` | 计数徽标；标签胶囊悬停时换成强调色浅底 |
| 空状态 | — | 图标、标题、一句说明，按需带一个按钮 |

**输入类控件的焦点**（输入框、多行文本框、搜索框、数字框、组合框，展开或用键盘移到上面的下拉选择框，以及有搜索词的侧栏搜索框）：边框颜色不变，底边换成一条两倍边框宽（2px）的强调色线，与 Windows 的输入框相同，不加外圈（本次提出）。强调色只出现在底边，不围住正在输入的文字；线画在背景层里，随控件的圆角弯曲，杂志的胶囊形控件上随两端收窄。复合控件（搜索框、侧栏搜索框、组合框）里的原生输入框不画焦点环，焦点只由外层控件的底边强调线表示。快捷键按钮录入中同样只换底边的强调线，加一层浅强调色底。

**菜单项**：指针悬停时叠一层悬停色，用键盘移到时换成选中色 `--sn-color-selected`，不加焦点环。

其余控件（按钮、开关、复选框、页签、卡片等）的焦点环统一：`--sn-focus-ring-width` 宽、`--sn-focus-ring-offset` 间距、`--sn-color-focus` 颜色，只在键盘操作时显示。

## 七、应用图标与品牌标记

### 7.1 内置图标

应用图标定稿为六个内置图标，默认 211（本次提出，过程见 [design-decisions.md](./design-decisions.md) 第三十七、三十九节）。资源随应用打包，在 `src-tauri/icons/builtin/`，清单是 `manifest.json`；`assets/app-icon.svg` 是默认图标的副本，原型与 Playground 的网页图标引用它。

| 编号 | 名称 | 画面 |
| --- | --- | --- |
| 211（默认） | 门缝浅笑 · 靛蓝 | 靛蓝暗房里，一张黄色便签从门缝探出来浅笑，旁边三颗星点；左下角的折角放大、换成浅色并加一道阴影，像一只小手 |
| 212 | 门缝平视 · 靛蓝 | 同一场景，平视，两颗星点 |
| 213 | 门缝浅笑 · 暖 | 暖色暗房，门缝透出暖光，浅笑，三颗星点 |
| 214 | 门缝平视 · 暖 | 暖色暗房，平视，两颗星点 |
| 210 | 一叠 · 浅笑 | 一叠便签从屏幕边上探出来，最前面那张浅笑，三颗星点 |
| 172 | 叠纸 · 一掠 | 最前面那张便签留下两道残影，像是唰地一下落到手边；没有表情 |

六个图标都是 64 × 64 的圆角方块，圆角 14；配色固定，不随主题变化。任务栏、托盘、程序坞、关于页，以及侧栏标题区、速记浮窗与设置窗口的品牌标记，都显示设置中选用的同一个图标，只是尺寸不同：标题区为图标尺寸的 1.25 倍，速记浮窗与设置窗口最小化后的按钮与图标尺寸相同，关于页为大号控件高度的 1.5 倍。设置窗口打开时，任务栏上有一个带运行指示的图标（设置窗口不隐藏任务栏按钮，与现有应用一致）。

每个图标有 12 个尺寸的 PNG（16、20、22、24、32、40、48、64、96、128、256、512）与一个 ICO（16、20、24、30、32、36、40、48、60、64、72、80、96、256），每个尺寸都从母版直接渲染。Playground 的「应用图标」页列出各尺寸、像素放大、使用场景与设计演进。

### 7.2 应用图标设置

在设置「外观与交互 › 显示」中，排在主题之后（本次提出）。交互参照常见的头像设置：

| 部位 | 规则 |
| --- | --- |
| 图标格 | 6 个内置图标在前，默认图标排第一，最后是自定义格；格子边长为控件高度的 1.5 倍，图标铺满格子，单击即换，立即生效 |
| 选中 | 强调色边框加一像素外圈，与明暗模式、主题的选项卡片相同；悬停时边框换成 `--sn-color-border-strong` |
| 预览 | 悬停或键盘聚焦时在图标上方显示大图，不写名称（本次提出）；名称只写在 `aria-label` 中，默认图标写「（默认）」；格子本身不写字 |
| 键盘 | 整行是一个单选组，方向键在图标之间移动并选中；焦点环只在键盘操作时显示 |
| 自定义格，没有图片 | 虚线边框的加号格，悬停时边框与加号换成强调色；点击选择图片 |
| 自定义格，已上传 | 显示裁好的图片，单击选用；右下角压一个圆形编辑按钮，打开菜单「更换图片…」「移除」。移除时如果正在使用它，回到默认图标；提示条带「撤销」 |

可以上传 PNG、JPG、WebP、GIF、BMP、SVG 与 ICO，最大 10 MB。读不出的图片提示后不做改动。

选好图片后打开「调整应用图标」弹窗：

- 左边是正方形的裁切框，透明部分用棋盘格表示。刚打开时图片铺满裁切框并居中；拖动移动，滚轮以指针为中心缩放，方向键微调（按住 Shift 移得更多），加号与减号缩放。最小可以缩到完整显示，最大放大到铺满时的 4 倍；图片比裁切框大的方向上不留空边。
- 裁切框下方是缩放滑块，两端是减号与加号按钮。
- 右边是托盘、任务栏与桌面三种实际尺寸（16、24、48px）的预览，浅色与深色任务栏各一行；下面是「圆角」开关，默认打开，圆角与内置图标相同，透明背景的标志可以关掉。
- 图片短边小于 256 像素时，弹窗底部提示桌面与资源管理器中的大图标会发虚。
- 「使用」裁成 256 × 256 的 PNG 并立即换上，提示「已换成自定义图标」；「取消」、Esc 或关闭按钮不做改动。打开时焦点在「使用」上。

桌面应用如何保存图片、替换窗口与托盘图标，见 [adaptation.md](./adaptation.md) 第十节。

现有应用的图标是灰绿色的两张纸片，标题区的品牌标记是三根竖条，不能更换。
