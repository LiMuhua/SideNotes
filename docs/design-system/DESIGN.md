# SideNotes 设计规范

本文是 SideNotes 设计系统的总纲：定位、设计原则、五套主题，以及各份规范的分工。规范以现有 0.7.3 的功能为准，只重构操作逻辑、布局与样式；标注「本次提出」的内容是对现有行为的修改建议。

## 一、定位

SideNotes 是贴在屏幕边缘的速记工具：鼠标移到屏幕边缘唤出侧栏，移开后收起；在任何程序中按快捷键呼出速记浮窗，记完就回到原来的工作。目的是不打断当前工作、随手记下碎片想法，整理与查找是辅助功能。

| 窗口 | 尺寸 | 用途 |
| --- | --- | --- |
| 侧栏 | 宽 416px（设置中可调，360 至 720），高度铺满屏幕 | 浏览、新建、编辑、整理记录 |
| 速记浮窗 | 560 × 420 | 全局快捷键呼出，记一条就收起 |
| 设置 | 880 × 720 | 外观与交互、快捷键、数据与同步、回收站、关于 |

现有功能的完整清单见 [references/sidenote-current-state.md](./references/sidenote-current-state.md)。

## 二、设计原则

1. **记下就走。** 新建卡片常驻在列表上方，Ctrl+Enter 保存后焦点留在原处，可以接着记下一条；速记浮窗保存即收起。
2. **一眼看清每一条。** 每条记录有自己的底面与边框，彼此留出间隙；悬停或选中的一条要醒目到不用找。
3. **重点不被挤掉。** 标题最多两行；操作按钮出现时与时间共用位置，不挤占标题。
4. **键盘与鼠标都顺手。** 每个操作都有鼠标入口，常用操作有快捷键；终端主题把快捷键直接写在界面上。
5. **同一结构，多套主题。** 五套主题共用一套组件与交互，差异来自令牌与少数结构差异，切换主题不需要重新学习。
6. **可读性优先于效果。** 半透明主题按最差背景保证对比度；效果做不到的平台退回实心表面。

## 三、五套主题

五套主题都会实现，在设置中切换，默认为终端。明暗模式（浅色、深色、跟随系统）单独设置，每套主题都有浅色与深色。

| 主题 | 理念 | 与屏幕边缘 | 记录 | 页签 | 强调色 | 材质 |
| --- | --- | --- | --- | --- | --- | --- |
| [终端](./themes/terminal.md)（默认） | 终端里并排的窗格，键盘优先 | 贴边整块 | 带标题栏的窗格 | 下划线 | 琥珀 | 实心 |
| [杂志](./themes/magazine.md) | 随手翻的杂志，阅读舒适 | 离开边缘 8px | 圆角卡片 | 分段控件 | 莓红 | 实心 |
| [记录纸](./themes/paper.md) | 纸垫上的一叠纸片，单色墨水 | 贴边整块 | 纸片 | 下划线 | 墨绿 | 实心 |
| [Windows 11](./themes/win11.md) | 和开始菜单一样的亚克力面板 | 离开边缘 12px | 半透明卡片 | 下划线 | 系统蓝 | 半透明 |
| [磨砂玻璃](./themes/glass.md) | 分开的几块磨砂玻璃 | 分开的若干块 | 玻璃块 | 分段控件加色点 | 青 | 半透明 |

浅色模式下，五套主题用不同的色相与底色区分：终端是冷灰加琥珀；杂志是暖白加莓红；记录纸是灰绿；Windows 11 是中性的白加蓝；磨砂玻璃透出桌面，强调色是低饱和的青。

五份主题文档使用同一套章节：定位、结构、颜色、字体与排版、形状间距与尺寸、层次与立体感、状态、编辑模式、动效、实现与平台、已知限制；最后的附录由令牌文件生成，列出这套主题的全部取值。

## 四、体系结构

1. **令牌**（`tokens/`）：颜色、字体、尺寸、圆角、材质与动效，见 [design-tokens.md](./design-tokens.md)。
2. **结构差异**（`playground/src/surfaces.ts`）：令牌表达不了的 6 项差异，即与屏幕边缘的关系、记录的组织方式、页签形态、是否半透明、快捷键是否写在界面上、页签色点。
3. **组件**：五套主题共用一套组件与样式（`playground/src/styles/`），只引用令牌与结构差异，见 [components.md](./components.md)。

Design Playground 用同一套令牌与组件运行三个窗口，见 [playground/README.md](./playground/README.md)。

## 五、本次提出的改动

与现有 0.7.3 相比，规范建议以下改动，细节见对应的分册：

| 改动 | 现有行为 | 见 |
| --- | --- | --- |
| 五套主题取代现有的四种界面材质，设置项「界面材质」改称「主题」 | 标准、纸张、玻璃、Win11 四种材质 | [adaptation.md](./adaptation.md) |
| 操作按钮与时间共用标题行右侧的位置，悬停时换下时间；标题最多两行 | 标签与操作按钮固定占卡片底部一行；标题只显示一行 | [components.md](./components.md) |
| 底部只在有标签时显示标签 | 没有标签也保留底部一行 | [components.md](./components.md) |
| 操作按钮的最右边增加收起按钮，位置与平时的时间相同；点时间收起的行为保留 | 只能点时间收起 | [interactions.md](./interactions.md) |
| 置顶按钮排在操作按钮的第一个 | 依次为复制、置顶、归档、更多 | [components.md](./components.md) |
| 悬停与选中用各主题的强调色，加一像素外圈；终端的标题栏同时染色 | 统一的绿色边框 | [components.md](./components.md) |
| 编辑中的卡片只有一圈强调色边框，换成编辑底色并浮起；获得焦点的新建卡片只换编辑底色并浮起，工具栏一直显示；编辑区里不画边框、强调线与行号；记录纸出现横线 | 编辑中的卡片用强调色边框、外圈与投影，其余卡片变淡（T21） | [editing.md](./editing.md) |
| 输入框、搜索框、下拉框等获得焦点时，底边换成强调色线，不加外圈 | 强调色边框 | [components.md](./components.md) |
| ↑ ↓ 在卡片之间移动，Enter 编辑，Delete 移入回收站，Shift+F10 打开卡片菜单 | 卡片只能用鼠标操作 | [interactions.md](./interactions.md) |
| Esc 在收起侧栏之前先清除多选 | 有多选时 Esc 直接收起侧栏 | [interactions.md](./interactions.md) |
| 提示条在指针停留或获得焦点时暂停计时 | 6 秒（带撤销 9 秒）后消失 | [interactions.md](./interactions.md) |
| 速记浮窗不显示草稿状态；快捷键与 Markdown 的说明收进标题旁的问号；字数放在附件工具右边；磨砂玻璃的浮窗是一整块玻璃，编辑器直接写在玻璃上 | 标题下写「Markdown · #标签」，占位文字第二行写保存与收起的按键，编辑区下方一行是草稿状态与字数 | [components.md](./components.md) |
| 设置窗口沿用 880 × 720（曾加宽到 960，2026-11-11 改回），同一行的设置项之间有竖线分隔，问号说明只留给需要额外理解的项；滑块、数值输入框与数字组合框可以用滚轮调整；按钮与输入类控件用常规尺寸；路径单行省略，悬停看全文，双击复制 | 名称后多数带问号，只能拖动或输入 | [components.md](./components.md) |
| 版本号移到底栏左下角并缩小，检查到新版本时带更新角标，点开列出即将更新的内容；底栏不再显示存储状态的绿色圆点（出错时仍显示警告） | 版本号在标题区，点击查看更新日志；底栏左边是存储状态的绿色圆点 | [components.md](./components.md) |
| 调整宽度的手柄在指针停留 400ms 后才高亮，指针仍然立即变为左右箭头 | 指针移上去立即高亮 | [interactions.md](./interactions.md) |
| 新的应用图标：六个内置图标，默认 211「门缝浅笑 · 靛蓝」，设置中可以切换或换成上传的图片；标题区的品牌标记用同一个图标，配色固定，不随主题变化 | 灰绿色的两张纸片，不能更换；品牌标记是三根竖条 | [components.md](./components.md) |
| Ctrl+, 打开设置 | 只能点设置按钮或侧栏菜单 | [interactions.md](./interactions.md) |
| 回收站的保留天数紧跟在条数之后；调试只留一个「打开开发者工具」按钮；标签菜单底部只有「搜索标签」一项 | 保留天数在页面标题右侧；侧栏、速记浮窗、设置各一个按钮；标签菜单底部是一句提示加「搜索」按钮 | [components.md](./components.md) |
| 「字体」设置增加「跟随主题」，并作为默认值 | 字体作用于全部界面文字 | [adaptation.md](./adaptation.md) |
| Windows 11 与磨砂玻璃使用透明窗口加 Acrylic | 三个窗口都不透明 | [adaptation.md](./adaptation.md) |
| 手机形态：侧栏铺满屏幕，不显示快捷键与固定、收起按钮 | 没有移动端界面 | [layout.md](./layout.md) |

## 六、实现顺序（建议）

1. 接入令牌与主题切换：设置项 `surface` 新增 `terminal`、`magazine`，现有的 `standard` 迁移为 `terminal`，见 [adaptation.md](./adaptation.md)。
2. 按 [components.md](./components.md) 重写侧栏：卡片、标题行、新建卡片、底栏。
3. 编辑模式（[editing.md](./editing.md)）与键盘操作（[interactions.md](./interactions.md)）。
4. 速记浮窗与设置窗口。
5. 三套实心主题完成后，再做两套半透明主题的窗口材质：先实测 Acrylic 在侧栏滑入滑出时的表现，并补上不透明的退路颜色。
6. 应用图标的切换：设置项 `appIcon`、窗口与托盘图标的替换、快捷方式的图标，见 [adaptation.md](./adaptation.md) 第十节；资源已随应用打包。
