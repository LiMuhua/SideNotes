# 无障碍

本文规定 SideNotes 的无障碍要求：对比度、焦点、键盘、指针目标尺寸、动效、读屏与缩放。目标是 WCAG 2.2 的 AA 级；控件的键盘行为遵循 WAI-ARIA 创作实践（APG）。五套主题使用同一套要求，令牌的对比度由测试逐项检查。

## 一、对比度

| 对象 | 要求 | 检查方式 |
| --- | --- | --- |
| 正文、标题、时间、标签、快捷键提示等一切文字 | 不低于 4.5:1，小字也不例外 | `tests/tokens.test.ts` |
| 控件边界（输入框、复选框等）、焦点环、输入光标、页签色点 | 不低于 3:1 | 同上 |
| 选中与多选卡片的强调色边框 | 不低于 3:1，与卡片内的底色比较 | 同上 |
| 卡片之间的边框与间隙 | 不作要求：卡片的范围由底色、间隙与文字共同表明，边框只是辅助 | — |

WCAG 允许 18pt 以上的大字只达到 3:1，本规范不使用这一放宽：侧栏里的字都不大，统一按 4.5:1 要求。

**最差情况。** 两套半透明主题的表面会透出桌面，桌面是什么颜色无法预知。测试把每一层半透明颜色依次叠在纯黑与纯白两种背景上，两种结果都要达标；需要叠放的组合（例如卡片底色上再叠选中色）按实际的层次计算。完整的组合清单见 [design-tokens.md](./design-tokens.md) 第六节。

**弱化文字。** 选中卡片的底色更深，弱化文字在上面达不到 4.5:1，所以选中卡片中的时间与标签改用次要文字色（见 [components.md](./components.md) 2.3 节）。

## 二、焦点

- 焦点环统一为 2px 的实线（`--sn-focus-ring-width`），与元素相距 2px（`--sn-focus-ring-offset`），颜色 `--sn-color-focus`。卡片的焦点环画在卡片内侧，避免被相邻的卡片遮住。
- 只在键盘操作时显示（`:focus-visible`），鼠标点击不显示。
- 焦点环用 `outline` 绘制，不用阴影，所以在 Windows 的对比主题下仍然可见（见 [adaptation.md](./adaptation.md) 第七节）。
- 输入类控件（输入框、搜索框、数字框、组合框、下拉选择框）不用焦点环，获得焦点时底边换成 2px 的强调色线；强调色与控件底色的对比度由测试保证不低于 3:1，文字输入框同时有闪烁的光标。这条线画在背景层里，对比主题下会被去掉，所以对比主题改用系统高亮色 `Highlight` 的轮廓线。搜索框与组合框里的原生输入框同样不画焦点环，焦点由外层控件表示。
- 菜单项用键盘移到时换成选中色，不加焦点环；对比主题下同样改用 `Highlight` 的轮廓线。
- 焦点不能被遮住：只有记录列表滚动，标题区、页签与底栏都在滚动区域之外，用方向键移到的卡片会滚动到可见位置。
- 弹窗打开时焦点移入，关闭后回到打开前的位置；菜单关闭后焦点回到打开它的元素；删除一条记录后焦点回到侧栏，不会丢失。

## 三、键盘

- 每一个鼠标操作都有键盘方式完成：卡片用方向键移动、Enter 编辑、Delete 移入回收站、Shift+F10 打开菜单（本次提出，见 [interactions.md](./interactions.md) 第三节）；拖动排序、框选等只能用鼠标完成的操作，都能通过菜单或快捷键得到同样的结果（例如「选择全部记录」）。
- 记录列表只占一个 Tab 停靠点（roving tabindex），不会让用户按几十次 Tab 才能离开列表。
- 页签、菜单、下拉选择框、单选组、弹窗的按键遵循 APG 的对应模式，见 [interactions.md](./interactions.md) 3.3 节。
- 快捷键写在按钮的 `aria-keyshortcuts` 属性中，并列在设置的快捷键页；终端主题另外把常用快捷键直接写在界面上。按钮不加悬停提示（本次提出）。
- 全局快捷键可以在设置中重新绑定，冲突时给出原因（现有）。

## 四、指针目标的尺寸

WCAG 2.2 的 2.5.8 要求指针目标里放得下一个 24 × 24 CSS 像素的正方形。放不下的目标算作偏小：以它为圆心画一个直径 24 的圆，圆不能碰到其他目标或其他偏小目标的圆（间距例外）；同一功能另有达标的入口时也可以例外。这项要求与页面的缩放倍数无关（见 [references/reference-matrix.md](./references/reference-matrix.md) 第四节），所以一律按令牌中的 CSS 像素判断，不计字号设置带来的缩放。

SideNotes 的小号图标按钮之间都留 2px（`--sn-space-1`），中心距等于「小号控件高度 + 2px」：

| 主题 | 小号控件 | 控件圆角 | 放得下 24 × 24 的正方形 | 中心距 | 结论 |
| --- | --- | --- | --- | --- | --- |
| 终端 | 24 | 3 | 否，四角被圆角切掉 | 26 | 满足间距例外 |
| 记录纸 | 24 | 6 | 否，四角被圆角切掉 | 26 | 满足间距例外 |
| Windows 11 | 24 | 4 | 否，四角被圆角切掉 | 26 | 满足间距例外 |
| 杂志 | 26 | 胶囊 | 否 | 28 | 满足间距例外 |
| 磨砂玻璃 | 26 | 12 | 否 | 28 | 满足间距例外 |

单位为 px。结论：

- 五套主题的小号按钮都靠间距例外满足要求，相邻两个圆之间至少留 2px。终端原来是 22px，中心距正好 24，两个圆相切、没有余量；2026-11-07 改为 24px，见 [design-decisions.md](./design-decisions.md) 第二十节。
- 卡片上的操作按钮在卡片菜单中都有对应的菜单项（菜单项高 26 至 34px），也可以算作等效例外；编辑栏与标题区的按钮没有对应的大目标。
- 因为按钮之间的间隙决定了是否达标，所以各主题都不能取消这 2px。
- 问号说明的按钮边长只有 14 至 15px（`--sn-icon-size-sm`），同样靠间距例外：它前面是名称文字，后面的控件至少隔 6px，直径 24 的圆向外只伸出 4.5 至 5px，碰不到其他目标。这 6px 不能收紧。

手机上用手指操作，触控目标至少 48 × 48dp（Android 与 Material 3 的要求）。桌面的 24 至 26px 不能沿用；Playground 的手机画面尚未放大触控目标。

## 五、动效

- 系统开启「减少动态效果」时，过渡与动画缩短到近似为零，循环动画只播放一次，滚动不再平滑；状态变化照常发生（Playground 已实现）。侧栏的出入动画按 0 处理（本次提出）。见 [interactions.md](./interactions.md) 11.2 节。
- 没有闪烁或连续闪动的元素；加载转圈只在等待时出现。
- 设置中的「出入动画」可以设为 0，关闭侧栏的滑入滑出（现有）。

## 六、读屏与语义

| 部件 | 角色与属性 |
| --- | --- |
| 侧栏 | `aside`，名称「SideNotes 侧栏」 |
| 页签 | `tablist`、`tab`、`tabpanel`；当前页签 `aria-selected` |
| 记录列表 | `list`，名称为条数（例如「21 条记录」）；每条记录是 `listitem` 中的 `article`，名称为记录标题；高亮的一张带 `aria-current` |
| 收起按钮 | `aria-expanded` 表示正文是否展开 |
| 图标按钮 | 必须有 `aria-label`；可切换的按钮带 `aria-pressed` |
| 菜单 | `menu`、`menuitem`，分隔线为 `separator` |
| 弹窗 | `dialog`，`aria-modal="true"`；需要确认的危险操作用 `alertdialog` |
| 提示条 | 所在区域为 `status`（`aria-live="polite"`）；失败提示用 `alert` |
| 开关 | 按钮加 `role="switch"` 与 `aria-checked` |
| 分段控件 | `radiogroup` 与 `radio` |
| 下拉选择框 | `combobox` 与 `listbox` |
| 组合框 | 输入框为 `combobox`，带 `aria-expanded`；获得焦点时展开候选，当前候选用 `aria-activedescendant` 标出，焦点始终留在输入框；候选列表不盖住输入框 |
| 问号说明 | 按钮名称为「某某说明」，带 `aria-expanded`；说明打开时用 `aria-describedby` 指向 `tooltip` |
| 调整宽度的手柄 | `separator`，带 `aria-valuenow`、`aria-valuemin`、`aria-valuemax` |
| 版本号 | 按钮名称写明版本号；有新版本时写明「发现新版本 0.7.3，点击查看更新内容」，更新角标只是装饰（`aria-hidden`） |
| 工具提示 | `tooltip`，延迟 500ms 出现；只用于应用图标的大图预览，按钮的名称只写在 `aria-label` 中 |

编辑区沿用现有的实时编辑器，是带 `aria-label`（「编辑记录」）的可编辑区域。

## 七、缩放与文字

- 字号设置 12 至 20px，整个界面等比缩放（现有），再叠加系统的显示缩放。
- 侧栏最窄 360px，内容竖向排列，不需要横向滚动；代码块的长行只在块内横向滚动。
- 标题最多两行，超出部分省略；完整的标题在编辑时与正文中可见。

## 八、高对比度

Windows 对比主题下的处理见 [adaptation.md](./adaptation.md) 第七节：焦点环不受影响；悬停、选中与编辑中的卡片需要改用系统颜色的轮廓线（待实现）。

## 九、检查清单

发布前逐项确认：

1. `pnpm test` 通过，其中包括对比度、样式与文档三项设计系统检查。
2. 只用键盘完成：新建一条记录、搜索、编辑、置顶、归档、移入回收站并撤销、打开设置并改回。
3. 系统开启「减少动态效果」后，没有滑动与旋转。
4. 字号 12px 与 20px 下，没有被截断而无法看到的控件。
5. 两套半透明主题在纯黑与纯白的壁纸上都清楚可读。
6. Windows 对比主题下，焦点、选中与编辑中的卡片都能分辨（待实现）。
