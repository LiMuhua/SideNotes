# 交互

本文规定 SideNotes 的鼠标、键盘与触屏操作，以及动效。五套主题的交互完全相同，只有动效的时长与曲线随主题变化。

「来源」一栏中，「现有」是 0.7.3 已有的行为，规范予以保留；「本次提出」是本规范建议的修改，Playground 已按此实现，个别没有模拟的另行注明。编辑模式的操作见 [editing.md](./editing.md)。

## 一、唤出与收起

| 操作 | 结果 | 来源 |
| --- | --- | --- |
| 鼠标移到屏幕边缘 | 侧栏滑入；设置中可以关闭「贴边唤出」 | 现有 |
| 鼠标移出侧栏 | 经过「移出后收起」的延迟后收起（默认 600ms，可设 100 至 10000ms）；延迟内移回则不收起 | 现有 |
| Alt+Shift+S | 在任何程序中切换侧栏的显示与收起 | 现有，可重新绑定 |
| 点标题区的固定按钮 | 保持展开，再点一次取消 | 现有 |
| 打开设置窗口 | 设置窗口打开期间保持展开，固定按钮显示虚线圈 | 现有 |
| 点标题区的收起按钮，或按 Esc | 立即收起 | 现有 |
| 侧栏菜单「停靠到屏幕左侧 / 右侧」 | 换到另一侧；设置中也可以选择 | 现有 |

下列情况下，侧栏不会自动收起：

- 固定、有菜单或弹窗打开、正在拖动、正在读取附件时，始终保持展开。
- 有多选、正在编辑记录、新建卡片有未保存的内容时，只在鼠标移出时保持展开（「编辑时保持展开」去掉了，编辑期间一律保持展开）；点到侧栏之外（整个侧栏失去焦点）仍会收起，编辑中的卡片在失焦时已经保存。

侧栏滑入滑出的时长取设置中的「出入动画」（默认 260ms，可设 0 至 600ms，0 表示关闭），不随主题变化。

## 二、选中与多选

| 操作 | 结果 | 来源 |
| --- | --- | --- |
| 指针移到卡片上 | 高亮这张卡片；指针离开后，最后高亮的一张保持高亮 | 现有 |
| 单击卡片 | 高亮这张卡片，与悬停是同一种高亮 | 现有 |
| Ctrl+单击 | 加入或移出多选 | 现有 |
| 已有多选时单击卡片 | 同 Ctrl+单击 | 现有 |
| Shift+单击 | 从上一次单击的卡片选到这一张 | 现有 |
| 在列表空白处拖动 | 框选 | 现有，Playground 没有模拟 |
| Ctrl+A（已有多选时） | 选中当前列表的全部记录；侧栏菜单「选择全部记录」效果相同 | 现有，Playground 只模拟了菜单项 |
| 单击空白处 | 清除高亮与多选 | 现有 |

操作的对象：有多选时是全部选中的记录，否则是高亮的那一张。复制、移到页签、移入回收站都按这一规则；多选时右键其中一张还可以合并，见第十三节（2026-11-14 去掉了归档）。

## 三、键盘

### 3.1 全局与侧栏

| 按键 | 操作 | 来源 |
| --- | --- | --- |
| Ctrl+Shift+Space | 呼出速记浮窗（任何程序中） | 现有，可重新绑定 |
| Alt+Shift+S | 呼出或收起侧栏（任何程序中） | 现有，可重新绑定 |
| Ctrl+N | 把焦点移到新建卡片；正在编辑的记录先保存 | 现有，可重新绑定 |
| Ctrl+F | 展开搜索框 | 现有，可重新绑定 |
| Ctrl+, | 打开设置窗口；侧栏获得焦点时响应，编辑中也可用 | 本次提出，可重新绑定 |
| Ctrl+C | 复制高亮或多选的记录（含附件）；焦点不在侧栏时也对悬停的卡片生效 | 现有 |
| Esc | 逐级退出，见 3.4 | 现有 |

全局快捷键由后端注册为系统热键，不能占用 Windows 自己使用的组合键（例如 Alt+Tab、Shift+F10、Win 加字母）；设置中录入时检查冲突，被其他程序占用时提示（`src/core/shortcuts.ts`）。

### 3.2 卡片

卡片列表只占一个 Tab 停靠点：Tab 进入列表时落在高亮的卡片上（没有高亮时是第一张），再按 Tab 离开列表。

| 按键 | 操作 | 来源 |
| --- | --- | --- |
| ↑、↓ | 移到上一张、下一张，并高亮；高亮了卡片而焦点不在卡片上（悬停高亮、编辑或菜单结束后）时同样有效，焦点随之落到卡片上 | 本次提出 |
| Home、End | 移到第一张、最后一张 | 本次提出 |
| Enter | 编辑这张卡片；焦点不在卡片上时编辑高亮的那一张 | 本次提出 |
| Delete | 移入回收站，不确认，提示条可以撤销；这张卡片在多选之中时移入全部选中的（2026-11-15 本次提出：此前先确认） | 本次提出 |
| Ctrl+C | 复制 | 现有 |
| Shift+F10、菜单键 | 打开卡片菜单，菜单出现在卡片左上角附近 | 本次提出 |

卡片获得焦点后，标题行右侧换成操作按钮，继续按 Tab 依次到达这张卡片的 Emoji、操作按钮与标签；其余卡片里的按钮不进入 Tab 顺序，只响应指针（本次提出）。时间不进入 Tab 顺序，它的作用由收起按钮承担。

### 3.3 控件

控件的键盘操作遵循 WAI-ARIA 创作实践（APG）的对应模式：

| 控件 | 按键 |
| --- | --- |
| 页签 | ←、→ 切换并立即显示，Home、End 到两端 |
| 菜单 | ↑、↓ 移动，Home、End 到两端，Enter 或空格执行，Esc 关闭并把焦点还给打开它的元素 |
| 下拉选择框 | ↑、↓、Enter 或空格打开；打开后 ↑、↓ 移动，Enter 选定，Esc 关闭 |
| 组合框 | 获得焦点时展开候选（现有）；↓ 打开候选或下移，↑ 上移，Enter 选用当前候选（候选未打开时提交输入的内容），Esc 关闭候选，再点输入框重新展开；失去焦点时提交 |
| 问号说明 | 获得焦点或点击时显示说明，Esc 关闭 |
| 分段控件与单选组 | 方向键切换并立即生效，Home、End 到两端 |
| 弹窗 | 打开时焦点移入，Tab 在弹窗内循环，Esc 关闭，关闭后焦点回到打开前的位置 |
| 调整宽度的手柄 | 获得焦点后 ←、→ 每次调整 8px，按住 Shift 每次 40px（本次提出） |
| 设置窗口的分类栏 | ↑、↓ 切换分类 |

### 3.4 Esc 的逐级退出

每按一次 Esc，只退出一层：

1. 关闭打开的菜单或弹窗。
2. 取消正在进行的拖动。
3. 退出编辑，放弃修改。
4. 新建卡片失去焦点，草稿保留。
5. 清除多选（本次提出）。
6. 关闭搜索框并清空搜索词，回到原来的页签，标签筛选保留；框内有灰字联想时，先关闭联想（现有）。
7. 清除标签筛选（2026-11-15 本次提出）。
8. 收起侧栏。

| 操作 | 结果 | 来源 |
| --- | --- | --- |
| 双击卡片 | 编辑；多选或拖动之后不触发 | 现有 |
| 双击列表空白处 | 收起或展开全部卡片 | 现有 |
| 点 Emoji | 打开「更换 Emoji」 | 现有 |
| 点时间 | 收起或展开正文；悬停显示创建与修改时间 | 现有 |
| 点收起按钮（操作按钮的最右边） | 收起或展开正文 | 本次提出 |
| 点标签 | 按这个标签筛选当前页签；搜索时改为搜这个标签（2026-11-15） | 现有，搜索时为本次提出 |
| 按住卡片 300ms 后拖动 | 排序；停在页签上 240ms 切换过去，松开即移到该页签（标签页签按标签加减，见第十二节）；停在页签栏的最后一格 0.6 秒展开菜单，可以放进收起的页签；拖到回收站即移入；松开后可以撤销 | 现有，最后一格为本次提出；Playground 没有模拟 |

| 按住卡片拖出侧栏 | 拖影保持倾斜并放大一点；松开后在那里打开记录窗口：窗口从拖影的位置展开、摆正后落定，默认置顶；多选的几条放进同一个窗口的标签页；落在已开的窗口上时放进它的标签页 | 本次提出，交互原型实现 |
| 点「展开全文」 | 在记录窗口中打开全文：窗口从卡片的位置向桌面一侧滑出并放大；双击正文编辑 | 本次提出，交互原型实现 |
| 记录窗口 | 宽高都按内容决定：宽 280–560（有标签页时按标签页定宽，最宽 720），高不超过 600 与视口的六成，按 13px 字号计，正文四周留白相同；标题栏拖动，四边与四角缩放，双击标题栏放大或还原；获得焦点时边框带一点强调色、外面淡淡一圈。拖出的窗口默认置顶，置顶时图钉是实心的。关闭是打开的倒放：拖出的窗口提起、倾斜着缩回原来的卡片、摆正淡出，卡片轻轻一顿；「展开全文」的窗口原路滑回；卡片看不见时原地提起、倾斜着淡出。Esc 关闭当前标签页，只剩一个时关闭窗口；Shift+Esc 关闭整个窗口（2026-11-15，编辑中的内容与点关闭按钮一样先保存）；「关闭全部记录窗口」快捷键关闭全部。桌面端另加 Ctrl+W 关闭当前页、Ctrl+Shift+W 与 Alt+F4 关闭窗口（浏览器中被占用，原型做不了，待桌面端实现） | 本次提出，交互原型实现 |
| 记录窗口的标签页 | 两个以上时标题栏换成标签页，标签栏比单页的标题栏高，右侧留一块空白按住可以拖动窗口；窗口标题栏或标签页拖到另一个窗口上时合并，标签页拖到窗口外拆成新窗口（默认置顶），在标签栏里拖动调整顺序，插入线标出位置；中键或标签页上的叉关闭。叉只在当前一页与悬停时浮在右端；标题被截断时悬停片刻显示全名。标签页可以放在左侧竖排：窗口标题栏上的按钮切换，与设置「外观与交互 › 其它 › 窗口标签页」是同一项；竖排时标题栏写当前标题，插入线是横线 | 本次提出，交互原型实现 |
| 在编辑区里拖动图片、文件或选中的文字 | 移到落点，不是复制；可以撤销。图片与文件按住移动 4 像素后开始拖动，插入光标落在字符之间，只能放在标题之后、正文末尾之前；原来那一行空了就删掉。拖影（2026-11-15）先停在拿起的位置，再平滑移到指针的右下方，左上角跟着指针；拖影半透明地垫在编辑区的文字下面，插入光标在最上层，与拖影重叠的字也能看清 | 本次提出 |
| 按住图片或文件引用拖到另一张卡片 | 移过去，可以撤销 | 现有，Playground 没有模拟 |
| 从资源管理器把文件拖到卡片上 | 插入附件；停留片刻进入编辑，可以放到具体位置 | 现有，Playground 没有模拟 |
| 拖动侧栏朝屏幕内侧的边 | 调整宽度，按 4px 取整；指针移上去立即换成左右箭头，停留 400ms 后手柄才高亮，只是划过不会闪一下（本次提出），按下即可拖动 | 现有 |
| 点底栏的版本号 | 有新版本时打开「发现新版本」，列出即将更新的内容；否则打开当前版本的更新日志 | 本次提出（现有：点标题区的版本号查看更新日志） |

## 五、右键菜单

右键卡片打开卡片菜单，右键空白处打开侧栏菜单（现有）。菜单项的名称与顺序沿用现有应用：

| 菜单 | 菜单项（分隔线用「｜」表示） |
| --- | --- |
| 卡片菜单 | （全局搜索的结果）转到「页签」｜（多选之中时）合并成一条…、合并到「标题」（标题超过 10 个字截断）｜复制内容与附件、编辑内容、展开或收起正文｜置顶记录或移到普通记录｜移到…（随记与固定的标签页签）｜创建副本、导出 Markdown、记录信息｜移入回收站 |
| 页签菜单 | 右键标签页签：改名、｜移出页签栏；最后一格菜单中收起的页签右键：放到页签栏、改名、｜移出页签栏（收起的页签也可以按住拖动，见第十二节） |
| 侧栏菜单 | 新建记录、搜索记录｜收起或展开全部卡片、选择全部记录（列表不为空时）｜固定侧栏、停靠到另一侧、设置、使用指南｜收起侧栏 |

菜单项右侧写出快捷键或鼠标操作（例如 Ctrl+C、双击、Delete）；危险操作放在最后，用危险色。

## 六、搜索与筛选

侧栏顶部只有两行：页签栏，与下面的筛选行（2026-11-15 本次提出）。筛选行左边是标签下拉，按标签筛选当前页签；右端是搜索，搜索全部记录。标签菜单与灰字联想沿用 0.7.3（`Sidebar.tsx`、`TagInput.tsx`、`TagFilter.tsx`）：

| 操作 | 结果 | 来源 |
| --- | --- | --- |
| 点筛选行的标签下拉 | 打开标签菜单（当前页签中的标签），焦点在第一项 | 现有 |
| 在标签菜单中点标签、点卡片上的标签 | 按这个标签筛选当前页签；标签下拉写「# 产品 · 2 条」，后面一个 × 清除筛选；再后面是「固定为页签」（这个标签还没固定时）与「合并」（筛出两条以上时） | 现有，写法与按钮为本次提出 |
| 点「全部标签」、点 ×、按 Esc、再点一下当前页签 | 清除标签筛选 | 现有，后三种为本次提出 |
| 点首位标签旁的「管理」 | 打开「管理 #标签」：重命名，或合并到已有的标签；也可以从所有记录中移除这个标签，记录正文与附件保留 | 现有 |
| Ctrl+F 或点放大镜 | 搜索框从筛选行的最右边向左展开到整行，盖住标签下拉与按钮，焦点移入；收起是展开的倒放 | 现有，位置为本次提出（此前在页签行，盖住页签） |
| 输入文字 | 搜索全部记录（不含回收站），与当前页签和标签筛选无关，匹配正文、标签与附件名。写完整的已有标签（如 `#产品`）只匹配这个标签，没写完的按前缀匹配；只写 `#` 时不算搜索 | 本次提出（此前只搜当前页签） |
| 搜索时的列表 | 结果按页签分组：每条记录放在页签栏中第一个包含它的页签（随记、置顶、固定的标签依次），组的顺序与页签栏相同，组内置顶在前。组标题写页签名与条数，右侧「转到」切到这个页签。页签栏不标出当前页签，新建卡片收起，搜索框里写结果的条数；搜索结果中不能拖动排序 | 本次提出 |
| 只搜一个已有标签 | 搜索框里出现「固定为页签」（还没固定时）与「合并」（两条以上时），作用于全部结果 | 本次提出 |
| 卡片菜单「转到「页签」」 | 结束搜索，切到这条记录所在的页签，滚到它并闪一下 | 本次提出 |
| 单击页签 | 结束搜索并切到这个页签 | 本次提出 |
| 输入 `#` 加标签的开头 | 联想已有标签（全部记录中的）：Playground 与桌面端在框内以灰字联想，Tab 选用，↑ ↓ 切换候选；交互原型在框下列出候选，Enter 选第一个，↓ 移进候选 | 现有 |
| 点清空按钮 | 清空搜索词，回到原来的页签；标签筛选保留 | 本次提出（此前同时清除标签筛选） |
| 再点放大镜、按 Esc | 收起并清空搜索词，回到原来的页签与滚动位置 | 现有 |
| 点标签菜单底部的「搜索标签」 | 打开搜索框并预填 `#`，光标在 `#` 之后 | 现有 |
| 搜索框失去焦点 | 没有内容时自动收起；有内容时保持展开，结果留在列表中 | 现有，后半为本次提出 |

选用标签时记下使用次数与时间。标签菜单的候选先排命中搜索词与已选中的标签，其余按评分排序：访问频率 40、近期访问 30、条数 4、置顶 3；搜索框中的灰字联想按同一评分排序（现有，`src/core/notes.ts` 的 `rankTags` 与 `suggestTags`）。

## 七、反馈与撤销

| 项目 | 规则 | 来源 |
| --- | --- | --- |
| 提示条 | 反色；同时最多三条，超过时丢弃最早的一条 | 现有 |
| 停留时间 | 普通提示 6 秒，带「撤销」的提示 9 秒；指针停在提示条上或焦点在提示条内时暂停计时 | 时长为现有，暂停为本次提出 |
| 位置 | 设置中的「通知位置」：顶部正中（默认）、右上角、底部正中 | 现有 |

## 九、设置窗口

- 打开设置窗口不会收起侧栏，见第一节。
- 窗口高度固定，切换分类时不跳动；内容多的分类在页面里滚动。设置中的操作（复制路径、恢复记录等）的提示条显示在设置窗口里（本次提出）。
- 设置改动立即生效，没有「应用」按钮（现有）。
- Esc 关闭设置窗口；焦点在输入框、下拉框、组合框或正在录入快捷键时，Esc 先退出这些控件（现有）。
- 数值输入框在 Enter 或失去焦点时提交；不是范围内的整数时提示原因，并恢复原值（现有）。
- 字体组合框按输入的内容筛选候选；输入的字体不在候选中时提示并恢复原值（现有）。
- 快捷键的录入：点按键框后按下新的组合即可，Esc 取消；与其他命令或固定按键冲突时在左侧说明原因，按键保持不变。全局快捷键至少按住两个修饰键，或一个修饰键加功能键；其余快捷键要按住 Ctrl 或 Alt，功能键除外（现有，`src/core/shortcuts.ts` 的 `shortcutProblem`）。
- 字号滑块松开后才应用（现有）；用滚轮调整时，滚轮停下 500ms 后才应用，途中只改显示的数值（本次提出）。
- 滚轮调整数值（本次提出）：
  - 指针停在滑块、数值输入框或「移出后收起」「保留天数」这类数字组合框上转动滚轮，向上加、向下减；每一格一个步长，按住 Shift 为十个步长，结果限制在取值范围内。
  - 一次滚动手势只交给一个对象：手势开始时指针在控件上，由控件接管，页面不滚动；开始时在别处，整个手势都滚动页面，指针中途扫过滑块也不会改值。停顿超过 400ms 算作新的手势。
  - 触控板的小增量累计到约 30px 才算一格；禁用的控件不接管滚轮；Ctrl + 滚轮留给缩放。

## 十一、动效

### 11.1 时长与用途

三档时长随主题变化，用途固定：

| 令牌 | 用于 | 终端 | 杂志 | 记录纸 | Windows 11 | 磨砂玻璃 |
| --- | --- | --- | --- | --- | --- | --- |
| `--sn-duration-fast` | 悬停与按下的颜色变化、卡片高亮、时间与操作按钮的切换、工具提示出现 | 70ms | 150ms | 160ms | 100ms | 160ms |
| `--sn-duration-normal` | 菜单、下拉列表与提示条出现，遮罩淡入，开关圆钮、分段控件与页签下划线移动，收起按钮旋转，其余卡片变淡，搜索框中页签与输入框的淡入淡出 | 110ms | 240ms | 240ms | 167ms | 260ms |
| `--sn-duration-slow` | 弹窗、速记浮窗与设置窗口出现 | 160ms | 340ms | 280ms | 250ms | 360ms |
| `--sn-motion-distance` | 元素出现时的位移 | 4px | 12px | 6px | 8px | 10px |

各主题的缓动曲线见主题文档的「动效」一节。规则如下：

- 元素出现用 `--sn-ease-enter`（减速），消失用 `--sn-ease-exit`（加速），状态变化用 `--sn-ease-standard`。
- 只对颜色、透明度与位移做动画，不对宽度、高度与布局做动画。唯一的例外是搜索框的展开与收起（沿用现有应用）：搜索框叠在页签行之上，宽度变化不推动其它元素。它比其它状态变化慢一些，用 `--sn-duration-slow` 的 1.25 倍：终端 200ms、杂志 425ms、记录纸 350ms、Windows 11 约 313ms、磨砂玻璃 450ms（现有应用为 220ms）。
- 加载转圈与骨架屏的循环周期由 `--sn-duration-slow` 推算，分别是它的 4 倍与 6 倍。

### 11.2 减少动态效果

系统开启「减少动态效果」（`prefers-reduced-motion: reduce`）时：

- 所有过渡与动画缩短到近似为零，循环动画只播放一次，滚动不再平滑；状态变化照常发生，只是不再有过程（Playground 已实现）。
- 侧栏的出入动画按 0 处理，即直接出现与消失（本次提出；Playground 的模拟桌面没有处理）。

## 十二、页签

页签是「随记」「置顶」与用户手动固定的标签（2026-11-14 本次提出；原来的「工作区」改名随记，去掉「归档」）：

| 项目 | 规则 |
| --- | --- |
| 随记 | 没有任何已固定标签的记录；条数始终显示 |
| 置顶 | 置顶的记录，与原来相同 |
| 标签页签 | 带这个标签的记录；页签上不写 #，名称超过 4 个字截断；只在当前时显示条数 |
| 固定 | 按标签筛选时点筛选行上的「固定为页签」（只搜一个标签时在搜索框里），或点页签栏最后一格的菜单中的「新建页签」（输入时联想还没固定的已有标签，↑ ↓ 选择，Enter 固定）；不会自动出现页签 |
| 改名 | 双击页签原地改名，Enter 或点到别处确认，Esc 取消；所有记录上的这个标签一起改，与已有标签同名时合并 |
| 排序 | 按住页签横向拖动，插入线标出位置。最后一格菜单中收起的页签也可以拖动（2026-11-15）：在菜单里上下拖，插入线是横线；拖到页签栏插到那个位置，栏里放不下的顺延收进菜单；栏里的页签拖到最后一格上停 0.6 秒展开菜单，放进收起的页签之间（松开后栏里有空位时，排在前面的收起页签会补上来） |
| 移出 | 右键「移出页签栏」：只是不再固定，记录与标签都不变；当前在这个页签时回到随记；提示条可以撤销 |
| 放不下 | 多出来的页签从右往左收进最后一格「N ▾」；选中收起的页签时前面的页签不动，最后一格显示它的名称并带当前样式。最后一格按 4 个字的宽度预留，显示哪个名称都不会挤动前面的页签。单击最后一格总是打开菜单：收起的页签（当前的打勾）与「新建页签」 |
| 移动卡片 | 拖到标签页签：加上这个标签，从别的标签页签来时换掉原来那个；拖到随记：去掉当前页签的标签（卡片还带别的已固定标签时留在那个页签，提示写明）；拖到置顶：只置顶。卡片菜单「移到…」相同 |
| 新建 | 在标签页签中新建，新建卡片的工具栏上有一个「#标签 ×」，保存时写进标签行，点 × 这条不带，保存后提示记在了哪里（见第七节）；速记浮窗进入随记 |
| 键盘 | ← → 在可见的页签之间切换；移到最后一格时只聚焦，Enter 或 ↓ 打开菜单 |
| 旧数据 | 原来的归档记录回到随记，正文加上 #归档 |

## 十三、合并成一条

把零散的记录汇总到一张卡片里整理（2026-11-14 本次提出）：

| 项目 | 规则 |
| --- | --- |
| 入口 | 按标签筛选时筛选行上的「合并」（合并筛出来的全部记录；只搜一个标签时在搜索框里，合并全部结果）；多选后右键「合并成一条…」；多选后右键其中一张「合并到「标题」」（其余选中的追加进这张卡片） |
| 标题 | 所有来源共有的标签（按标签合并时就是筛选的标签），没有时用第一条的标题；弹窗中可以改。合并到已有卡片时标题不变 |
| 小节 | 每条记录除共同标签外的标签合成一个二级小标题，按列表中第一次出现的顺序排；只有共同标签的记录放在最前，不加小标题；带两个以上其他标签的记录合成一节，例如「装修 · 日常」 |
| 内容 | 清单：每条记录一个待办，多出来的行缩进在待办下面；段落：每条记录整段放入，之间空一行。来源都只有一行时默认清单 |
| 标签 | 所有来源标签的并集 |
| 合并到已有卡片 | 按小标题对号，新内容追加到同名小节末尾，没有的小节加在最后；只有共同标签的内容加在第一个小标题之前 |
| 弹窗 | 标题、格式、实时预览与「保留原记录」，点「合并」或 Ctrl+Enter 才写入 |
| 之后 | 新卡片放在原来第一条的位置并进入编辑；原记录移到回收站（勾了「保留原记录」时不动）；提示条一次撤销全部恢复。正文中的图片随段落带过来，缩略条中的图片放到后面，每条最多 12 张 |
