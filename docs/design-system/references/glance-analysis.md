## 一、产品与技术栈

Glance 是「藏在屏幕边缘的系统监控」：鼠标推到屏幕边缘，面板滑出；移开即收回（`README.zh-CN.md` 开头）。0.4 起增加了工作台（中转站、Markdown 便签、快捷启动）和音乐组件，面板可以撕下来变成桌面小组件。

技术上，它是一个约 2 MB 的 Rust 程序，用 Direct2D、DirectWrite 与 DirectComposition 原生绘制（`Cargo.toml` 的 `windows` 依赖；`README.zh-CN.md`「小巧安静」）。没有 CSS，视觉参数全部写在 Rust 常量里，主要集中在 `src/ui/theme.rs`（三种外观的颜色、字体与尺寸）和 `src/ui/skins.rs`（各外观的表面绘制）。

**与 SideNotes 的关系（INFERRED）**：两者的出发点几乎相同，都是贴在屏幕边缘、随用随取的工具。现有 SideNotes 的「纸张、玻璃、Win11」三种材质与 Glance 的三种外观一一对应，浅色纸张的配色（画布 `#edf0e9`）也与 Glance 记录纸（`#EEF2EC`）非常接近，说明现有原型已经受到 Glance 的影响。

## 二、主要视觉特征

Glance 提供三种外观（skin），每种都有浅色与深色：

| 外观 | 源码中的定义 | 视觉特征 |
| --- | --- | --- |
| 记录纸（Paper，默认） | 「一整块贴着屏幕边缘的记录纸」（`theme.rs:8`） | 实心纸面，灰绿色调，单色墨水，栏目之间用细线分隔，贴边的一侧没有圆角 |
| Windows 11（Fluent） | 「一张亚克力，和开始菜单、快速设置一样」（`theme.rs:10`） | 半透明亚克力，8px 圆角，一像素描边，系统强调色标示数据 |
| 磨砂玻璃（Glass） | 「分开的透明玻璃块，在边缘折射桌面」（`theme.rs:12`） | 每个栏目是独立的圆角玻璃块，块间留 8px，边缘有高光，各模块用不同颜色 |

官方截图（`docs/images/looks-zh.webp`，深色）可以看到（OBSERVED）：

- 三种外观的**版式完全相同**：每栏顶部是「粗体标题 + 浅色副标题 + 右对齐数值」（如「CPU　AMD Ryzen 9 9950X……　59 °C」），下面是大号数字、折线图和两列键值表。外观只改变材质、圆角与配色。
- **数字是视觉焦点**：大号读数（42px 左右）配小号单位（%），键值表左列为浅色标签、右列为深色数值。
- **颜色很少**：记录纸外观的图表与数字都是同一种墨色；Windows 11 外观只用系统强调色（蓝）；玻璃外观每个模块一种颜色（CPU 蓝、GPU 绿、内存橙）。

工作台截图（`docs/images/workbench-zh.webp`）中，中转站与便签同样采用「标题 + 计数 + 右侧视图切换按钮」的头部，卡片标题下方是灰色的「类型 · 时间」元信息，便签以浅色纸片叠放（OBSERVED）。

## 三、设计语言

以下原则直接写在源码注释里（SOURCE），是理解 Glance 的关键：

1. **只在有意义时用颜色。** 记录纸「整块面板只有一种墨色，直到某项过热，信号色才出现」（`theme.rs:173-174`）。
2. **用标题和留白分组，而不是加框。** Windows 11 外观「内容靠标题和空间分组，而不是方框；底栏稍暗一些；凡是数据都用用户的强调色」（`theme.rs:246-249`）。
3. **可读性优先于效果。** 玻璃「背后的画面越杂乱、越不配合，就磨得越砂，让文字在任何背景上都清楚」（`theme.rs:317-320`）；磨砂程度按背景亮度与杂乱程度实时计算（`skins.rs:56-63`）。
4. **克制的高光。** 玻璃边缘「顶部受光，底部带一点反光」，作者比较过三种方案，四周都亮的那种「看起来像一根金属管」（`skins.rs:595-596`）。
5. **对齐系统，但不照抄。** Windows 11 外观去掉了系统亚克力自带的颗粒，因为「在深色面板上看起来像噪点」（`skins.rs:492-495`）。

归纳起来（INFERRED）：Glance 是**内容先行、克制用色、层级靠排版与透明度、材质为可读性服务**的设计语言。它的辨识度来自统一的版式和精确的数字排版，而不是装饰。

### 4.5 交互状态

- **悬停**：在当前底色上叠加主要文字色的 4%–10%（见 4.1），不换底色。
- **选中**：设置窗口的选中项使用强调色（`settings_window.rs` 的 `selection`）；分段控件选中项为接近白色的块（`control_on`）。
- **禁用**：浅色 22%、深色 16% 的透明度（`settings_window.rs` 的 `disabled`）。
- **焦点**：设置窗口支持 Tab、方向键、空格操作（`README.zh-CN.md`「使用」一节）。具体的焦点样式本次没有找到明确的常量，不做推断。

## 五、组件特征

### 5.1 右键菜单

「尺寸与 Windows 11 的菜单一致」（`menu.rs:78`）：行高 32、分隔线占 9、内缩 4、圆角 8、图标 16、文字距左 44、最小宽度 200、四周留 16 给阴影；文字 14 / 400（`menu.rs:79-92`）。Windows 11 外观用 Segoe，玻璃与记录纸外观改用各自的字体（`menu.rs:94-102`）。

### 5.2 工具提示

出现在目标下方 8 处，高 28，左右留 10，最宽 360、最高 150，放不下的文字以省略号截断（`tip.rs:58-64`）。小组件上的按钮直径 22、间距 4；指针停留 500ms 才显示「关闭鼠标穿透」这类按钮，避免路过时误触（`buttons.rs:30-35`）。

### 5.3 搜索窗

搜索窗是与 SideNotes「快速搜索」最接近的组件（`find/window.rs:66-96`）：

| 部分 | 尺寸 |
| --- | --- |
| 窗口宽度 | 680 |
| 输入框高度 | 56 |
| 类别标签行 | 40 |
| 分组标题 | 30 |
| 结果行 | 44；最佳匹配行 60（图标 32） |
| 「还有几项」行 | 32 |
| 底栏 | 30 |
| 列表最大高度 | 440，超出后滚动 |
| 没有结果时 | 72 |
| 行内缩 / 图标 / 文字起点 | 6 / 20 / 52 |
| 窗口顶部位置 | 屏幕可用高度的 16% |

键盘模型（`find/window.rs:1314-1371`）：

- Esc 关闭；上下键、PageUp、PageDown 移动选中项。
- Tab 切换类别。
- Enter 打开，Ctrl+Enter 打开所在位置。
- 输入框没有选中文字时，Ctrl+C 复制选中的结果；Ctrl+Shift+C 复制路径。
- 底栏显示操作提示「Enter 打开 · Ctrl+Enter 打开所在位置 · Tab 切换类别」（`find/window.rs:1069`），复制后在底栏显示 1.6 秒的结果提示（`find/window.rs:96`）。

### 5.4 设置窗口

设置窗口模仿 Windows 11 设置应用：左侧 200 宽的导航，右侧是带 8px 圆角的卡片，每行最小高 60，模块卡片中的子项行高 52（与 Windows 设置相同，`settings_window.rs:121-125`）；滑块轨道 160；页签行 48、页签下划线 16（`settings_window.rs:1417-1422`）。

### 5.5 面板与栏目

- 栏目头部：粗体标题、浅色副标题、右对齐数值（OBSERVED）。
- 记录纸外观「栏目之间用线分开，并排的栏目之间也是」（`theme.rs:105-106`、`213`）。
- 底栏放图钉、设置等图标按钮，Windows 11 外观的底栏稍暗（`theme.rs:307`）。

### 5.6 便签

便签以 Markdown 文件保存，「标题、强调、待办方框和链接按排版后的样子显示，Markdown 标记只在正在编辑的那一行显示」（`README.zh-CN.md`「工作台」）。正文 15px，停止输入 600ms 后保存（`note.rs:26`、`note.rs:38`）。

### 5.7 图标

使用 Lucide 的路径数据，24 单位网格，描边 2、圆端点（`icons.rs:1-3`、`icons.rs:285-287`）。

## 六、主题差异

- **主题选项**：浅色、深色、跟随系统，以及「跟随桌面背景亮度」：背景平均亮度不高于 0.5 时用深色（`theme.rs:401-411`）。只有能看到桌面的外观（Windows 11、玻璃）才能跟随背景，记录纸退回跟随系统。
- **深浅色的处理**：Windows 11 与玻璃用同一种颜色加不同透明度表示层级，换主题只需要把黑换成白、调整透明度；记录纸为深浅色分别给出完整的色值。
- **深色下的细节**：深色主题的阴影透明度是浅色的两到三倍（例如 Windows 11 为 40% 对 18%），文字透明度更高（白 100% 对黑 90%），以补偿深色背景上较低的感知对比。

## 七、值得借鉴的设计

| 设计 | 理由 | 在 SideNotes 中的用法 |
| --- | --- | --- |
| 同一版式，多种外观 | 外观只换材质与配色，用户切换后不必重新学习 | 五套主题共用一份结构样式，差异来自令牌与少数结构差异 |
| 层级靠排版与透明度 | 少用边框和底色块，界面安静 | 标题区、页签与底栏少用边框；记录本身要有清楚的边界，见第八节「细线分栏」 |
| 颜色只用于意义 | 一种强调色，一种危险色 | 强调色只用于选中、焦点与主要操作 |
| 标题 + 右对齐数值 | 一行同时交代对象与状态 | 卡片标题行：Emoji、标题、右侧时间 |
| 界面字号与阅读字号分开 | 控件与长时间阅读的需求不同 | 界面用 `--sn-font-size-*`，正文用 `--sn-note-size` |
| 两层阴影 | 浮层轮廓清楚又不脏 | 菜单、弹窗、速记浮窗 |
| 强减速曲线、160–240ms | 响应迅速、收尾平稳 | 动效令牌；终端更短 |
| 贴边一侧不圆角 | 面板与屏幕边缘连成一体 | 终端与记录纸的侧栏贴边一侧没有圆角 |
| 菜单与设置窗口对齐 Windows 11 尺寸 | 桌面用户熟悉 | Windows 11 主题的菜单行高与圆角对齐系统菜单 |
| 底栏提示 | 键盘用户无需记忆快捷键 | 终端在新建卡片、编辑栏与按钮上写出常用快捷键；底栏本身不放提示（2026-11-07 用户反馈底部的快捷键多余） |

## 八、不直接照搬的设计

| 设计 | 处理 |
| --- | --- |
| 玻璃折射与按背景实时磨砂 | Glance 用 DirectComposition 截取桌面画面。SideNotes 用 WebView 渲染，CSS 的 `backdrop-filter` 只能模糊窗口内部的内容；要透出桌面，需要透明窗口加 Tauri 的窗口材质（Windows 的 Acrylic、Mica），Linux 与 Android 没有对应实现，只能退回实心表面。Windows 11 与磨砂玻璃两套主题按这一限制设计，见 [../adaptation.md](../adaptation.md) |
| 细线分栏 | Glance 的栏目内容短而整齐；SideNotes 的记录长短不一，只用细线分隔时边界不清楚，看起来很累（2026-11-05 用户反馈）。记录纸主题改为纸垫上的纸片 |
| 每个模块一种颜色 | 适合区分监控指标；SideNotes 只有三个页签，只在磨砂玻璃主题用页签前的色点区分 |
| 大号数字（40px 以上） | 侧栏没有需要一眼读出的数值 |
| 界面正文 500 字重 | 为了在半透明背景上保持清晰；实心主题用 400，半透明主题由 `--sn-body-weight` 单独取值 |
| 圆角 24 的玻璃块与 16 的控件圆角 | 只用于磨砂玻璃主题；其余主题用小圆角，避免在窄侧栏里浪费空间 |
| 只支持 Windows | SideNotes 还要覆盖 Linux 与 Android，字体、材质与窗口按钮都需要跨平台的退路 |

## 九、结论

Glance 给 SideNotes 的最大启示不是某种材质，而是它的秩序：统一的版式、克制的颜色、靠排版和透明度表达层级，以及把材质效果放在可读性之后。五套主题中，记录纸、Windows 11、磨砂玻璃分别取自 Glance 的三种外观，也对应现有 SideNotes 的纸张、Win11、玻璃三种材质；五套主题的总览见 [../DESIGN.md](../DESIGN.md)，在 WebView 中的做法见 [../adaptation.md](../adaptation.md) 第九节。
