SideNotes

藏在屏幕边上的速记本

指针推到屏幕边缘，或按 Alt + Shift + S，侧栏就滑出来。记一条待办、一行命令、一个链接；指针移开，它又滑回去，手头的工作原样还在。

随时随地记一笔

按 Ctrl + Shift + Space，当前画面上弹出一个速记小窗。写完按 Ctrl + Enter，这条记录就在侧栏里等你。

一句话越写越长时，转到侧栏里接着写，其他记录都在手边。

零碎的记录，也井井有条

  • Markdown 随手可用

    标题、列表、待办、代码块与链接都有快捷键；截图直接粘贴，文件直接拖进来。

  • 标签与页签

    在记录里随手写 #标签。重要的记录置顶，常用的标签固定成页签。

  • 搜索全部记录

    Ctrl + F 搜索全部记录：文字匹配标题、正文与附件名，#标签 只匹配标签，结果按页签分组。

  • 拖出成窗口

    把卡片拖出侧栏，就成了独立的记录窗口；可以置顶在其他程序之上，也可以把几个窗口合并成标签页。

  • 不挡道

    指针离开侧栏，它就滑回去；想让它留着就点固定。侧栏可以贴在屏幕左边或右边。

  • 快捷键由你定

    每个快捷键都能在设置里重新绑定；按键被其他程序占用时会告诉你，并保留原来的按键。

五套主题，各有浅色与深色

明暗跟随系统，也可以固定一种。字体、字号、侧栏宽度和应用图标也都能换。

记录存在你自己的电脑上

  • 不用注册

    记录、附件与设置存在你电脑上的本地数据库里；不开云端同步，什么都不会离开你的电脑。

  • 每天一份快照

    每天自动保存一份快照，导入备份这类操作之前也各存一份，可以从任意一份恢复。

  • 想同步时再同步

    云端同步默认关闭。设置好之后，SideNotes 把快照存到你自己的存储里：群晖 NAS（WebDAV）、OneDrive 或 Google Drive，按时自动同步，也可以随时手动同步。

  • 中间没有别人

    SideNotes 没有服务器，也不收集统计数据；数据从你的电脑直接传到你连接的服务。

SideNotes 如何使用 Google 用户数据

只有你在云端同步里选择 Google Drive 并用 Google 账户登录，SideNotes 才会访问 Google Drive。它只申请 https://www.googleapis.com/auth/drive.file 这一项权限，只能访问 SideNotes 自己在你网盘里建立的文件与文件夹。

SideNotes 用这项权限做什么

  • 建立你选定的快照文件夹，同步时把记录与附件的快照上传到里面。
  • 恢复时列出并下载这些快照。
  • 按保留规则删除这个文件夹里的旧快照。
  • 读取你的 Google 账户邮箱，在设置里显示连接的是哪个账户。

它不会做什么

  • 看不到、读不到也改不了你网盘里的其他文件。
  • 没有服务器：数据只在你的电脑与 Google 之间直接传输。
  • 不出售、不共享 Google 用户数据，不用于广告或训练人工智能模型，也没有任何人阅读这些数据。

在设置里退出登录，会删除保存的登录令牌，并向 Google 撤销 SideNotes 的授权。你也可以随时在 Google 账户的第三方应用与服务里移除 SideNotes。

SideNotes 对从 Google API 获得的信息的使用，以及向任何其他应用的传输，都遵守 Google API 服务用户数据政策，包括有限使用要求。完整内容见隐私政策。
