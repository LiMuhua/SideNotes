## 功能改进项

V0.7.0 Preview 改进项

1. 移出后收起的输入框和下拉框内，不带单位，后面固定单位 ms；
2. 设置中，字体输入过滤的时候，输入一定的内容，按下回车应该是应用匹配的第一个值，如果没有匹配则不允许设置；比如我系统中的字体Maple Mono NF CN，输入Maple按下回车，应该应用第一个匹配项Maple Mono NF CN，，而不是应用不存在的Maple字体然后静默fallback到系统默认字体；搜索结果末尾的 “使用Maple”这一项换成固定的系统默认字体；
3. 设置字体大小，使用滚动条的时候，所有界面会实时重绘疯狂闪动，应该是鼠标松开之后再重绘，而不是值变化的时候重绘；
4. 代码片段：防抖函数 这条数据，的展开全文按钮点击无效，不需要这个按钮，如果有超出的内容，悬浮上去用tipbox提示，或者双击进入编辑视图看，不要再加这个元素；原有的卡片悬浮tipboxx先去掉，这些操作提示性的内容改为首次安装时的使用引导提示；
5. 卡片默认的最大高度加大一点点，并做成配置项，允许用户调整；
6. 消息提示窗口的样式太扁平不够醒目；底部通知默认放到顶部吧，并加一个通知弹出位置的配置项，固定下拉框，允许右上角、顶部正中、底部正中；
7. 偶发的；在收起边栏之后，鼠标移动到指定位置不能呼出边栏；在新建卡片中按下ctrl+enter保存后稳定复现；但不确定是不是只有这种情况；
8. 在边栏内部的新建卡片中按下ctrl+enter保存不关闭整个边栏，仍然保持聚焦；这个改动不影响独立的快速新建卡片；
9. 在使用快捷键生成的包裹性的md标记时，包括但不限于 \*\* \*\*、~~~~、ctrl+u生成的html标签，如果在列表中使用则会错误地将列表的标记语法也包裹起来，导致列表失效，你可以检查 SideNotes 路线图 这张卡片中的数据，我在这个上面进行的测试；
10. 在搜索栏只输入 # 的时候，下面只有3条匹配的数据，测试数据里面几乎都有 # 这个内容，对不上；
11. 复制卡片的消息中，现在是“已复制”，加上标题，已复制-XXX，如已复制-今日代办；
12. 边栏顶部的文字，拖动鼠标应该是不可选中的；
13. 编辑视图下的附件显示行为有问题，点击图片产生的弹窗会导致退出编辑模式；而且总是显示全量的文件标签会使编辑变得困难，附件不显示md源代码标记，和预览模式的样式保持一致，但是文件点击后改为弹窗，弹窗里显示md源码，允许直接手动修改源码或者拖动新文件到这个弹窗中替换，并提供打开、更换、另存为等操作按钮；图片弹窗也是一样；原有的点击打开文件改为按住ctrl+点击打开文件；但是要注意，最终附件数据只保存新的，旧的不再需要的数据需要及时清理，避免无效垃圾容量膨胀。
14. 实现 known-issues.md 中未实现项的 列表按需加载、更换数据存储位置、附件清理 功能；
15. 实现从资源管理器拖动文件进来，默认预览状态下可以拖动到卡片上选择需要需要插入的卡片，在卡片上悬停一会儿之后进入卡片的编辑模式，允许拖动到更为具体的插入位置；
16. 评估数据快照实现的可行性，我担心数据意外损坏，但是额外做备份又不合适，对整个应用数据目录做快照的形式可行吗？资源和可恢复性上？还是说后续实现云同步将其作为备份也行？这两个方案冲突吗？
