# 开发任务

本文跟踪 SideNotes 桌面端的开发任务，是判断当前进度的主要依据。

任务状态分为四种：待开始、进行中、已完成、阻塞。只有通过验收标准中列出的验证，任务才标记为已完成；未经验证的部分写入[已知问题](./known-issues.md)。

## 验证方法

**与原型比对**：用 Python 启动原型的静态服务（`python -m http.server 5181 --directory docs/prototype`），与 `pnpm dev` 同时运行；分别打开原型的设置弹窗与应用的 `?window=settings`（视口 880×720），逐个分类导出截图、DOM 轮廓（标签、类名、文字与相对坐标）和计算样式后比对。`.claude/launch.json` 记录了这两个预览服务。侧栏比对时，原型视口取 1600×1000，应用取 `?debug-data=1`、视口 416×1000。

用无头 Edge 比对时，每次使用全新的用户数据目录并加上 `--disable-extensions`：本机为 Edge 配置的扩展会自动装入新目录，其中有的会改写页面配色或注入浮层，干扰截图与样式比对。

**桌面端调试**：WebView2 支持远程调试，启动时设置环境变量即可用 DevTools 协议连接三个窗口，检查运行时行为：

```bash
WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9555 pnpm tauri dev
```

连接后访问 `http://127.0.0.1:9555/json` 获取各窗口的调试地址。该方式会读写真实的应用数据，验证前应先备份 `%APPDATA%\com.limuhua.sidenotes` 目录下的数据库文件。
