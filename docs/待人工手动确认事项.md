# 待人工手动确认事项

只列我在这台电脑上测不了、要你动手的事：要你的账户、密钥或设备，平常用应用时又不一定碰得到。确认过、改掉或用不着的项随时删掉；平常用着发现的问题直接告诉我，不必等这份清单。

## 一、失败通知邮件（T163）

要你的 Resend 密钥。

1. 设置 → 数据与同步 → 云端同步，点「失败通知」后面的信封按钮，填收件邮箱与 Resend 密钥，点「发送测试邮件」：弹窗里显示已发出，邮箱里收到测试邮件。保存后打开「失败通知」。
2. 让同步失败一次（例如在 NAS 上去掉 `/backup/Test` 的写入权限）后点「立即同步」：弹出系统通知，邮箱里收到「云端同步失败」的邮件。

## 二、Google Drive（T169、T173）

1. 在 [Search Console](https://search.google.com/search-console) 的资源 `https://limuhua.github.io/SideNotes/` 里点「验证」（HTML 标记已加进英文主页并上线，2026-11-22）。
2. 验证通过 24 小时后，在品牌页的「Branding verification issues」里选「I have fixed the issues」，点 Proceed；通过后到[受众页](https://console.cloud.google.com/auth/audience)点「发布应用」。
3. 告诉我，我打开 Google 登录页：登录后弹窗自动关闭，接着弹出远程文件夹的选择框；我选 `/Test`，同步一次，再从这份快照恢复。
