# 待人工手动确认事项

下面这些行为要用真实的键盘、鼠标、游戏或安装包才能确认，自动化验证做不到或会打扰正在用电脑的人，留给你有空时手动测。每项写明要测什么、怎么测、应该看到什么。测出问题时，把看到的现象和下面「出问题时」要的信息告诉我。

测之前用 `pnpm tauri dev` 启动最新代码（或安装最新的安装包）。

## 一、全屏程序在前台时不贴边唤出（T75）

**要测的**：玩游戏、看全屏视频或放映幻灯片时，指针碰到屏幕边缘不应该弹出侧栏（侧栏会抢走焦点，独占全屏的游戏会被切回桌面）。快捷键与托盘照常能唤出。

**步骤与预期**：

1. 打开一个全屏游戏（独占全屏或无边框全屏都试一下），指针移到侧栏所贴的那一边：侧栏不出现。
2. 同一时间按呼出侧栏的快捷键（默认 Alt+Shift+S）：侧栏出现。
3. 浏览器里按 F11 全屏，或播放器全屏播放视频，再碰边缘：侧栏不出现。
4. 退出全屏后再碰边缘：侧栏正常出现。
5. 普通窗口最大化（任务栏自动隐藏时它也铺满整块屏幕）后碰边缘：侧栏正常出现，不应被当成全屏。
6. 有两块屏幕时，一块屏幕全屏放视频，指针碰另一块屏幕的外沿：侧栏正常出现。

**出问题时**：说明是哪个程序、是独占全屏还是窗口化全屏，并附上诊断日志里那段时间的内容（日志位置见第十节）。

## 二、长时间运行后侧栏唤不出或收不起（T86）

**问题是什么**：应用在后台开着很长时间（几个小时到一两天）之后，指针移到屏幕边缘、点托盘图标都唤不出侧栏，只能重启应用；也出现过侧栏展开后收不起来。

**这次做了什么**：没能复现，排查代码后修了几处会让侧栏一直唤不出的情形（侧栏停在屏幕外却算作「显示着」、拿不到焦点时滑入中断、贴边轮询出错后不再工作、自己画标题栏的程序铺满屏幕时被当成全屏），并加了诊断日志。

**步骤与预期**：

1. 照常使用，让应用在后台开一整天，中间电脑可以睡眠、锁屏、插拔显示器。
2. 隔一段时间试一次：指针碰屏幕边缘、点托盘图标、按 Alt+Shift+S。三种方式都应该能唤出侧栏；指针移开后侧栏应该收起（没有固定时）。
3. 如果唤不出，先别重启，按顺序试：
   - 按两次 Alt+Shift+S（侧栏可能「显示着」却停在屏幕外，按一次是收起，第二次才显示）；
   - 右键托盘图标，点「显示侧栏」。

**出问题时**：告诉我是哪种方式唤不出、另外两种行不行、出问题前电脑做过什么（睡眠、锁屏、换显示器、全屏程序），以及诊断日志最后几十行。

## 三、快捷键呼出的窗口不再立刻消失（T87）

**问题是什么**：按 Ctrl+Shift+Space 呼出速记浮窗后，浮窗闪一下就消失；按 Alt+Shift+S 呼出侧栏也一样。原因是开发模式下同一个快捷键注册了两个处理函数，按一次切换了两次，已修复，但没有用真实键盘按过。

**步骤与预期**：

1. 在别的程序里按 Ctrl+Shift+Space：速记浮窗出现并停住，光标在输入框里，可以直接打字。
2. 再按一次 Ctrl+Shift+Space，或按 Esc：速记浮窗收起。
3. 按 Alt+Shift+S：侧栏滑出并停住；再按一次：侧栏收起。
4. 在设置的「快捷键」页把这两个快捷键改成别的组合，再重复 1–3。
5. 用 `pnpm tauri dev` 和安装版各试一遍（问题只在开发模式出现过）。

**出问题时**：说明是开发版还是安装版、哪个快捷键、窗口是闪一下就消失还是根本没出现，并附上诊断日志（日志会记下每次快捷键是「显示」还是「收起」）。

## 四、两块屏幕时侧栏不跟着指针跨屏（T89）

**问题是什么**：有两块屏幕时，指针从一块屏幕划到另一块，经过两块屏幕相接的那条边，侧栏会在那里弹出，收起时又滑进旁边那块屏幕，看起来整个侧栏从一块屏幕跑到了另一块。

**这次的规则**：只有整个桌面最外面的边算边缘。两块屏幕相接的边不算，侧栏只贴在外沿。

**步骤与预期**（按你现在的布局：副屏在主屏左侧，侧栏贴右边）：

1. 指针从主屏慢慢划进副屏、再划回来，来回几次：侧栏不出现。
2. 指针碰主屏的右边缘（整个桌面的最右边）：侧栏在主屏右边滑出；移开后收起，收起时不经过副屏。
3. 在设置里把侧栏改成贴左边，指针碰副屏的左边缘（整个桌面的最左边）：侧栏在副屏左边滑出；碰两块屏幕相接的地方不出现。
4. 侧栏展开时把指针移到另一块屏幕：侧栏照常收起，不会移到那块屏幕上。
5. 只接一块屏幕时，两边都算外沿，贴哪边就碰哪边唤出。

**出问题时**：说明两块屏幕的左右（或上下）位置、各自的缩放比例、侧栏贴哪一边，以及侧栏出现在哪里。

## 五、记录窗口的 Alt+F4（T83）

**已经测过的**：2026-11-18 你离开电脑时，我用系统级鼠标测了标题栏拖到另一个窗口上合并、标签页拖到窗口外拆成新窗口，结果正常；Alt+F4 用向窗口发关闭消息的方式测过，与按键走同一条路。只剩真实按键没有按过。

**步骤与预期**：

1. 从侧栏拖出两张卡片，各成一个记录窗口。
2. 点其中一个窗口让它获得焦点，按 Alt+F4：这个窗口按关闭动画缩回侧栏的卡片（侧栏收着时原地淡出），编辑中的内容先保存；另一个窗口与侧栏不受影响。

**出问题时**：说明窗口是没反应、直接消失没有动画，还是另一个窗口也关了。

## 六、应用图标：托盘与安装版的快捷方式（T85）

**要测的**：设置中换应用图标后，托盘图标与安装版在开始菜单、桌面上的快捷方式图标也跟着换。开发版没有快捷方式，自动化验证也看不到托盘的实际显示，要装一次安装版。安装版与 `pnpm tauri dev` 是同一个应用标识，共用同一份数据，不要同时运行两者；装之前先在「数据与同步」里导出一次备份。

**步骤与预期**：

1. 在仓库目录运行 `pnpm tauri build`，安装 `src-tauri/target/release/bundle/nsis/` 下的安装包（只装给当前用户）。
2. 打开设置的「其它」，换一个内置图标：任务栏、窗口与托盘的图标立刻换成新的；开始菜单里的 SideNotes 与桌面快捷方式的图标也换成新的（资源管理器有图标缓存，可能要过一会儿，或注销重新登录后才显示）。
3. 上传一张图片作为应用图标：托盘与快捷方式换成这张图，托盘里的小图清楚、不糊。
4. 选回默认图标：快捷方式恢复成程序自身的图标。
5. 退出应用再打开：托盘与窗口仍是所选的图标。

**出问题时**：说明哪一处没换（托盘、任务栏、开始菜单、桌面），以及开始菜单快捷方式的位置（右键快捷方式 →「打开文件所在的位置」）。

## 七、展开全文的浮窗（T100）

**要测的**：自动化验证用的是脚本把焦点交给侧栏；2026-11-18 你离开电脑时我用系统级鼠标测过第 1 步与第 3 步里「点侧栏里的另一张卡片」，结果正常。其余几步要用真实鼠标再确认一遍。

**步骤与预期**：

1. 点一张长卡片的「展开全文」：浮窗从卡片旁滑出，带强调色边框，一块渐变的连接带连到卡片（浮窗一边最浓），卡片只有淡淡的细边，按钮变成「收起全文」。
2. 按 Alt+Tab：列表里没有这个浮窗；任务栏上也没有它的按钮。
3. 点侧栏里的另一张卡片、点桌面、点别的程序，各试一次：浮窗缩回卡片，按钮换回「展开全文」。
4. 再展开，点卡片上的「收起全文」：浮窗收回，不会收回后又立刻展开。
5. 再展开，滚动侧栏的列表：连接带跟着卡片走，卡片滚出列表时连接带消失。
6. 再展开，按住浮窗的标题栏拖到别处：连接带消失、强调色边框去掉，浮窗成为普通的记录窗口（出现在任务栏与 Alt+Tab 中、有置顶按钮），之后点别处也不再收回。

**出问题时**：说明是哪一步、浮窗是没收回还是收回后又出现。

## 八、合并与附件弹窗（T99）

**步骤与预期**：

1. 多选几张卡片点「合并」：合并弹窗在屏幕正中出现，标题框里的文字已选中，可以直接改；侧栏保持展开，固定按钮显示为临时固定。
2. 按 Alt+F4：弹窗关闭，侧栏重新获得焦点，选中的卡片还在。
3. 点卡片里的一张图片打开附件弹窗，点「更换」选一张图片、点「另存为」存到桌面：系统的文件对话框出现在弹窗前面，选完后弹窗照常更换或另存。

**出问题时**：说明弹窗出现在哪块屏幕、文件对话框是否被挡住。

## 九、磨砂玻璃的侧栏（T101、T118、T124、T131、T133）

**要测的**：自动化验证时背后是测试窗口与深色的程序窗口。换一张颜色丰富的桌面壁纸（或在背后播放视频）再看一遍。

**步骤与预期**：

1. 设置里切到磨砂玻璃，唤出侧栏：标题区、筛选行、新建卡片、每张卡片与底栏各自是一块磨砂玻璃，块与块之间透出清晰的桌面，没有整块的磨砂底板。
2. 磨砂里透出的颜色与它背后的壁纸位置对得上（块的左上透出的是背后左上那一片的颜色）。
3. 固定侧栏后在背后切换程序或播放视频：Windows 11 上磨砂的颜色立刻跟上（T118），背后的文字与图形在块里化成柔和的色块（T124）；Windows 10 上要等下一次侧栏出来才跟上（截图的做法，T133）。
4. 拖动侧栏边缘调宽、滚动列表：Windows 11 上各块的磨砂跟着块走，卡片之间的缝里是清晰的桌面；Windows 10 上调宽时磨砂略有拉伸，松手后半秒内恢复。
5. 浅色与深色各看一次。
6. 背后换成深色的壁纸与浅色的网页各看一次（T131）：深色主题在深色背景前块很通透，换到浅色网页前一两秒内慢慢变浓，文字始终清楚；浅色主题反过来。
7. 固定侧栏、指针停在侧栏上看半分钟（T133）：侧栏与指针都不闪。

**出问题时**：截一张图，说明背后是什么程序、侧栏是否固定。

## 十、Win+D 与置顶（T106、T113、T120）

**要测的**：Win+D 与任务栏的「显示桌面」不碰固定的侧栏与置顶的记录窗口，它们不闪也不动；置顶或固定的按钮亮着时，窗口真的在最上层。

**步骤与预期**：

1. 拖出两张卡片成为记录窗口，一个置顶、一个不置顶；固定侧栏。按 Win+D：置顶的记录窗口与侧栏一直显示，不闪；不置顶的记录窗口与别的程序一起收起。
2. 再按一次 Win+D：收起的窗口全部回来。
3. 点任务栏最右边的「显示桌面」两次：与第 1、2 步相同。有触摸板时三指下滑、上滑各一次，也一样。
4. 看任务栏与 Alt+Tab：置顶的记录窗口不在里面，不置顶的在；把置顶的取消置顶，它出现，再置顶又消失。
5. 取消侧栏的固定，按 Win+D，再分别用快捷键与指针碰屏幕边缘：侧栏都能唤出。
6. 固定侧栏后点一个最大化的程序：侧栏仍在它上面。打开设置窗口（侧栏临时固定）再点别的程序：侧栏仍在最上面；关掉设置窗口后，侧栏回到原来的固定状态。
7. 记录窗口置顶、取消置顶后各切到别的程序一次：置顶时在最上面，取消后可以被盖住。在置顶的记录窗口里按 Alt+F4：窗口关闭。

**出问题时**：说明是第几步、哪个窗口闪了、被盖住或被收走；看诊断日志里有没有「丢了置顶，已补回」。

## 十一、拖动合并与 Ctrl（T104、T105）

**要测的**：被别的程序挡住的记录窗口不再「幽灵响应」；从侧栏拖卡片出来时被挡住的记录窗口自动提起；拖记录窗口时按住 Ctrl 才找回被挡住的窗口。

**步骤与预期**：

1. 拖出两张卡片成为两个记录窗口，都取消置顶，再打开别的程序把它们盖住。从侧栏拖一张卡片出侧栏：两个记录窗口立刻提到最前，拖动不断，焦点没有离开；放到其中一个窗口上，卡片并进去，这个窗口获得焦点并改为置顶。
2. 让一个不置顶的记录窗口被别的程序盖住，拖另一个记录窗口的标题栏（或标签页）经过它所在的位置：被盖住的窗口没有反应，没有插入线。
3. 拖动中按住 Ctrl：被盖住的窗口原处慢慢出现整个窗口的半透明副本（T126）；指针移进去，窗口浮现到最前、副本淡出；移到它的标题栏上松开，合并进去，合并后的窗口置顶。松开 Ctrl 时副本淡出。

**出问题时**：说明拖的是卡片、标题栏还是标签页，挡住它的是什么程序。

## 十二、全文浮窗、待办勾选与滚动（T108、T109、T114）

**步骤与预期**：

1. 点卡片的「展开全文」：浮窗与卡片顶边对齐；卡片靠近屏幕底部时浮窗与卡片垂直居中。卡片与浮窗之间是一块渐变的连接带，浮窗一边最浓、往卡片渐淡，打开时从卡片一边展开，收回时倒放（T122）。
2. 在卡片、全文浮窗与记录窗口的预览里点待办的方框：勾选状态切换，别的窗口里同一条记录跟着变；点方框不进入编辑、不开始拖动。
3. 打开带「血糖监测报告.pdf」的「长标题测试……」卡片的记录窗口：预览时内容放得下就没有滚动条；双击进入编辑，窗口跟着内容长高，到上限后才能在编辑区里用滚轮滚到最下面（T123）。

**出问题时**：截一张图，说明卡片在屏幕上的位置。

## 十四、浮现、回收站与编辑时的窗口大小（T119、T121、T123）

**步骤与预期**：

1. 拖出两张卡片成为记录窗口，都取消置顶，再打开别的程序把它们盖住。从侧栏拖一张卡片出侧栏：两个记录窗口连同边框与投影一起慢慢淡入、轻轻上浮到最前（约 0.36 秒，T130），不先闪一下，也没有先出现一块深色的底板；拖动不断。
2. 拖动记录窗口时按住 Ctrl，指针移进被盖住的窗口的半透明副本：副本淡出，窗口同样淡入上浮。
3. 在侧栏里拖动卡片：右下角的回收站比以前大一倍，光环与呼吸动画照常。
4. 双击一张短卡片的记录窗口进入编辑，连按回车加十几行：窗口跟着长高，顶边不动，宽度不变；删掉这些行，窗口缩回。窗口碰到屏幕底边时整体往上挪。按 Esc 退出编辑，窗口按预览重新定大小。
5. 拖窗口的边把它拉宽拉高，再进入编辑：内容放得下时窗口不动；加很多行，放不下时才长高；删掉后缩回到你拉的大小。

**出问题时**：说明是哪一步、窗口是闪了、跳了还是大小不对，截一张图。

## 十六、窗口外框、浮现后的次序与全文浮窗（T125、T127、T128、T129）

**步骤与预期**：

1. 五套主题各唤出一次侧栏，浅色、深色各看一次：侧栏四边都没有原生的标题栏、白边或一条白线；终端与记录纸的侧栏是直角，朝屏幕里侧有柔和的投影；Windows 11 的侧栏有圆角、细边框与投影（T125）。
2. 拖出一张卡片成为记录窗口：置顶与取消置顶时都没有白边，四角是圆的，有投影；切换置顶时窗口里的内容不跳。速记浮窗（Ctrl+Shift+Space）、合并与附件弹窗也看一眼。
3. 把置顶的记录窗口从四边与四角拉大拉小：指针移到窗口边缘里面几个像素处变成拉伸的形状，可以拉动。
4. 让一个不置顶的记录窗口被别的程序盖住（点一下那个程序），从侧栏拖一张卡片出来再拖回侧栏松开，指针移开让侧栏收起，再碰屏幕边缘呼出侧栏、移开（T129）：记录窗口一直在那个程序上面；键盘输入仍进那个程序。
5. 点卡片的「展开全文」，指针停在卡片上（T127）：浮窗是强调色边框、标题栏染成强调色、顶上一条强调色线；卡片不变亮，只有淡淡的细边。
6. 打开标题很长的记录窗口（「第三季度产品路线图……」），双击正文进入编辑（T128）：窗口直接长高，中间不闪一条滚动条；内容多到窗口长到上限后，滚动条照常出现。

**出问题时**：截一张图，说明主题、明暗与是第几步。

## 十八、第七轮：标题栏、闪烁、全文浮窗、Ctrl 副本、编辑伸缩与退出（T132–T137）

**步骤与预期**：

1. 切到磨砂玻璃（或 Windows 11、杂志），唤出侧栏，在侧栏、一个置顶的记录窗口与别的程序之间来回点几次（T132）：侧栏与记录窗口的顶上、四边都不出现原生的标题栏或白边。
2. 磨砂玻璃下固定侧栏，指针停在侧栏上看半分钟（T133）：侧栏一直不闪；背后换成浅色的网页时块在一两秒内变浓，换回深色时变回通透。
3. 五套主题各点一次长卡片的「展开全文」，再点「收起全文」（T134）：卡片、连接带与浮窗同时开始变化，浮窗从展开的第一帧起就是强调色边框与高亮的标题栏，展开完成时没有样式跳变；收起时连接带随浮窗一起缩回卡片。快速连点两下「展开全文」只开一个浮窗。
4. 拖出两张卡片成为记录窗口，一个取消置顶并被别的程序盖住；按住 Ctrl 拖动另一个窗口的标题栏经过它（T135）：被盖住的窗口先慢慢淡入成半透明，指针移进去后同一份副本接着变实，整个过程不闪、没有重影。
5. 打开标题很长的记录窗口，双击正文进入编辑、按 Esc 放弃（T136）：窗口平滑地长高、缩回，不出滚动条；编辑中粘贴十几行，窗口平滑长高。拖过窗口边框之后再进入编辑看一次。侧栏里双击一张长卡片进入编辑、按 Esc 退出：卡片高度平滑地变化。
6. 磨砂玻璃下用托盘的「退出」退出（T137）：不弹出系统错误；重新启动后正常。

**出问题时**：截一张图，说明主题、明暗与是第几步；退出报错时记下时间。

## 十九、第八轮：磨砂玻璃的高亮、全文浮窗、设置窗口、拖动边、Ctrl 与拿起、编辑伸缩（T138–T145）

**步骤与预期**：

1. 磨砂玻璃（浅色、深色各一次）：指针移到卡片上、单击一张卡片、双击进入编辑、点新建卡片（T138）：都只有一像素的强调色边框，卡片的边角与下沿、新建卡片下面没有阴影。
2. 五套主题各点一次长卡片的「展开全文」，再点「收起全文」（T139）：浮窗从卡片滑出时就是最后的样子，滑到位后外框、圆角、标题栏都不再变；磨砂玻璃的浮窗是大圆角、背后是模糊的画面，杂志的浮窗四个角上没有多出的弧线；收起时卡片轻轻按下再弹回，左右的边框一直都在。
3. 打开设置窗口，把它最小化（或用别的窗口盖住），再唤出或点击侧栏（T140）：设置窗口回到原来的位置，侧栏仍可以直接输入。
4. 五套主题各把指针停在侧栏朝屏幕内侧的边上（T141）：停一会儿出现一条强调色的线，拖动时一直亮着。
5. 拖出两张卡片成为记录窗口，一个取消置顶并被别的程序盖住；按住 Ctrl 拖动另一个窗口的标题栏经过它（T142）：被盖住的窗口出现半透明的副本，拖到它的标题栏上时副本变实；先松开 Ctrl 再松开鼠标：副本沉下去消失，窗口仍在别的程序下面。再按住 Ctrl 拖到它的标题栏上直接松开鼠标：并进去，窗口浮现到最前。被盖住时从侧栏拖出一张卡片：被盖住的窗口浮现，投影只淡入一次，不闪。
6. 拖出一张卡片成为记录窗口，再从侧栏把同一张卡片拖出来（T143）：卡片一出侧栏，原来的窗口缩进拖影消失，松手后只在松手处有一个窗口；拖出来再拖回侧栏松开：原来的窗口在原处现出来。
7. 长标题的记录窗口与侧栏的长卡片进入编辑、粘贴十几行、按 Esc 放弃（T144）：窗口与卡片平滑地伸缩，先快后慢，没有一顿一顿的感觉。
8. 右键托盘图标（T145）：最后一项是「退出」，点它正常退出。

**出问题时**：截一张图，说明主题、明暗与是第几步。


## 二十、第九轮：全文浮窗、拖动边的线、记录纸的角、Ctrl 松手与托盘菜单（T146–T152）

**步骤与预期**：

1. 五套主题各点一次长卡片的「展开全文」（T148）：浮窗滑到位之后，边框的粗细、连接带与背景都不再变；磨砂玻璃的浮窗从卡片滑出时就是磨砂的，到位后背景不跳、不先变暗。再点「收起全文」（T147）：卡片本身不缩放。
2. 五套主题各把指针停在侧栏朝屏幕内侧的边上，停一会儿再移开（T149）：线淡入、淡出，不是一下子出现；杂志、记录纸、磨砂玻璃的线只在面板旁边，两端随面板的圆角收住，上下留白处没有线。
3. 记录纸主题（浅色、深色）看侧栏朝屏幕内侧的两个角（T150）：圆角外是桌面，没有直线。
4. 拖出两张卡片成为记录窗口，一个取消置顶并被别的程序挡住；按住 Ctrl 拖动另一个窗口，被挡住的窗口显出半透明的副本，不拖到它的标题栏上就松开鼠标（Ctrl 仍按着，T151）：副本像松开 Ctrl 时一样下沉淡出，不是一下子消失。
5. 右键托盘图标（T152）：四项依次是显示侧栏、快捷速记、设置、退出应用，每项前面一个线条图标，「设置」后面没有省略号；系统换成浅色（设置 → 个性化 → 颜色 → 选择模式）后再右键：图标变成黑色。点「退出应用」正常退出。
6. 屏幕缩放不是 150% 的显示器上重复第 1 步（T148）：浮窗到位后边框不变粗、不变细。
