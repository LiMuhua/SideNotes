# 待人工手动确认事项

下面这些行为要用真实的键盘、鼠标、游戏或安装包才能确认，自动化验证做不到或会打扰正在用电脑的人，留给你有空时手动测。每项写明要测什么、怎么测、应该看到什么。测出问题时，把看到的现象和下面「出问题时」要的信息告诉我。

测之前用 `pnpm tauri dev` 启动最新代码（或安装最新的安装包）。

## 一、全屏程序在前台时不贴边唤出（T75）

**要测的**：玩游戏、看全屏视频或放映幻灯片时，指针碰到屏幕边缘不应该弹出侧栏（侧栏会抢走焦点，独占全屏的游戏会被切回桌面）。快捷键与托盘照常能唤出。

**步骤与预期**：

1. 打开一个全屏游戏（独占全屏或无边框全屏都试一下），指针移到侧栏所贴的那一边：侧栏不出现。
2. 同一时间按呼出侧栏的快捷键（默认 Alt+Shift+S）：侧栏出现。
3. 浏览器里按 F11 全屏，或播放器全屏播放视频，再碰边缘：侧栏不出现。
4. 退出全屏后再碰边缘：侧栏正常出现。
5. 普通窗口最大化（任务栏自动隐藏时它也铺满整块屏幕）后碰边缘：侧栏正常出现，不应被当成全屏。
6. 有两块屏幕时，一块屏幕全屏放视频，指针碰另一块屏幕的外沿：侧栏正常出现。

**出问题时**：说明是哪个程序、是独占全屏还是窗口化全屏，并附上诊断日志里那段时间的内容（日志位置见第五节）。

## 二、长时间运行后侧栏唤不出或收不起（T86）

**问题是什么**：应用在后台开着很长时间（几个小时到一两天）之后，指针移到屏幕边缘、点托盘图标都唤不出侧栏，只能重启应用；也出现过侧栏展开后收不起来。

**这次做了什么**：没能复现，排查代码后修了几处会让侧栏一直唤不出的情形（侧栏停在屏幕外却算作「显示着」、拿不到焦点时滑入中断、贴边轮询出错后不再工作、自己画标题栏的程序铺满屏幕时被当成全屏），并加了诊断日志。

**步骤与预期**：

1. 照常使用，让应用在后台开一整天，中间电脑可以睡眠、锁屏、插拔显示器。
2. 隔一段时间试一次：指针碰屏幕边缘、点托盘图标、按 Alt+Shift+S。三种方式都应该能唤出侧栏；指针移开后侧栏应该收起（没有固定时）。
3. 如果唤不出，先别重启，按顺序试：
   - 按两次 Alt+Shift+S（侧栏可能「显示着」却停在屏幕外，按一次是收起，第二次才显示）；
   - 右键托盘图标，点「显示侧栏」。

**出问题时**：告诉我是哪种方式唤不出、另外两种行不行、出问题前电脑做过什么（睡眠、锁屏、换显示器、全屏程序），以及诊断日志最后几十行。

## 三、快捷键呼出的窗口不再立刻消失（T87）

**问题是什么**：按 Ctrl+Shift+Space 呼出速记浮窗后，浮窗闪一下就消失；按 Alt+Shift+S 呼出侧栏也一样。原因是开发模式下同一个快捷键注册了两个处理函数，按一次切换了两次，已修复，但没有用真实键盘按过。

**步骤与预期**：

1. 在别的程序里按 Ctrl+Shift+Space：速记浮窗出现并停住，光标在输入框里，可以直接打字。
2. 再按一次 Ctrl+Shift+Space，或按 Esc：速记浮窗收起。
3. 按 Alt+Shift+S：侧栏滑出并停住；再按一次：侧栏收起。
4. 在设置的「快捷键」页把这两个快捷键改成别的组合，再重复 1–3。
5. 用 `pnpm tauri dev` 和安装版各试一遍（问题只在开发模式出现过）。

**出问题时**：说明是开发版还是安装版、哪个快捷键、窗口是闪一下就消失还是根本没出现，并附上诊断日志（日志会记下每次快捷键是「显示」还是「收起」）。

## 四、两块屏幕时侧栏不跟着指针跨屏（T89）

**问题是什么**：有两块屏幕时，指针从一块屏幕划到另一块，经过两块屏幕相接的那条边，侧栏会在那里弹出，收起时又滑进旁边那块屏幕，看起来整个侧栏从一块屏幕跑到了另一块。

**这次的规则**：只有整个桌面最外面的边算边缘。两块屏幕相接的边不算，侧栏只贴在外沿。

**步骤与预期**（按你现在的布局：副屏在主屏左侧，侧栏贴右边）：

1. 指针从主屏慢慢划进副屏、再划回来，来回几次：侧栏不出现。
2. 指针碰主屏的右边缘（整个桌面的最右边）：侧栏在主屏右边滑出；移开后收起，收起时不经过副屏。
3. 在设置里把侧栏改成贴左边，指针碰副屏的左边缘（整个桌面的最左边）：侧栏在副屏左边滑出；碰两块屏幕相接的地方不出现。
4. 侧栏展开时把指针移到另一块屏幕：侧栏照常收起，不会移到那块屏幕上。
5. 只接一块屏幕时，两边都算外沿，贴哪边就碰哪边唤出。

**出问题时**：说明两块屏幕的左右（或上下）位置、各自的缩放比例、侧栏贴哪一边，以及侧栏出现在哪里。

## 五、诊断日志在哪里

应用把唤出、收起侧栏的经过与出错写进日志文件，只在出错或状态变化时写，平时很少：

- 安装版与 `pnpm tauri dev`：`%LOCALAPPDATA%\com.limuhua.sidenotes\logs\sidenotes.log`
- 超过 1 MB 时，启动时旧文件改名为 `sidenotes.old.log`。

在资源管理器的地址栏粘贴上面的路径即可打开。把出问题前后的几十行发给我。
