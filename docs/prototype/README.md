## 按 Playground 还原样式（2026-11-10）

侧栏、速记浮窗、设置窗口、编辑区、菜单、弹窗与提示条的尺寸、间距、字体与颜色按 [Design Playground](../design-system/playground/README.md) 逐项对齐：两边在无头 Edge 中按五套主题与明暗截图并排比对，并比对对应元素的计算样式。

- 终端主题的界面字体 Maple Mono NF CN 随应用打包，原型引用同一份 `src/styles/fonts.css`；只服务 `docs/prototype/` 时取不到字体，仍要从仓库根目录起服务。
- 新建卡片移到列表之上，不随列表滚动；平时只是一行占位，获得焦点或有内容时才出现工具栏。Ctrl+Enter 保存后侧栏保持展开，焦点留在新建卡片（与现有应用的 T47 一致）；速记浮窗仍是保存即收起。去掉了「置顶」「普通」分组标题。
- 设置窗口：标题栏有最小化与关闭（浏览器原型中最小化与关闭相同）；分类栏、分组卡片、一行几项的竖线、滑块、数值框、开关与按钮按 Playground 排列；外观页的选项卡片用迷你侧栏预览，「跟随系统」写出当前明暗；快捷键分成「全局」「应用内」。
- 补上现有应用已有的三项设置：出入动画（侧栏滑出与收起的时长，0–600 ms）、卡片高度（正文的最大高度，120–600 px）、通知位置（顶部正中、右上角、底部正中）。提示条出现在侧栏窗口里，默认在标题区下方正中。
- 时间、标签与版本号是小号字（`--sn-font-size-xs`），问号与文字按钮按组件规范的字重显示，新建卡片、卡片编辑与速记浮窗的保存是强调色的主要图标按钮。比对中发现 Playground 有两处显示与组件规范不同（外壳的按钮字体规则作用于应用窗口、主要图标按钮没有样式），已在 Playground 中修正，两边都按规范显示。
- 原型没有的内容不补：Playground 快捷键页的「格式」快捷键（原型的编辑器没有实现）、数据页的快照与附件清理。

## 五套主题与设计令牌（2026-11-10）

原型接入 `docs/design-system/` 的设计令牌与五套主题，规范见 [DESIGN.md](../design-system/DESIGN.md)。

- 令牌是唯一来源：页面先引用应用的内置字体（`src/styles/fonts.css`），再引用 `base.css` 与五套主题的令牌文件、旧样式层 [legacy.css](legacy.css)，最后是 [theme.css](theme.css)。旧样式中的颜色都换成了令牌，并放进级联层 `legacy`：`theme.css` 写了的属性一律以它为准，没写的属性仍沿用旧样式。`theme.css` 只引用令牌，按 Playground 的样式补齐各部件。
- 主题与明暗写在根节点的 `data-sn-surface`、`data-sn-theme` 上；令牌表达不了的结构差异写在 `data-sn-dock`（贴边、浮动、分块）、`data-sn-entries`（窗格、卡片、玻璃块）、`data-sn-tabs`（下划线、分段）、`data-sn-translucent`、`data-sn-shortcuts`（快捷键写在界面上或只在提示里）、`data-sn-tab-marks`（页签前的分区色点）上，取值与 Playground 的 `surfaces.ts` 一致（[surfaces.js](surfaces.js)）。组件不区分主题，样式按这些属性选择。
- 设置「外观与交互 › 显示」：明暗模式（浅色、深色、跟随系统）与主题（终端、杂志、记录纸、Windows 11、磨砂玻璃，默认终端）都是单选卡片，预览是用对应令牌画出的迷你侧栏，可以用方向键切换。跟随系统时，系统明暗变化立即生效。
- 字体默认「跟随主题」，选了具体字体时替换界面与正文的字体。字号 12–20（默认 16）就是整页缩放：界面按 13px 设计，缩放到「字号 ÷ 13」倍；侧栏宽度按 13px 字号计。
- 设置结构升到版本 3：旧的 `standard` 改为 `terminal`，无法识别的取值回到终端；旧默认字体（Segoe UI、Maple Mono NF CN）改为跟随主题，用户选过的字体保留。
- 按规范第五节「本次提出的改动」调整：
  - 卡片：时间、置顶标记与操作按钮共用标题行右侧，悬停或选中时操作换下时间，标题最多两行；置顶按钮排第一，最右是收起按钮；带标签时才显示底部一行。悬停与选中用主题强调色的外圈，终端的标题栏同时染色。
  - 选中与编辑：单击与悬停共用一种高亮，双击编辑。编辑中的卡片与获得焦点的新建卡片只换编辑底色，不加强调色边框，记录纸出现横线；输入框获得焦点时底边换成强调色线。
  - 键盘：Tab 进入列表（列表只占一个停靠点），↑ ↓ Home End 移动，Enter 编辑，Delete 移入回收站（先确认），Shift+F10 打开卡片菜单，Ctrl+C 复制选中的卡片，Ctrl+, 打开设置；页签用方向键切换。Esc 依次关闭菜单与弹窗、取消拖动、退出编辑、收起有内容的输入、清除多选、清空搜索，最后收起侧栏。
  - 速记浮窗：快捷键与 Markdown 说明收进标题旁的问号，字数放在附件工具右边；磨砂玻璃的浮窗是一整块玻璃。
  - 设置窗口 960 × 720，同一行的设置项之间用竖线分隔，问号说明只留给需要额外理解的项；滑块与数值框可以用滚轮调整（Shift 加大步长）。
  - 底栏：版本号在左下角，检查到新版本时带更新角标，点开列出即将更新的内容；只在存储出错时显示警告。
  - 提示条在指针停留或获得焦点时暂停计时；标签菜单底部只有「搜索标签」；回收站的保留天数紧跟条数；调试只留「打开开发者工具」。
  - 调整宽度的手柄在指针停留 400ms 后才高亮，也可以用方向键调整（Shift 加大步长），宽度按 4px 取整。
  - 手机形态（宽度不超过 480px）：侧栏铺满屏幕，不显示快捷键、固定与收起按钮，速记浮窗贴在屏幕底部。
- 应用图标：「外观与交互 › 显示」中排在主题之后，6 个内置图标（默认 211）与一个自定义格排成一行，单击即换，方向键切换，名称在悬停或键盘聚焦时提示。自定义格可以上传图片，在「调整应用图标」弹窗中拖动、用滚轮或滑块缩放、用方向键微调，对照托盘、任务栏与桌面三种实际尺寸的浅深预览，选择是否圆角，裁成 256 × 256；上传后可以更换或移除（可撤销）。选中的图标作用于网页图标、页面左上角、侧栏标题区、速记浮窗与关于页。内置图标直接引用 `src-tauri/icons/builtin/` 中随应用打包的资源，清单在 [app-icons.js](app-icons.js)。

## 记录、标签与搜索

首页仅分置顶和普通，默认组内按创建时间倒序；手动排序后使用保存的顺序。今天显示二十四小时时分，其他日期显示完整年月日时分。Emoji 可分类搜索和更换，新建时随机分配未使用的 Emoji。

新增卡片直接输入，Placeholder 分两行，正文随输入增高至上限。侧栏新建继承当前 tab：置顶页自动置顶、归档页保存到归档；独立速记默认进入工作区。侧栏确认按钮只保存，Ctrl+Enter 保存并收起侧栏。双击品牌 Logo 或标题回到顶部。

使用 `#标签` 声明分组，标签原文独立放在正文末尾。卡片底部显示可容纳的全部标签，右侧为其它操作留出空间；“…”展开整理模式并显示悬浮圆形删除按钮。双击标签可就地修改，首次点击外部只退出标签整理，即使点到卡片内部也不会进入正文编辑。

搜索入口位于 tab 右侧，Ctrl+F 展开。支持正文和多个标签组合查询；失焦收起但保留查询，图标旁按关键词自适应显示，过长时省略并悬浮提示全文。标签快捷菜单最多六项，按访问频率、最近访问、记录数量和置顶情况评分；超出提示使用搜索。当前搜索标签优先出现并可管理。

## Markdown、附件和复制

支持标题、强调、删除线、代码、列表、可交互任务、引用、链接、分隔线及图片。卡片正文限高，长内容省略并可展开；正文标题字号受卡片排版约束。

侧栏、速记和卡片编辑均使用实时 Markdown。光标进入被标记包裹的内容时显示完整暗色原始标记，其它内容保持渲染；任务和图片控件可以直接操作。保留原文、CRLF、选区与撤销重做。文件引用示例放在独立卡片，不写入新增草稿；完整复制链接保留左方括号。

新增入口和卡片支持拖入图片、文件及外部选中的文本；编辑时按选区或拖放光标插入。卡片拖入失败时保留到新增草稿，异步读取不覆盖继续输入的内容。图片可预览、移除和粘贴，单张最多 2 MB、每条最多 12 张；不递归读取目录。

网页无法取得普通文件的完整原路径时使用 `sidenotes-file:` 引用，选择的文件在本会话可读取，刷新后需重新定位。文件句柄可以验证可读性；普通副本标记原路径未验证，不伪装成已调用系统默认应用。

双击非编辑卡片复制 Emoji、正文和引用，支持时写入纯文本、HTML，以及含图记录的 PNG 表示。文件附件提供重新定位、真实副本下载或支持环境中的系统分享。**Windows 原生文件剪贴板及微信附件粘贴仍未实现/未实测**，已记录 [CLIP-001](../begin/implementation-gaps.md#clip-001)，不得以路径或下载替代验收。

## 布局与设置

## 原型与原生能力边界

浏览器存储、标签、Markdown、附件读取和备份 JSON 为实际浏览器流程。系统字体、目录选择、文件句柄与通知取决于浏览器支持及用户授权。

云服务尚未连接：当前仅配置验证和模拟备份，本地防抖生成另一份浏览器快照，未上传云端。目录设置仅作桌面配置预览，当前数据实际仍在浏览器。系统文件剪贴板、全局热键、托盘、SQLite、多屏 DPI 与原生文件跳转属于后续桌面实现。

以下为浏览器中的模拟，待原生验证：Windows 11 与磨砂玻璃的半透明用 CSS `backdrop-filter` 模拟，只能模糊页面中的模拟桌面，真实应用需要透明窗口与 Acrylic；全局快捷键只在页面获得焦点时生效；「打开开发者工具」与「立即更新」只弹出提示；系统文件选择取决于浏览器支持。上传的应用图标保存在浏览器本地存储的单独键中，不进入导出的备份（桌面版保存在应用数据目录）；原型没有模拟任务栏与托盘，图标只作用于页面中的品牌标记、网页图标与关于页。
