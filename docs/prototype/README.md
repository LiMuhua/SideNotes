# SideNotes 交互原型 0.7.4

更新日期：2026-11-14。入口：[index.html](index.html)。原生 HTML、CSS、JavaScript，无需构建或联网；样式直接引用 [设计令牌](../design-system/tokens/)。

原型与 Playground 由同一个开发服务器提供，地址去掉了 `docs` 一层。在仓库根目录执行：

```bash
pnpm playground
```

命令会在浏览器打开原型 `http://localhost:1430/prototype/`；Playground 在 `http://localhost:1430/design-system/playground/`。两边可以互相跳转：原型左上角品牌区的「Design Playground ↗」，Playground 顶栏最右边的「交互原型 ↗」。地址改写在 `vite.config.ts` 的 `sidenotes-design-playground` 插件中；服务目录仍是仓库根目录，原型引用的内置字体（`src/styles/fonts.css`）与应用图标（`src-tauri/icons/builtin/`）都在 `docs` 之外。不起服务时直接用浏览器打开 index.html 也可以，修改后刷新页面。

请固定同一个浏览器与访问地址；file、localhost、不同端口使用不同存储。2026-11-11 地址从 `http://127.0.0.1:1431/docs/prototype/` 换到 `http://localhost:1430/prototype/`，浏览器把它当作新地址，旧存档不会自动出现：先在旧地址的设置中导出 JSON 备份，再到新地址导入。保留旧记录与草稿，不重置用户存档。

## 按第五次反馈改进（2026-11-15）

用户用标注截图提出，验收清单见[任务](../tasks.md) DS06，设计决定见[技术决策](../decisions.md) DS-12。

- 搜索：
  - 搜索全部记录（不含回收站），与当前在哪个页签无关；写完整的已有标签只搜这个标签，没写完的按前缀。
  - 结果按页签分组，组标题写页签名与条数，右侧「转到」；卡片菜单最上面是「转到「X」」，切过去、滚到这条并闪一下。搜索时页签栏不标出当前页签，新建卡片收起，搜索框里写结果的条数；结束搜索回到原来的页签与位置。
  - 只搜一个已有标签时，搜索框里有「固定为页签」「合并」（修正：此前搜索标签时这两个按钮不出现）。
- 筛选行（侧栏顶部保持两行）：搜索从页签栏移到页签下面一行的右端，展开时铺满这一行；左边的标签下拉选了标签时写「# 产品 · 2 条」，× 清除，后面是「固定为页签」「合并」。Esc 依次清除搜索与标签筛选，再点一下当前页签也清除。
- 移入回收站不再确认，提示条可以撤销；多选时菜单与 Delete 键移入全部选中的记录。多选菜单的「合并到这条」改写为「合并到「标题」」。
- 页签：最后一格菜单里的页签可以拖动排序、拖到页签栏；栏里的页签停在最后一格 0.6 秒后可以放进菜单。新建页签面板的输入框铺满面板（此前被旧样式限制在 140px 宽）。
- 在标签页签里去掉新建卡片上的「#标签」后保存，提示「已记在「随记」」并可「查看」「放回」；新记录因为别的原因不在当前页签时也提示记在了哪里。
- 置顶卡片默认带淡的强调色边框，比悬停暗。
- 附件：拖动图片与文件时拖影的左上角跟着指针，垫在编辑区的文字下面；文件附件弹窗恢复「Markdown 原文」与「应用修改」（此前示例的 file:/// 地址找不到原文），不留空白。
- 设置：关于页从上往下排，「检查更新」在版本号旁，项目与开源致谢是铺满整行的等宽块，致谢写许可证；「其它」两行两列，「窗口标签页」默认左侧并有问号说明。
- 记录窗口：Shift+Esc 关闭整个窗口，Esc 照旧逐页关闭。
- Playground 同步了上述改动中的样式与关键功能（全局搜索、筛选行、回收站、提示、置顶边框、合并菜单、关于页与「其它」），拖动、附件弹窗与记录窗口操作写在[交互规范](../design-system/interactions.md)。

## 按第四次反馈改进（2026-11-14）

按用户确认的方案新增两项功能，并调整设置窗口、附件与记录窗口，设计决定见[技术决策](../decisions.md) DS-11，验收清单见[任务](../tasks.md) DS05。

- 页签：
  - 「工作区」改名「随记」，去掉「归档」。随记显示没有任何已固定标签的记录，置顶照旧。旧的归档记录回到随记，正文加上 #归档。
  - 标签可以手动固定成页签：按标签筛选时点筛选条上的「固定为页签」，或在页签栏最后一格的菜单里点「新建页签」（输入时联想已有标签）。不会自动出现页签。
  - 双击页签原地改名，所有记录上的这个标签一起改；按住拖动排序，插入线标出位置；右键「改名」「移出页签栏」，移出只是不再固定，可以撤销。
  - 页签上不写 #，名称超过 4 个字截断；条数只写在随记与当前页签上。
  - 放不下的页签从右往左收进最后一格「N ▾」。选中收起的页签时前面的页签不动，最后一格显示它的名称并带当前样式；单击最后一格打开菜单（收起的页签与「新建页签」，收起的页签右键可以放回页签栏）。
  - 卡片拖到标签页签上加上这个标签（从别的标签页签来时换掉原来那个），拖到随记去掉当前页签的标签，拖到置顶只置顶；拖到最后一格停 0.6 秒展开菜单，可以放进收起的页签。卡片菜单的「归档」换成「移到…」。
  - 在标签页签中新建记录时，新建卡片的工具栏上有一个「#标签」，保存时写进标签行，点 × 可以不带。
- 合并成一条：
  - 入口：按标签筛选时筛选条上的「合并」；多选后右键「合并成一条…」；多选后右键其中一张「合并到这条」。
  - 共同标签作标题，其余标签各成一个二级小节（只有共同标签的放在最前，带多个其他标签的合成一节，例如「装修 · 日常」）；只有一行的记录合成待办，多行的整段放入；标签取并集。合并到已有卡片时按小标题追加。
  - 弹窗有标题、格式（清单或段落）、实时预览与「保留原记录」。合并后新卡片在原来第一条的位置并进入编辑，原记录移到回收站，提示条一次撤销全部恢复。
- 设置窗口：高度固定（560，不随分类跳动），内容多的分类在页面里滚动；页面外面不再套一层边框，窗口左右分成两栏（左栏是「设置」与分类，用窗口底色；右栏是页面，用表面色）。回收站为空时提示在空出的地方居中，关于页上下居中。手机形态下仍铺满屏幕。
- 附件：编辑面中拖动图片或文件，插入光标落在字符之间，松开后移到这个位置（不再只按行）；原来那一行空了就删掉。文件附件的弹窗去掉上方的预览，图片保留。
- 记录窗口：
  - 有标签页时窗口按标签页定宽，上限放宽到 720；关闭按钮只在当前页和悬停时浮在右端，平时把位置让给标题；标题仍放不下时省略，悬停片刻显示全名。
  - 标签页可以放在左侧竖排：窗口标题栏上的按钮切换，也可以在「设置 › 外观与交互 › 其它 › 窗口标签页」中切换。竖排时标题栏写当前标题，拖动排序、合并与拆出照常，插入线是横线。
- 跳转：品牌区「交互原型 0.7.4」之后一个「Design Playground ↗」链接；`pnpm playground` 默认打开原型。
- 同步到 Playground（连同第三次反馈的改动）：设置窗口、页签与合并成一条、多选拖动的一叠卡片、记录窗口的样式示例，见 [Playground 说明](../design-system/playground/README.md)。Playground 主要示范样式与关键功能，细致的交互写在[交互规范](../design-system/interactions.md)；拖动相关的操作只在原型中实现。

## 按第三次反馈改进（2026-11-11）

按用户当天的第三次反馈（9 项）调整，设计决定见[技术决策](../decisions.md) DS-10。当时只改交互原型，2026-11-14 与第四次反馈一起同步到 Playground。

- 多选拖动：拖影是一叠真实的卡片。抓住的那张在最上面，后面两层是另外两张选中卡片的副本，往右上错开、转开一点，露出它们的标题栏；开始拖动时，列表中看得见的选中卡片飞进这一叠；右上角写条数。
- 记录窗口：
  - 大小按内容决定，宽高都是：短的记录窗口窄一些（最窄 280），长段落折到 560，高不超过 600 与视口的六成，按 13px 字号计；正文四周留白相同。
  - 标签栏比单页的标题栏高，标签页之间留出间距；标签栏右侧一块空白，按住可以拖动窗口，标签页多了在左边横向滚动（滚轮可用）。
  - 拖动标签页、窗口标题栏或侧栏的卡片到窗口上时，标签栏里一条竖线（上端一个小圆点）标出松开后的位置，目标窗口的标题栏换成浅强调色；在本窗口里放回原处不显示。标签页拖到窗口外时拖影放大，松开后拆成的新窗口与从侧栏拖出的一样从拖影展开、默认置顶。
  - 关闭时与打开呼应：拖出的窗口先轻轻提起，再缩到卡片的大小、倾斜成拖影的样子落向原来的卡片，落下时摆正淡出，卡片轻轻一顿；时长与缓动与打开相同。「展开全文」的窗口原路滑回。卡片看不见时原地提起、倾斜着淡出。
  - 获得焦点的窗口：边框带一点强调色，外面再淡淡一圈；置顶时图钉是实心的，与没置顶的空心图钉分开。
- 编辑器：
  - 双击卡片（或在记录窗口中双击正文）进入编辑时，光标在正文末尾（标签行之前），不在标签行末尾。
  - 点工具栏的图片、文件按钮，附件插在原来的光标处（此前编辑区失焦后选区被重置，总插在开头）；光标在卡片的标题行或 Markdown 标题行上时，作为单独一行插在这一行之后，标题不变；在标签行上或之后时仍插在标签行之前。拖入与粘贴的文件按同样的规则插入。
  - 编辑面中的图片与文件块可以按住拖动：移动 4 像素后开始，拖影与卡片拖影同样倾斜，插入线落在行与行之间，松开后整块移成单独一行（第四次反馈改为落在字符之间）；不能放到标题行之前或标签行之后；Esc 取消，Ctrl+Z 撤销。
  - 附件弹窗：Markdown 原文完整显示在一个整行的大输入框里，随内容加高、长地址折行，没有滚动条；修改原文时上方的预览跟着变（文件名、图片，或不再是附件时按卡片排版显示），点「应用修改」或按 Ctrl+Enter 才写入；「应用修改」是底栏右侧的主要按钮，原文没改时不可用，打开、更换、另存为与删除在左侧；弹窗加宽到常规弹窗的 1.3 倍（第四次反馈：文件附件去掉预览）。
  - 修正：正文中的图片刷新后又出现在缩略条里（读取存档时丢了 inline 标记）；读取时按正文补上标记，之前保存的数据也能恢复。
- 设置窗口：
  - 页面有最大宽度（弹窗宽度的 1.6 倍，居中，与 Playground 相同）：字号 12 时页面不再铺满整个面板；明暗模式与主题两行卡片铺满名称右侧的一栏，右边与下面的滑块、数值框和字体预览对齐。
  - 高度随内容：最高 600，外观与交互、数据与同步在页面里滚动；快捷键、回收站、关于等内容少的分类窗口跟着变矮，最矮 360。上边固定，切换分类时标题栏不动（第四次反馈改为固定高度 560）。手机形态下设置窗口仍铺满屏幕（[布局规范](../design-system/layout.md)第七节），不用这条规则。
  - 设置中的操作（双击复制路径、恢复与永久删除记录、改快捷键等）的提示条出现在设置窗口里，位置按「通知位置」，大小与侧栏的提示条相同，不再落到侧栏。

## 按第二次反馈改进（2026-11-11）

按用户当天的第二次反馈（17 项）调整，设计决定见[技术决策](../decisions.md) DS-9。

- 服务：原型与 Playground 都由 `pnpm playground`（端口 1430）提供，地址是 `/prototype/` 与 `/design-system/playground/`。Python 静态服务不能编译 Playground 的 TSX，只服务 `docs` 时也取不到原型引用的字体与图标，所以改用同一个 Vite 服务；原来的 `/design-playground` 不再使用。
- 卡片：
  - 高亮了卡片而焦点不在卡片上时（悬停高亮、编辑或菜单结束后），↑ ↓ 同样移动高亮，Enter 开始编辑。
  - 编辑中的卡片只有一圈强调色边框：不再叠加悬停时的外圈，窗格的标题栏也不画顶部的强调色线。
  - 拖影倾斜加大到 2.5°；多选拖动时，拖影后面叠着一两张卡片的边，右上角写条数（第三次反馈改为一叠真实卡片的副本）。拖出侧栏时拖影保持倾斜。
- 编辑器：
  - 列表与待办的光标不能停在项头之前：点到复选框左边、按 Home 或从上一行移下来时都落到正文开头，在正文开头按 ← 跳到上一行末尾。
  - 编辑中的待办方框与文字的中线对齐，勾选前后不上下跳。
  - Ctrl+U 的下划线 `<u>…</u>` 在编辑面与卡片中都显示为下划线（与现有应用一致），不再露出标签。
- 新建卡片的工具栏一直显示，不随焦点收起展开，也去掉了收起按钮；点工具栏的空白处时焦点留在输入区。
- 记录窗口：
  - 窗口大小按内容决定，留一点白，长文不超过视口的七成高（第三次反馈改为宽高都按内容、不超过六成高）；当前操作的窗口边框带一点强调色。
  - 拖出侧栏的窗口默认置顶，置顶按钮显示为按下；窗口从倾斜的拖影展开、摆正后落定。
  - 关闭时窗口缩小并滑回侧栏中原来的卡片，卡片看不见时原地淡出（第三次反馈改为与打开呼应）。
  - 标签页：多选拖出的几条放进同一个窗口；卡片拖到已开的窗口上、窗口标题栏拖到另一个窗口的标题栏上、标签页拖到另一个窗口，都会合并成标签页；标签页拖到窗口外拆成新窗口，在标签栏里拖动调整顺序。Esc 关闭当前标签页，只剩一个时关闭窗口。
  - 新增快捷键「关闭全部记录窗口」，默认 Alt+Shift+W，可在设置中更换（浏览器保留了 Ctrl+W 与 Ctrl+Shift+W）。
- 附件：
  - 图片与文件一样写进正文，插在光标处；光标在标签行或它之后时，插在标签行之前，标签行始终在最后。正文中的图片写作 `![名称](sidenotes-image:标识?name=名称)`，图片内容仍随记录保存（浏览器不能把文件复制到数据目录）；旧记录里不在正文中的图片仍显示在缩略条中。
  - 编辑面中拖动图片、文件或选中的文字，落在同一个编辑面时是移动，不再复制一份（第三次反馈：图片与文件改为按住拖动，插入线落在行与行之间）。
  - 卡片、记录窗口与编辑面中显示缩略图：整张图按比例缩小，最高 150；大图显示缩小的副本，点开附件弹窗才加载原图。
  - 正文中的图片与文件都在附件弹窗中显示 Markdown 原文，可以修改。
- 设置：
  - 字号 8–24、步长 0.5、默认 12。
  - 设置窗口回到现有应用的 880 × 720。明暗模式与主题两行卡片的总宽相同，比整行窄（第三次反馈：高度随内容、最高 600；页面有最大宽度，两行卡片铺满一栏。第四次反馈：高度固定 560）。
  - 按钮、下拉框、输入框与回收站的搜索框改用常规尺寸；回收站页按搜索快捷键（默认 Ctrl+F）聚焦搜索框。
  - 路径只占一行，放不下时末尾省略，悬停显示完整路径，双击复制；当前目录与快照目录的按钮紧跟在路径之后。
  - 快照按现有应用排版：快照目录一行，已有快照（份数与附件统计）与立即创建一行，下面是带边框的快照列表，一行一份。

## 按反馈改进（2026-11-11）

版本号比现有应用 0.7.3 高一版，改为 0.7.4。按用户的 24 项反馈调整，设计决定见[技术决策](../decisions.md) DS-8。

- 两条最高优先级的设计规则：避免不必要的二次标签和描述，让布局来解释；提示浮窗只写最客观的操作。按钮、卡片与标题区不再有悬停提示，名称只写在 `aria-label` 中；悬浮说明只跟问号绑定，「列表加载」补上问号。问号说明、下拉列表、字体候选与应用图标的大图预览挂在 body 下的独立一层（[layer.js](layer.js)），不被设置页裁剪或遮挡，也不撑出滚动条。说明里写的未完成事项与浏览器限制移到本文与[已知问题](../known-issues.md)。
- 卡片：编辑中的卡片保留与悬停、选中相同的高亮；进入编辑时把卡片滚到列表顶部（设置「编辑时滚到顶部」，默认打开）；搜索展开时点卡片区域，搜索框正确失焦并收起；新建卡片与列表中的卡片同宽，列表始终留出细滚动条的位置，滚动条放在右侧的内边距里；标签整理时的移除按钮缩成右上角的小圆点。
- 拖动排序按设计系统显示：拖影是卡片本身的副本，向右错开、倾斜、浮起；插入线左端一个小圆点，不再写说明文字。
- 记录窗口（[note-window.js](note-window.js)）：卡片拖出侧栏，松开后在那里打开一个可以移动、缩放与置顶的窗口，窗口从拖影的位置展开、摆正后落定；点「展开全文」时窗口从卡片的位置向桌面一侧滑出并放大。两种入口共用一个组件；双击正文编辑，Ctrl+Enter 或点到窗口外保存，Esc 取消编辑或关闭窗口；双击标题栏放大或还原。
- 编辑器：列表与待办的项头不再随光标露出（勾选复选框、光标停在正文开头时都不显示 `- [ ]`），光标在正文开头按退格删去项头。格式快捷键、回车续写列表、Tab 与 Shift+Tab 缩进、智能粘贴与 Ctrl+Shift+V 纯文本粘贴接入现有应用的编辑命令（[markdown-commands.js](markdown-commands.js)）。
- 附件对齐现有应用：单击附件打开附件弹窗（预览、Markdown 原文、打开、更换、另存为、删除，卡片中的改动可撤销），按住 Ctrl 单击直接打开；编辑面中的图片与文件引用整块显示，退格按整个引用删除，点开附件弹窗不退出编辑；粘贴的截图改名为「截图-年月日-时分秒」；粘贴文件与「引用文件」直接插在光标处；缩略图 70 × 55，编辑中 64 × 49。
- 其它对齐现有应用的行为：复制只写纯文本，提示「已复制-标题」；新建记录后不改动搜索、筛选与滚动位置，提示「记录已保存」；归档提示「已归档」；内容没变时退出编辑不写库，清空正文时恢复原文；导出 Markdown 的文件名是 Emoji 加首行；底栏只在出错时显示状态；版本弹窗只列本版要点。
- 设置：
  - 外观与交互：明暗模式的三张卡片与主题卡片同宽（第二次反馈改为两行总宽相同）；字号 9–16、步长 0.5、默认 12（第二次反馈改为 8–24）；侧栏默认宽 400；去掉「编辑时保持展开」（编辑期间一律保持展开）；「移出后收起」可以输入 100–10000 毫秒，下拉列出常用值；应用图标的说明只写「标题区、速记浮窗、关于页与网页图标都换成选中的图标」，悬停图标时在上方显示大图预览。
  - 快捷键：按现有应用与 Playground 分成全局、应用内、格式三组，点击按键后按下新的组合即可更换，冲突时在按键旁写出原因，可以逐项或全部恢复默认（[shortcuts.js](shortcuts.js)）。
  - 数据与同步：按 Playground 分成数据目录（存储位置、附件、迁移到、当前目录）、快照（目录、立即创建、列表与恢复）、导入与导出、云端自动备份四组；快照保存在浏览器中，导入、永久删除、迁移与恢复之前各创建一份。
  - 回收站：搜索与筛选用 Playground 的下拉框，文字靠左、箭头紧跟；保留天数紧跟条数，是一个可输入的组合框。
  - 关于：标语改为「藏在屏幕边上的速记本」；支持项目改为链接。

## 五套主题与设计令牌（2026-11-10）

原型接入 `docs/design-system/` 的设计令牌与五套主题，规范见 [DESIGN.md](../design-system/DESIGN.md)。

- 令牌是唯一来源：页面先引用应用的内置字体（`src/styles/fonts.css`），再引用 `base.css` 与五套主题的令牌文件、旧样式层 [legacy.css](legacy.css)，最后是 [theme.css](theme.css)。旧样式中的颜色都换成了令牌，并放进级联层 `legacy`：`theme.css` 写了的属性一律以它为准，没写的属性仍沿用旧样式。`theme.css` 只引用令牌，按 Playground 的样式补齐各部件。

## 记录、标签与搜索

首页仅分置顶和普通，默认组内按创建时间倒序；手动排序后使用保存的顺序。今天显示二十四小时时分，其他日期显示完整年月日时分。Emoji 可分类搜索和更换，新建时随机分配未使用的 Emoji。

新增卡片直接输入，Placeholder 分两行，正文随输入增高至上限。侧栏新建继承当前 tab：置顶页自动置顶、归档页保存到归档；独立速记默认进入工作区（2026-11-14 起：标签页签中新建时带上这个标签，速记浮窗进入随记）。侧栏确认按钮只保存，Ctrl+Enter 保存并收起侧栏。双击品牌 Logo 或标题回到顶部。

使用 `#标签` 声明分组，标签原文独立放在正文末尾。卡片底部显示可容纳的全部标签，右侧为其它操作留出空间；“…”展开整理模式并显示悬浮圆形删除按钮。双击标签可就地修改，首次点击外部只退出标签整理，即使点到卡片内部也不会进入正文编辑。

搜索入口位于 tab 右侧，Ctrl+F 展开。支持正文和多个标签组合查询；失焦收起但保留查询，图标旁按关键词自适应显示，过长时省略并悬浮提示全文。标签快捷菜单最多六项，按访问频率、最近访问、记录数量和置顶情况评分；超出提示使用搜索。当前搜索标签优先出现并可管理。

## Markdown、附件和复制

支持标题、强调、删除线、代码、列表、可交互任务、引用、链接、分隔线及图片。卡片正文限高，长内容省略并可展开；正文标题字号受卡片排版约束。

侧栏、速记和卡片编辑均使用实时 Markdown。光标进入被标记包裹的内容时显示完整暗色原始标记，其它内容保持渲染；任务和图片控件可以直接操作。保留原文、CRLF、选区与撤销重做。文件引用示例放在独立卡片，不写入新增草稿；完整复制链接保留左方括号。

新增入口和卡片支持拖入图片、文件及外部选中的文本；编辑时按选区或拖放光标插入。卡片拖入失败时保留到新增草稿，异步读取不覆盖继续输入的内容。图片可预览、移除和粘贴，单张最多 2 MB、每条最多 12 张；不递归读取目录。

网页无法取得普通文件的完整原路径时使用 `sidenotes-file:` 引用，选择的文件在本会话可读取，刷新后需重新定位。文件句柄可以验证可读性；普通副本标记原路径未验证，不伪装成已调用系统默认应用。

双击非编辑卡片复制 Emoji、正文和引用，支持时写入纯文本、HTML，以及含图记录的 PNG 表示。文件附件提供重新定位、真实副本下载或支持环境中的系统分享。**Windows 原生文件剪贴板及微信附件粘贴仍未实现/未实测**，已记录 [CLIP-001](../begin/implementation-gaps.md#clip-001)，不得以路径或下载替代验收。

## 布局与设置

侧栏边缘可拖动调整 360–720px，手动收起解除固定，也可用 `Alt + Shift + S` 呼出。新建卡片由不透明粘性底板固定在记录列表顶部，正文滚动不会带走输入入口，也不会在圆角处透出滚动卡片。默认按需加载，每批 10 条、接近底部立即追加，不重建已有卡片；加载与整理提醒位于“外观与交互”末尾“其它”组，左右紧凑同排，可关闭或设置每批 5–100 条。工作区默认超过 50 条提醒整理，可调整、关闭或忽略 7 天；不自动处理内容。

## 原型与原生能力边界

浏览器存储、标签、Markdown、附件读取和备份 JSON 为实际浏览器流程。系统字体、目录选择、文件句柄与通知取决于浏览器支持及用户授权。

云服务尚未连接：当前仅配置验证和模拟备份，本地防抖生成另一份浏览器快照，未上传云端。目录设置仅作桌面配置预览，当前数据实际仍在浏览器。系统文件剪贴板、全局热键、托盘、SQLite、多屏 DPI 与原生文件跳转属于后续桌面实现。

以下为浏览器中的模拟，待原生验证：Windows 11 与磨砂玻璃的半透明用 CSS `backdrop-filter` 模拟，只能模糊页面中的模拟桌面，真实应用需要透明窗口与 Acrylic；全局快捷键只在页面获得焦点时生效；「打开开发者工具」与「立即更新」只弹出提示；系统文件选择取决于浏览器支持。上传的应用图标保存在浏览器本地存储的单独键中，不进入导出的备份（桌面版保存在应用数据目录）；原型没有模拟任务栏与托盘，图标只作用于页面中的品牌标记、网页图标与关于页。
