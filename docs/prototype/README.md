# SideNotes 交互原型 0.5.0

更新日期：2026-10-21。入口：[index.html](index.html)。原生 HTML、CSS、JavaScript，无需构建或联网。直接用浏览器打开；修改后刷新页面。也可以在本目录执行 `python -m http.server 4173 --bind 127.0.0.1`，访问 [本地预览](http://127.0.0.1:4173)。

请固定同一个浏览器与访问地址；file、localhost、不同端口使用不同存储。保留旧记录与草稿，不重置用户存档；设置中可导出 JSON 备份。

## 本轮更新

- 编辑输入失焦自动保存并退出，保持侧栏展开。Esc 丢弃当前编辑，Ctrl+Enter 保存退出；编辑工具、附件选择和输入法组合期间保护当前事务，结束后补做失焦检查，保存失败保留修改。
- Esc 先退出确认弹窗、菜单、拖动、标签整理、搜索、编辑或多选，最后才收起窗口。搜索收起保留关键词与筛选，使用展开动画的反向平移，移除旋转。
- 侧栏从隐藏变为显示时聚焦新增卡片的真实 Markdown 输入面，展开后复核；已固定侧栏重新获得窗口焦点，或点击页面外后再点回侧栏空白处，也会回到新建输入，并保留当前滚动位置。编辑、搜索、设置弹窗或拖动期间不抢焦点。
- 长按卡片 300ms 拖动排序，允许鼠标在长按前移动；支持拖动整批选中记录及边缘自动滚动，松开不触发编辑或复制。跨组落位继承目标组；顺序随存档保存。
- 从列表空白边缘或卡片间隙拖框选择，也可用 Ctrl 点击、Shift 区间选择和 Ctrl+A。选择不使用额外工具条或勾选按钮；点击空白处或按 Esc 均可退出选择。拖动所选卡片到 Tab 可跨页继续排序，拖到右下角红色回收站可批量移入回收站。
- 右下角“…”和卡片右键共用快捷菜单，支持编辑、复制、展开/折叠、置顶、归档、副本、导出、信息及回收站；提供键盘导航和视口边界处理。点击右上角时间也可折叠正文，折叠后保留标题行和操作行。
- 外观配置改为左侧标签、右侧控件；侧栏组前三项同排、宽度独立第二行，宽度滑块步进为 4 px。快捷键“记录/浏览”两栏排列。滑块旁数值可以直接输入，Enter 或失焦提交，Esc 还原，按范围与步长校正。
- 自动备份开关紧跟说明按钮；群晖 NAS、Google Drive 与 OneDrive 使用各自品牌图形，不再统一使用云朵图标。
- 快捷键新增 `Alt + Shift + S` 呼出侧栏，隐藏状态下也可使用；呼出后直接聚焦新建输入。记录列表滚动时，新建卡片通过完整矩形粘性底板固定在顶部，圆角外侧不会透出下方滚动内容。
- 侧栏组统一使用 11 px、500 字重和 18 px 行高的完整字体规则，“编辑时保持展开”不再出现字符视觉大小不一致。
- 字体下拉框不再随输入过滤候选，也不截断前 80 项；输入仅用于追加自定义字体名，候选列表滚动时始终保留全部字体。
- 回收站保留天数使用紧凑的预设和自定义输入，范围 1–365 天，默认 30 天。单条和批量恢复、彻底删除均需确认；取消保留原分类、搜索和滚动位置。
- 速记浮窗同步实时 Markdown、图片/文件工具、拖放及图标确认。确认按钮保存后保持浮窗展开，Ctrl+Enter 保存并收起浮窗；两个入口继续共享草稿。
- 搜索展开只保留一个清空按钮；收起后按关键词文本自适应宽度，长关键词最大 176 px 并以省略号显示，悬浮提示完整内容。
- 拖动排序增加贯穿列表的插入线和“松开后放到…”状态，拖到列表上下边界外仍会选择当前可见列表的首尾落点，不再要求指针精确命中某张卡片。
- 列表加载与整理提醒移到“外观与交互”最后一组“其它”，左侧加载、右侧提醒；紧凑数值框与单位共用控件外壳。快捷键页移除双击复制、长按排序、框选多选和 Esc 等默认行为条目。

## 记录、标签与搜索

首页仅分置顶和普通，默认组内按创建时间倒序；手动排序后使用保存的顺序。今天显示二十四小时时分，其他日期显示完整年月日时分。Emoji 可分类搜索和更换，新建时随机分配未使用的 Emoji。

新增卡片直接输入，Placeholder 分两行，正文随输入增高至上限。侧栏新建继承当前 tab：置顶页自动置顶、归档页保存到归档；独立速记默认进入工作区。侧栏确认按钮只保存，Ctrl+Enter 保存并收起侧栏。双击品牌 Logo 或标题回到顶部。

使用 `#标签` 声明分组，标签原文独立放在正文末尾。卡片底部显示可容纳的全部标签，右侧为其它操作留出空间；“…”展开整理模式并显示悬浮圆形删除按钮。双击标签可就地修改，首次点击外部只退出标签整理，即使点到卡片内部也不会进入正文编辑。

搜索入口位于 tab 右侧，Ctrl+F 展开。支持正文和多个标签组合查询；失焦收起但保留查询，图标旁按关键词自适应显示，过长时省略并悬浮提示全文。标签快捷菜单最多六项，按访问频率、最近访问、记录数量和置顶情况评分；超出提示使用搜索。当前搜索标签优先出现并可管理。

## Markdown、附件和复制

支持标题、强调、删除线、代码、列表、可交互任务、引用、链接、分隔线及图片。卡片正文限高，长内容省略并可展开；正文标题字号受卡片排版约束。

侧栏、速记和卡片编辑均使用实时 Markdown。光标进入被标记包裹的内容时显示完整暗色原始标记，其它内容保持渲染；任务和图片控件可以直接操作。保留原文、CRLF、选区与撤销重做。文件引用示例放在独立卡片，不写入新增草稿；完整复制链接保留左方括号。

新增入口和卡片支持拖入图片、文件及外部选中的文本；编辑时按选区或拖放光标插入。卡片拖入失败时保留到新增草稿，异步读取不覆盖继续输入的内容。图片可预览、移除和粘贴，单张最多 2 MB、每条最多 12 张；不递归读取目录。

网页无法取得普通文件的完整原路径时使用 `sidenotes-file:` 引用，选择的文件在本会话可读取，刷新后需重新定位。文件句柄可以验证可读性；普通副本标记原路径未验证，不伪装成已调用系统默认应用。

双击非编辑卡片复制 Emoji、正文和引用，支持时写入纯文本、HTML，以及含图记录的 PNG 表示。文件附件提供重新定位、真实副本下载或支持环境中的系统分享。**Windows 原生文件剪贴板及微信附件粘贴仍未实现/未实测**，已记录 [CLIP-001](../begin/implementation-gaps.md#clip-001)，不得以路径或下载替代验收。

## 布局与设置

侧栏边缘可拖动调整 360–720px，手动收起解除固定，也可用 `Alt + Shift + S` 呼出。新建卡片由不透明粘性底板固定在记录列表顶部，正文滚动不会带走输入入口，也不会在圆角处透出滚动卡片。默认按需加载，每批 10 条、接近底部立即追加，不重建已有卡片；加载与整理提醒位于“外观与交互”末尾“其它”组，左右紧凑同排，可关闭或设置每批 5–100 条。工作区默认超过 50 条提醒整理，可调整、关闭或忽略 7 天；不自动处理内容。

正常保存只显示绿色标记；开启同步显示云朵。处理中和异常才展示文字，备份失败另有首页警告与重试。

普通入口隐藏测试按钮；`?demo=1` 或 `?mode=demo` 显示测试与故障模拟，`?demo=1&update=1` 额外显示更新提示和生成测试记录入口。外观参考用户指定的 [Filee](https://github.com/KnifeLemon/Filee)。

## 原型与原生能力边界

浏览器存储、标签、Markdown、附件读取和备份 JSON 为实际浏览器流程。系统字体、目录选择、文件句柄与通知取决于浏览器支持及用户授权。

云服务尚未连接：当前仅配置验证和模拟备份，本地防抖生成另一份浏览器快照，未上传云端。目录设置仅作桌面配置预览，当前数据实际仍在浏览器。系统文件剪贴板、全局热键、托盘、SQLite、多屏 DPI 与原生文件跳转属于后续桌面实现。
