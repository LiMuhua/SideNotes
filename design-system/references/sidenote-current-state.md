# SideNotes 项目现状报告

本文是设计系统工作的阶段一产出：在动手设计之前，记录现有工程的定位、功能、界面结构与视觉语言，找出可复用的部分和必须遵守的限制。

功能以原项目 `claude` 分支的 `3a7ac02`（0.7.3）为准。本工作树的代码基线是 `ba47739`（0.7.2），两者的共用代码（`src/core`、Markdown 与编辑器）相同；0.7.3 新增的快捷键重新绑定、设置页说明放进问号两项，Playground 按 0.7.3 的行为模拟。括号中给出出处。

## 一、结论摘要

1. **产品是贴边的速记侧栏。** 目的是不打断当前工作、随手记下碎片想法：鼠标移到屏幕边缘唤出侧栏，移开后收起；任何程序中按快捷键呼出速记浮窗，记完就回到原来的工作（`README.md`）。整理与查找是辅助功能，片段管理不是重点（2026-11-05 用户确认）。
2. **本次只重构操作逻辑、布局与样式。** 功能、数据模型与三个窗口保持不变，不新增业务功能；Playground 中提出的交互改动都标注为「本次提出」，与现有行为分开。
3. **视觉资产成熟，但没有令牌体系。** 现有界面延续原型的鼠尾草绿配色，有四种界面材质（标准、纸张、玻璃、Win11）和深浅两套外观；颜色、字号、圆角大量直接写在选择器里，没有间距、字号、圆角、动效的令牌。
4. **空间很紧。** 侧栏默认 416 像素宽、最小 300 像素，所有内容都在这一窄条里；字号设置是整页缩放，侧栏随字号等比加宽（技术决策第 17 条、T45）。
5. **没有路由和 UI 框架。** 窗口角色由窗口标签或 `?window=` 参数决定（`src/main.tsx`），组件全部手写。Design Playground 使用独立入口，不改动这套启动逻辑。

## 三、窗口与平台

三个窗口加载同一份前端代码（`src-tauri/tauri.conf.json`）：

| 窗口 | 标签 | 尺寸 | 特性 |
| --- | --- | --- | --- |
| 侧栏 | `main` | 宽 416、高 900，最小宽 300 | 无边框、置顶、不进任务栏；宽度由应用内拖动调整 |
| 速记浮窗 | `capture` | 560 × 420 | 无边框、置顶、居中 |
| 设置 | `settings` | 880 × 720，最小 720 × 560 | 无边框、可调整大小、置顶 |

- **Windows**：主要目标平台。后端关闭了侧栏的 DWM 过渡动画，按内容区贴边，读取系统字体（`src-tauri/src/windows.rs`、`fonts.rs`）。窗口不透明（`transparent: false`）。
- **Linux**：代码有 `cfg(not(windows))` 的退路（如字体列表），没有构建与界面验证记录。
- **Android**：已生成启动图标，全局快捷键在移动端排除（`Cargo.toml` 的 `target` 条件），没有移动端界面。
- **明暗**：浅色、深色、跟随系统。跟随系统只在设置变化时判断一次（`src/core/settings.ts`），系统切换明暗后要等下一次设置变化才生效。

## 四、功能清单

### 侧栏

- **唤出与收起**：鼠标移到屏幕边缘唤出（可关闭），移出后按「移出后收起」的延迟收起；固定按钮让侧栏保持展开；设置窗口打开期间保持展开（T15）；编辑时保持展开（可关闭）；全局快捷键 Alt+Shift+S 切换。可贴左侧或右侧，拖动内侧边框调整宽度，出入动画时长可调。
- **列表**：工作区、置顶、归档三个页签，带计数；Ctrl+F 搜索正文与标签，输入 `#` 时联想已有标签，Tab 选用；标签筛选菜单；筛选时列表上方显示筛选条（条件、条数、显示全部）；工作区记录超过阈值时显示整理提醒；滚动按需加载。
- **新建卡片**：固定在列表之上的实时 Markdown 编辑器，与速记浮窗共用草稿；Ctrl+Enter 保存后侧栏保持展开，可以接着记下一条（T47）。
- **卡片内容**：Emoji（点击更换）、标题（正文首行）、置顶标记、时间（点击收起或展开正文，悬停显示创建与修改时间）、正文预览（超过最大高度渐隐）、标签（点击按标签筛选）、操作按钮（复制、置顶、归档、更多）。
- **卡片操作**：指针移到卡片上或单击即选中，两者共用一种高亮（T66）；Ctrl+C 复制选中的卡片（含附件）；双击编辑，Ctrl+Enter 保存、Esc 取消、焦点离开即保存；Ctrl 或 Shift 单击多选，框选；按住拖动排序，拖到页签或回收站即移过去，可撤销。
- **右键菜单**：卡片菜单有复制内容与附件、编辑、展开或收起正文、置顶、归档、创建副本、导出 Markdown、记录信息、移入回收站；空白处的侧栏菜单有新建、搜索、收起或展开全部卡片、选择全部、固定、停靠到另一侧、设置、使用指南、收起侧栏。双击空白处收起或展开全部卡片；Esc 逐级退出搜索与多选，最后收起侧栏。

### 编辑

- Markdown 快捷键与 `#标签` 联想；粘贴截图或文件时保存一份副本，插入到光标处。
- 点击图片或文件打开附件弹窗：查看、修改引用、更换文件、另存为；按住 Ctrl 点击直接打开。
- 从资源管理器把文件拖到卡片上即可插入，停留片刻进入编辑后可以放到具体位置。

### 速记浮窗

全局快捷键 Ctrl+Shift+Space 呼出；Ctrl+Enter 保存并收起，Esc 保留草稿并收起；可以转到侧栏继续编辑；有添加图片与引用文件的工具（`src/components/Capture.tsx`）。

### 设置窗口

| 分类 | 内容 |

## 五、数据模型

一条记录（`Note`，`src/core/types.ts`）的字段：

| 字段 | 含义 | 界面中的位置 |
| --- | --- | --- |
| `text` | Markdown 原文；首行是标题，标签写在末尾独立行 | 卡片标题、正文预览、标签 |
| `emoji` | 每条记录一个 Emoji | 卡片标题前，点击更换 |

| `order` | 手动排序序号 | 拖动排序 |

## 六、现有视觉语言

**颜色。** 浅色主题以暖灰绿为底：画布 `#edf0e9`、纸面 `#f8faf5`、卡片 `#fff`、正文 `#29352c`、强调色 `#4d714f`（`src/styles/prototype.css` 第二版变量）。深色主题为墨绿底：画布 `#20271f`、卡片 `#2c3529`、强调色 `#9bbd85`。四种材质各自覆盖这组变量：纸张为米黄、玻璃为半透明加背景模糊、Win11 为冷蓝。

**变量。** 只有 `--canvas`、`--paper`、`--card`、`--ink`、`--muted`、`--subtle`、`--line`、`--soft`、`--accent`、`--accent-hover`、`--accent-soft`、`--shadow`、`--danger` 等颜色变量，以及 `--card-radius`、`--note-font-family`、`--note-font-size`。

**字号与圆角。** 原型按正文 13px 设计，界面中大量使用 9–10px 的文字（时间、计数、提示）。圆角从 3px 到 16px 共有十余种取值，同类控件之间也不一致（按钮 6–8px、卡片 10–11px、弹窗 10–15px）。

**状态。** 选中与悬停共用一种绿色边框高亮，不随材质的强调色变化（技术决策第 13 条）；编辑中的卡片用强调色边框、外圈与投影，其余卡片变淡；提示条为反色。

## 七、设计限制与问题

1. **硬编码样式多。** `prototype.css` 与 `desktop.css` 中有上百处直接写出的十六进制颜色和数十处 `!important`，深色主题与材质靠逐个选择器覆盖，调整强调色需要改很多地方。
2. **文字偏小。** 大量 9–10px 文字依赖整页缩放才勉强可读；在 13px 设计基准下，次要信息的对比度和字号都偏弱。
3. **卡片底部常驻一行。** 标签与操作按钮固定占卡片底部一行（`src/components/NoteCard.tsx` 的 `note-bottom`），没有标签的卡片也留着这一行，窄侧栏里一屏能看到的记录变少。
4. **等宽字体作界面字体。** Maple Mono NF CN 的汉字宽 1.2 em，同样宽度能放下的汉字比常规中文字体少约两成（技术决策第 18 条），信息密集时更挤。
5. **系统主题不实时。** 见第三节。
6. **没有语法高亮与表格。** 代码块是单色等宽文字；Markdown 解析器不支持表格。

## 十、对 Design Playground 的约束

- 使用独立的开发入口（`/design-playground`，`pnpm playground` 在 1430 端口启动），不改动 `src/main.tsx` 的窗口角色判断，不进入正式构建。
- 不引入 `prototype.css`：它在 `:root` 与 `body` 上设置了全局字体、背景和溢出，会把旧样式带进 Playground。
- 复用 `src/core` 中的纯函数、`Markdown` 组件与实时编辑器。
- 只使用内存中的示例数据，不调用 `src/core/bridge.ts` 的桌面命令，不读写数据库。
