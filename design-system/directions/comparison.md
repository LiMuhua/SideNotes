# 五套视觉方向对比

本文汇总 SideNotes 的五套候选视觉方向：各自的理念、结构差异、关键数值，以及五套共用的交互改动。状态是**待评审**：请在 Design Playground 中逐一操作比较，选定方向后再编写正式的设计规范（`DESIGN.md` 与各分册）。

五套方向的由来（2026-11-05 用户确认）：开发者工作台是首选，现代编辑留作备选；原先的「沉静技术」与开发者工作台太相近，已去掉；另外按 Glance 的三种外观补充记录纸、Windows 11、磨砂玻璃三套。

## 怎样评审

在本工作树中启动 Playground：

```bash
pnpm playground
```

浏览器打开 `http://localhost:1430/design-playground`。它使用 1430 端口，可以与应用的开发服务器（1420）同时运行，方便对照实际应用。

- 「五套对比」页把五个侧栏并排放在同一张壁纸上，每个都可以操作。
- 「侧栏」「速记浮窗」「设置」页在模拟桌面中单独运行一套方向，顶部切换方向、明暗、平台、壁纸与屏幕尺寸。
- 「繁杂」壁纸是高对比的色块与条纹，用来检验半透明方向的可读性。

建议重点看：

1. 一屏能看到几条记录，记录之间的边界是否一眼可见。
2. 连续看一会儿是否累，深色主题下是否清楚。
3. 随手记一条（新建卡片、速记浮窗）与改一条（双击编辑）是否顺手。
4. 侧栏调窄（拖动内侧边框）、字号调大后是否仍然放得下。

## 五套共用的改动（本次提出）

下面这些是对现有操作逻辑与布局的修改建议，五套方向都采用，与现有行为分开列出：

| 改动 | 现有行为 | 理由 |
| --- | --- | --- |
| 卡片的操作按钮移到标题行，只在悬停、选中或键盘聚焦时出现；底部只在有标签时显示标签 | 标签与操作按钮固定占卡片底部一行，没有标签也留着 | 窄侧栏里每条记录少占一行；单行记录与收起的记录只剩标题行 |
| 操作按钮出现时隐藏置顶标记 | 置顶标记一直显示 | 操作按钮里已有「取消置顶」，避免同一个图钉出现两次 |
| ↑ ↓ 在卡片之间移动，Home、End 到首尾，Enter 编辑，Delete 移入回收站（沿用现有的确认），Shift+F10 打开卡片菜单 | 卡片只能用鼠标选中与操作 | 「先选中，再操作」的键盘模型，与 Ctrl+C 复制选中项一致 |
| 手机形态：侧栏铺满屏幕，不显示快捷键提示、固定与收起按钮；点一下卡片显示操作按钮；速记浮窗从底部弹出 | 没有移动端界面 | 为 Android 预留；触屏没有悬停与实体键盘 |

现有的交互全部保留：悬停与单击共用选中、双击编辑、右键菜单、Ctrl+C 复制、Esc 逐级退出、空白处双击收起或展开全部、新建卡片保存后保持展开。

## 半透明方向的实现条件

Windows 11 与磨砂玻璃两套方向在 Playground 中用 CSS 的 `backdrop-filter` 模糊模拟桌面上的场景。真实应用中，WebView 里的 `backdrop-filter` 只能模糊窗口内部的内容，要透出桌面需要系统的窗口材质。以下事实来自官方文档（2026-11-05 查阅）：

- **Tauri 的窗口材质**（[配置参考](https://v2.tauri.app/reference/config/)）：`windowEffects` 要求窗口透明，现有应用的窗口不透明（`transparent: false`）；Linux 不支持。Mica 只支持 Windows 11；Acrylic 支持 Windows 10 与 11，但在 Windows 10 v1903 以上与 Windows 11 build 22000 上拖动、调整窗口大小时性能差。侧栏的滑入滑出与拖动调宽都会移动或改变窗口，需要实测。
- **Mica**（[微软文档](https://learn.microsoft.com/en-us/windows/apps/design/style/mica)）：不透明，只取一次桌面壁纸与主题色，不透出后面的其他窗口；窗口失去焦点、关闭透明效果、省电模式或低端硬件上退回纯色。
- **Acrylic**（[微软文档](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)）：背景亚克力透出壁纸与后面的窗口，推荐用于菜单、浮出面板、轻触即关的窗格等临时表面；起分区作用的竖向面板建议用不透明背景；不要在亚克力上放强调色文字。窗口失去焦点时退回纯色，关闭透明效果或省电模式时也退回纯色。

对 SideNotes 的影响：

1. 侧栏收起后即消失，接近「轻触即关的窗格」，符合亚克力的推荐用法；但侧栏由鼠标悬停唤出，不一定获得焦点，失去焦点时亚克力会退回纯色。这一点决定 Windows 11 与磨砂玻璃方向在真实应用中的观感，选用前必须实测。
2. Linux 与 Android 没有窗口材质，两套方向都需要实心的退路，例如每套另备一组不透明的面板与卡片颜色；目前的令牌中还没有这组颜色（待实现）。
3. 令牌已按最差情况设计：半透明表面分别叠在纯黑与纯白上，文字仍达到 4.5:1（`design-system/tests/tokens.test.ts`）。

## 2026-11-05 的调整

用户看过第一版 Playground 后提出：开发者工作台与记录纸太扁平，记录之间区分不明显，看起来很累，边距间隔也奇怪、浪费空间。已做的调整：

- 开发者工作台的记录从「细线分隔的条目」改为带标题栏的窗格，记录纸改为纸垫上的纸片；记录之间留出间隙。
- 去掉卡片底部常驻的一行（见上节第一项），内容下方不再留空。
- 收紧内边距：开发者工作台面板内边距 12 改为 10；记录纸面板与记录内边距 18 改为 12，标题区高度 46 改为 42。
- Playground 改用 1430 端口，避免与应用的开发服务器冲突。
