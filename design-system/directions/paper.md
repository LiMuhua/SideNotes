# 记录纸（Paper）

状态：待评审。在 Playground 顶部选择「记录纸」查看。

## 理念

一叠贴着屏幕边缘的记录纸：灰绿纸垫上铺着一张张浅色纸片，只有一种墨色，信号色只在需要时出现。取自 Glance 的记录纸外观，也对应现有 SideNotes 的纸张材质。

## 视觉特征

| 项目 | 做法 | 主要令牌 |
| --- | --- | --- |
| 字体 | Archivo（Glance 记录纸的字体，未随应用打包），回落到 Segoe UI Variable Text、微软雅黑 UI 等系统字体 | `--sn-font-ui` |
| 字号 | 界面 11–13px，标题 13px（650），正文 13.5px、行高 1.7 | `--sn-font-size-*`、`--sn-note-size` |
| 颜色 | 灰绿纸色、单色墨水，第二墨色（墨绿）只用于主要操作与选中。浅色：纸垫 `#e3e9e1`、纸片 `#f5f8f3`、墨色 `#16221e`、强调色 `#1f6b45`；深色：纸垫 `#0f1a17`、纸片 `#172723`、文字 `#e7eee7`、强调色 `#4ecb82` | `--sn-color-*` |
| 面板 | 贴边整块，贴边一侧没有圆角，朝屏幕内侧一边 16px 圆角 | `--sn-panel-radius`、`--sn-panel-radius-edge` |
| 记录 | 纸片：一像素边框、3px 圆角，底边一像素的纸厚阴影；纸片之间留 8px | `--sn-card-radius`、`--sn-shadow-sm`、`--sn-card-gap` |
| 选中 | 纸片边框换成墨绿 | `--sn-color-accent` |
| 页签 | 文字加下划线 | — |
| 快捷键 | 写在工具提示中 | — |
| 动效 | 160、240、280ms，强减速曲线（取自 Glance） | `--sn-duration-*`、`--sn-ease-*` |

## 优点与代价

优点：

- 颜色最少，界面安静；纸片之间的缝与纸垫的深浅差让每条记录的边界清楚。
- 贴边一侧没有圆角，侧栏与屏幕边缘连成一体。
- 与现有 SideNotes 的纸张材质一脉相承。

代价：

- Archivo 没有随应用打包，多数电脑上实际显示的是系统字体，与 Glance 的观感有差距；要打包需要确认字体许可。
- 只有一种墨色，置顶、归档等状态主要靠图标区分。

## 2026-11-05 的调整

用户反馈第一版太扁平、记录之间区分不明显、看起来很累、间距浪费空间。Glance 原本用细线分栏，它的栏目内容短而整齐；SideNotes 的记录长短不一，只用细线时边界不清楚。调整如下：

- 记录从细线分栏改为纸垫上的纸片，纸片之间留 8px。
- 纸垫由 `#eef2ec` 加深为 `#e3e9e1`，纸片用更浅的 `#f5f8f3`；深色同理。
- 面板与记录的内边距 18 改为 12，标题区高度 46 改为 42，底栏 44 改为 38。
- 去掉卡片底部常驻的一行（五套共用，见 [comparison.md](./comparison.md)）。
