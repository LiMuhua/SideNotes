# 磨砂玻璃（Frosted Glass）

状态：待评审。在 Playground 顶部选择「磨砂玻璃」查看；把壁纸换成「繁杂」可以检验文字在杂乱背景上的可读性。

## 理念

分开的几块磨砂玻璃，在边缘透出桌面；背景越杂乱磨得越砂，文字在任何背景上都清楚。取自 Glance 的磨砂玻璃外观，也对应现有 SideNotes 的玻璃材质。

## 视觉特征

| 项目 | 做法 | 主要令牌 |
| --- | --- | --- |
| 结构 | 侧栏没有整块面板：标题区与页签、列表顶栏、新建卡片、每条记录、底栏都是独立的玻璃块，块与块之间留 8px | `--sn-block-gap` |
| 字体 | Inter（未随应用打包），回落到 Segoe UI Variable Text、微软雅黑 UI 等系统字体 | `--sn-font-ui` |
| 字号与字重 | 界面 11–13px，标题 14px（650），正文 13.5px、行高 1.6；正文字重 500，在半透明背景上保持清晰 | `--sn-note-size`、`--sn-body-weight` |
| 颜色 | 浅色：玻璃 `rgb(255 255 255 / 0.78)`、文字 `rgb(0 0 0 / 0.88)`、强调色 `#0a64d8`；深色：玻璃 `rgb(20 20 26 / 0.8)`、文字 `rgb(255 255 255 / 0.95)`、强调色 `#3d9bff` | `--sn-color-*` |
| 材质 | 每块玻璃模糊 24px、饱和度 1.3；顶部一像素受光，文字带一圈光晕 | `--sn-panel-blur`、`--sn-color-edge-highlight`、`--sn-color-halo` |
| 圆角 | 面板块 24px，记录 18px，控件 12px | `--sn-panel-radius`、`--sn-card-radius`、`--sn-radius-control` |
| 页签 | 分段控件，页签前有分区色圆点（工作区、置顶、归档各一种颜色） | `--sn-color-mark-*` |
| 快捷键 | 写在工具提示中 | — |
| 动效 | 160、260、360ms | `--sn-duration-*` |

Glance 按背景亮度与杂乱程度实时调整磨砂程度；这里取固定的较高不透明度，保证玻璃叠在纯黑或纯白背景上，弱化文字仍达到 4.5:1（可读性优先于效果）。

## 优点与代价

优点：

- 视觉上最轻，最有「浮在桌面上」的感觉。
- 分区色圆点让三个页签一眼可辨。

代价：

- 大圆角与块间距占空间，密度低（记录内边距 16 × 13px）。
- 每块玻璃各自模糊，渲染开销在五套中最大。
- 与 Windows 11 方向相同的平台与焦点限制，见下一节。

## 实现条件与已知问题

- 实现条件与 Windows 11 方向相同，见 [comparison.md](./comparison.md) 的「半透明方向的实现条件」。
- Playground 中，列表底边处被裁到一半的玻璃块会漏出背后的内容，疑似 Chromium 对滚动容器裁切与 `backdrop-filter` 的绘制问题。选用本方向时，要在 WebView2 中复核，必要时改为列表整体模糊或在列表底部加渐隐。
