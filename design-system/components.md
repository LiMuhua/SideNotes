# 组件

本文规定五套主题共用的组件：侧栏的各个部件、记录卡片、速记浮窗、设置窗口与基础控件。每个组件只引用令牌（见 [design-tokens.md](./design-tokens.md)）与结构差异（见 [DESIGN.md](./DESIGN.md) 第四节）；各主题的具体取值见主题文档。Playground 中「组件」页按当前主题渲染全部组件与状态。

## 一、侧栏

### 1.1 结构

侧栏自上而下：

| 部件 | 高度或尺寸 | 说明 |
| --- | --- | --- |
| 标题区 | `--sn-header-height` | 品牌标记、产品名、版本号按钮（点击查看更新日志）；右侧是固定与收起按钮 |
| 页签与搜索 | `--sn-tab-height` | 工作区、置顶、归档三个页签，带计数；右侧的搜索按钮展开为搜索框 |
| 整理提醒 | 按内容 | 工作区记录超过阈值时出现：去归档、七天内不再提醒、关闭 |
| 列表顶栏 | 按内容 | 当前列表的条数，右侧是标签筛选菜单 |
| 新建卡片 | 按内容 | 常驻在列表之上；归档页签中不显示 |
| 筛选条 | 按内容 | 搜索或按标签筛选时出现：条件、匹配条数 / 全部条数、「显示全部」 |
| 记录列表 | 剩余高度 | 只有这一部分滚动 |
| 底栏 | `--sn-footer-height` | 存储状态与设置按钮；终端主题为状态栏 |

侧栏朝屏幕内侧的一边是调整宽度的手柄：指针变为左右箭头，拖动调整宽度，获得焦点时可用方向键调整。

### 1.2 面板与屏幕边缘

| 结构 | 主题 | 做法 |
| --- | --- | --- |
| 贴边整块（flush） | 终端、记录纸 | 面板贴住屏幕边缘，朝屏幕内侧一条边框；贴边一侧的圆角取 `--sn-panel-radius-edge` |
| 浮动面板（floating） | 杂志、Windows 11 | 离开屏幕边缘 `--sn-panel-inset`，四角圆角 `--sn-panel-radius`，一像素边框 |
| 分开的若干块（blocks） | 磨砂玻璃 | 没有整块面板：标题区与页签、列表顶栏、新建卡片、每条记录、底栏各是一块，块间距 `--sn-block-gap` |

面板底色 `--sn-color-panel`，投影 `--sn-shadow-panel`；半透明主题加背景模糊 `--sn-panel-blur` 与饱和度 `--sn-panel-saturate`。

### 1.3 标题区

- 固定按钮按下时显示为选中；设置窗口打开期间，侧栏保持展开，固定按钮显示虚线圈，表示「临时固定」（现有行为 T31）。
- 收起按钮的箭头指向屏幕边缘；快捷键 Esc。
- 手机形态不显示固定与收起按钮。

### 1.4 页签与搜索

- 页签有两种形态：下划线（当前页签下方一条强调色的线）与分段控件（当前页签为浮起的胶囊）。磨砂玻璃在页签前加分区色圆点（`--sn-color-mark-workspace`、`--sn-color-mark-pinned`、`--sn-color-mark-archive`）。
- 页签按 WAI-ARIA 页签模式：左右方向键切换并立即显示，Home 与 End 到两端。
- 搜索框展开后盖住页签。输入 `#` 时，框内以灰字补全已有标签，Tab 选用；Esc 先清空，再收起。

### 1.5 整理提醒、列表顶栏与筛选条

- 整理提醒用警告色浅底（`--sn-color-warning-subtle`）。
- 筛选条用强调色浅底与强调色文字（`--sn-color-accent-subtle`、`--sn-color-accent-text`），写明条件与「匹配条数 / 当前页签全部条数」。

### 1.6 新建卡片

- 平时只有一个编辑区，占位文字两行：「记一条… 支持 Markdown、#标签」与保存方式。获得焦点或有内容时，底部出现工具栏：添加图片、引用文件、字数（终端为 Ctrl+Enter 按键提示）、收起、保存。
- 获得焦点时边框换成焦点色，底色换成编辑底色 `--sn-color-editing`。
- 草稿与速记浮窗共用。

### 1.7 底栏

| 形态 | 主题 | 内容 |
| --- | --- | --- |
| 普通底栏 | 杂志、记录纸、Windows 11、磨砂玻璃 | 「已保存到本地」与设置按钮；底色叠一层 `--sn-color-panel-band` |
| 状态栏 | 终端 | 底色 `--sn-color-statusbar`，文字 `--sn-color-on-statusbar`：存储状态、当前页签的条数、Ctrl+N 新建、Ctrl+F 搜索、设置；编辑时换成强调色的「编辑中」与 Ctrl+Enter 保存、Esc 取消 |

状态栏放不下时，快捷键提示整项折到第二行并被裁掉，不会只剩半个。

## 二、记录卡片

### 2.1 结构

```text
┌───────────────────────────────────────────────┐
│ 📝  标题，最多两行……………………       📌 06:04      │  ← 标题行
│     ………………………………………                              │
│ 正文预览，超过最大高度时底部渐隐                    │
│ #标签  #标签                                    │  ← 只在有标签时显示
└───────────────────────────────────────────────┘
悬停、选中或聚焦时，标题行右侧换成：[复制] [置顶] [归档] [更多] [收起]
```

| 部位 | 规则 |
| --- | --- |
| Emoji | 点击更换；宽 `--sn-icon-size` 加 `--sn-space-3`，高 `--sn-control-height-sm` |
| 标题 | 正文的第一行，去掉标题标记；字体 `--sn-font-title`、字号 `--sn-font-size-lg`、字重 `--sn-title-weight`；最多两行，超出部分省略 |
| 右侧位置 | 时间与操作按钮叠放在同一格，格宽取两者中较宽的一个。平时显示置顶标记与创建时间；悬停、选中或键盘聚焦时换成操作按钮。标题的宽度因此在悬停前后不变 |
| 时间 | 创建时间，字号 `--sn-font-size-xs`，弱化文字色；悬停在时间上显示创建与修改时间；点击时间收起或展开正文 |
| 操作按钮 | 复制、置顶（只在工作区与置顶中）、归档或恢复、更多、收起；小号图标按钮，高 `--sn-control-height-sm` |
| 正文 | Markdown 渲染，字体 `--sn-font-note`、字号 `--sn-note-size`、行高 `--sn-note-line-height`；超过设置中的「卡片高度」时底部渐隐，双击查看全文 |
| 标签 | 小号胶囊，点击按标签筛选；没有标签时不占位置 |

Emoji、时间与按钮对齐标题的第一行。单行记录与收起的记录只剩标题行。

### 2.2 三种组织方式

| 结构 | 主题 | 做法 |
| --- | --- | --- |
| 窗格（panes） | 终端 | 标题行是带底色的标题栏（`--sn-color-card-head`），与正文之间一条分隔线 |
| 卡片（cards） | 杂志、记录纸、Windows 11 | 底色 `--sn-color-card`，边框 `--sn-color-border-subtle`，投影 `--sn-shadow-sm` |
| 玻璃块（tiles） | 磨砂玻璃 | 每块各自磨砂，边缘受光（`--sn-color-rim-top` 到 `--sn-color-rim-bottom`），顶部光泽（`--sn-color-sheen`） |

圆角 `--sn-card-radius`，内边距 `--sn-card-padding-x` 与 `--sn-card-padding-y`，卡片之间 `--sn-card-gap`。

### 2.3 状态

| 状态 | 表现 | 令牌 |
| --- | --- | --- |
| 默认 | 卡片底色、浅边框，右侧显示时间 | `--sn-color-card`、`--sn-color-border-subtle` |
| 悬停与选中 | 强调色边框加外圈，叠一层选中色；终端的标题栏换成选中色，顶部一条 2px 的强调色线；玻璃块去掉边缘受光 | `--sn-shadow-card-active`、`--sn-color-card-active`、`--sn-color-card-head-active` |
| 多选 | 叠一层强调色浅底，强调色边框 | `--sn-color-accent-subtle` |
| 键盘焦点 | 卡片内侧一圈焦点环 | `--sn-color-focus`、`--sn-focus-ring-width` |
| 编辑中 | 编辑底色，强调色边框与外圈，见 [editing.md](./editing.md) | `--sn-color-editing`、`--sn-shadow-editing` |
| 其余卡片变淡 | 有卡片在编辑时降到禁用透明度，悬停时恢复 | `--sn-opacity-disabled` |
| 收起 | 只剩标题行 | — |

悬停与单击共用同一种高亮，指针离开后最后高亮的一张保持高亮（现有行为 T66）；高亮的那一张就是 Ctrl+C 复制的对象。选中卡片中的时间与标签改用次要文字色，因为弱化文字在选中底色上达不到 4.5:1。

## 三、菜单、弹窗与提示

| 组件 | 规则 |
| --- | --- |
| 右键菜单 | 浮起的表面（`--sn-color-surface-raised`、`--sn-shadow-md`、`--sn-radius-md`），菜单项高 `--sn-menu-item-height`；右侧显示快捷键；危险操作用 `--sn-color-danger`，放在最后并用分隔线隔开。键盘按 WAI-ARIA 菜单模式 |
| 弹窗 | 宽 `--sn-dialog-width`，`--sn-shadow-lg`、`--sn-radius-lg`，遮罩 `--sn-color-overlay`；打开时焦点移入，Tab 在弹窗内循环，Esc 关闭，关闭后焦点回到打开前的位置 |
| 确认移入回收站 | 标题「将这条记录移入回收站？」，正文是记录的第一行；多选时标题写明条数 |
| 提示条 | 反色（`--sn-color-inverse`、`--sn-color-on-inverse`），可带「撤销」；位置取设置中的「通知位置」：顶部正中、右上角或底部正中 |
| 工具提示 | 反色，延迟出现；说明按钮用途与快捷键 |

## 四、速记浮窗

自上而下：标题区（品牌标记、「速记」，右侧是「在侧栏继续」与收起）、编辑区、草稿状态与字数、底栏（添加图片、引用文件、快捷键提示、收起、保存）。

- 面板为卡片底色叠在面板底色上：实心主题就是卡片底色，半透明主题保留磨砂；`--sn-shadow-lg`、`--sn-radius-lg`。
- 编辑区获得焦点时的样式与卡片编辑相同（行号、横线、强调线），见 [editing.md](./editing.md)。
- 窗口尺寸 560 × 420，不随字号变化，内容按字号缩放。

## 五、设置窗口

| 部位 | 规则 |
| --- | --- |
| 标题栏 | 应用名、最小化与关闭；高 `--sn-header-height` |
| 分类栏 | 外观与交互、快捷键、数据与同步、回收站、关于；上下方向键切换；当前项叠 `--sn-color-selected`，左侧一条强调色的竖线 |
| 内容区 | 底色 `--sn-color-surface`，最大宽度为弹窗宽度的 1.6 倍；分组标题用次要文字色 |
| 设置行 | 名称在左、控件在右；说明放进名称后的问号图标，悬停显示（现有行为 0.7.3） |
| 明暗模式与主题 | 选项卡片：每个选项是用对应主题与明暗的令牌画出的迷你侧栏，选中的卡片为强调色边框 |
| 快捷键 | 点击按键后按下新组合即可；冲突时在左侧说明原因 |

窗口尺寸 880 × 720，最小 720 × 560，不随字号变化，内容按字号缩放。

## 六、基础控件

| 控件 | 尺寸 | 状态与说明 |
| --- | --- | --- |
| 按钮 | 高 `--sn-control-height-sm`、`--sn-control-height`、`--sn-control-height-lg`，圆角 `--sn-radius-control` | 主要（强调色填充）、次要、文字、危险四种；悬停、按下叠加 `--sn-color-hover` 与 `--sn-color-pressed`；禁用为 `--sn-opacity-disabled`；可带快捷键（终端直接显示，其余写入工具提示与 `aria-keyshortcuts`） |
| 图标按钮 | 边长同控件高度，图标 `--sn-icon-size` 或 `--sn-icon-size-sm` | 必须有文字说明（工具提示与 `aria-label`）；可切换的按钮用按下态 |
| 输入框与搜索框 | 高同按钮 | 底色 `--sn-color-surface`，边框 `--sn-color-border-strong`；获得焦点时焦点色边框 |
| 复选框、单选、开关 | 图标尺寸 | 选中为强调色；开关是 `role="switch"` 的按钮 |
| 分段控件 | 高同按钮 | 单选组，方向键切换并立即生效；当前项浮起 |
| 下拉选择框 | 高同按钮 | 列表框按 WAI-ARIA 模式：方向键移动、首字母跳转、Enter 选定、Esc 关闭 |
| 滑块 | — | 字号滑块松开后才应用（现有行为） |
| 快捷键 | 字号 `--sn-font-size-xs` | 每个键一个小框，圆角 `--sn-radius-xs` |
| 徽标与标签 | 圆角 `--sn-radius-chip` | 计数徽标；标签胶囊悬停时换成强调色浅底 |
| 空状态 | — | 图标、标题、一句说明，按需带一个按钮 |

所有控件的焦点环统一：`--sn-focus-ring-width` 宽、`--sn-focus-ring-offset` 间距、`--sn-color-focus` 颜色，只在键盘操作时显示。
