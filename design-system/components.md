# 组件

本文规定五套主题共用的组件：侧栏的各个部件、记录卡片、速记浮窗、设置窗口与基础控件。每个组件只引用令牌（见 [design-tokens.md](./design-tokens.md)）与结构差异（见 [DESIGN.md](./DESIGN.md) 第四节）；各主题的具体取值见主题文档。Playground 中「组件」页按当前主题渲染全部组件与状态。

## 一、侧栏

### 1.1 结构

侧栏自上而下：

| 部件 | 高度或尺寸 | 说明 |
| --- | --- | --- |
| 标题区 | `--sn-header-height` | 品牌标记与产品名；右侧是固定与收起按钮（版本号在底栏） |
| 页签与搜索 | `--sn-tab-height` | 工作区、置顶、归档三个页签，带计数；这一行最右边的搜索按钮展开为搜索框 |
| 整理提醒 | 按内容 | 工作区记录超过阈值时出现：去归档、七天内不再提醒、关闭 |
| 列表顶栏 | 按内容 | 当前列表的条数（按标签筛选时带上标签），右侧是标签筛选按钮 |
| 新建卡片 | 按内容 | 常驻在列表之上；归档页签中不显示 |
| 筛选条 | 按内容 | 搜索或按标签筛选时出现：条件、匹配条数 / 全部条数、「显示全部」 |
| 记录列表 | 剩余高度 | 只有这一部分滚动 |
| 底栏 | `--sn-footer-height` | 左下角是版本号（有新版本时带更新角标），右边是设置按钮，其余留白 |

侧栏朝屏幕内侧的一边是调整宽度的手柄：指针一移上去就变为左右箭头，表示可以拖动；高亮要等指针停留 400ms 之后，只是划过不会闪一下强调色（本次提出）。按下即可拖动，获得焦点时立即高亮，可用方向键调整。

### 1.2 面板与屏幕边缘

| 结构 | 主题 | 做法 |
| --- | --- | --- |
| 贴边整块（flush） | 终端、记录纸 | 面板贴住屏幕边缘，朝屏幕内侧一条边框；贴边一侧的圆角取 `--sn-panel-radius-edge` |
| 浮动面板（floating） | 杂志、Windows 11 | 离开屏幕边缘 `--sn-panel-inset`，四角圆角 `--sn-panel-radius`，一像素边框 |
| 分开的若干块（blocks） | 磨砂玻璃 | 没有整块面板：标题区与页签、列表顶栏、新建卡片、每条记录、底栏各是一块，块间距 `--sn-block-gap` |

面板底色 `--sn-color-panel`，投影 `--sn-shadow-panel`；半透明主题加背景模糊 `--sn-panel-blur` 与饱和度 `--sn-panel-saturate`。

### 1.3 标题区

- 左边是品牌标记与产品名。品牌标记就是应用图标，配色固定，不随主题变化，见第七节（本次提出）。
- 固定按钮按下时显示为选中；设置窗口打开期间，侧栏保持展开，固定按钮显示虚线圈，表示「临时固定」（现有行为 T31）。
- 收起按钮的箭头指向屏幕边缘；快捷键 Esc。
- 手机形态不显示固定与收起按钮。

### 1.4 页签与搜索

- 页签有两种形态：下划线（当前页签下方一条强调色的线）与分段控件（当前页签为浮起的胶囊）。磨砂玻璃在页签前加分区色圆点（`--sn-color-mark-workspace`、`--sn-color-mark-pinned`、`--sn-color-mark-archive`）。
- 页签按 WAI-ARIA 页签模式：左右方向键切换并立即显示，Home 与 End 到两端。
- 搜索按钮在页签行的最右边，与现有应用一致。点击后搜索框从右向左展开到整行，盖住页签，页签淡出；收起时反向。宽度变化用 `--sn-duration-slow` 的 1.25 倍（终端 200ms，与现有应用的 220ms 相近），比其它状态变化慢一些；页签淡出与输入框淡入用 `--sn-duration-normal`，输入框等宽度展开一段之后才出现。展开后放大镜留在框的左端，再点一次收起。框内依次是输入框、灰字联想的 Tab 按键提示与清空按钮（有内容时出现）。
- 末尾正在输入 `#标签` 时，框内以灰字联想已有标签，Tab 选用，↑ ↓ 切换候选；查询中已写过的标签不再联想（现有行为，交互见 [interactions.md](./interactions.md) 第六节）。

### 1.5 整理提醒、列表顶栏与筛选条

- 整理提醒用警告色浅底（`--sn-color-warning-subtle`）。
- 列表顶栏的标签筛选按钮写「# 全部标签」，筛选时换成当前标签并用强调色；点击打开标签菜单。
- 筛选条用强调色浅底与强调色文字（`--sn-color-accent-subtle`、`--sn-color-accent-text`），左边一个放大镜，写明条件与「匹配条数 / 当前页签全部条数」。

标签菜单沿用现有应用（`TagFilter`）。宽度跟着内容走：最长的一项加上左右的内边距，条数与标签之间多留 8px（本次提出：此前固定为弹窗宽度的 0.6 倍，标签少时显得太宽）。自上而下：

| 部位 | 内容 |
| --- | --- |
| 首位标签 | 评分最高的标签命中搜索词或正被选中时，移到最上方，右侧是「管理」按钮（重命名、合并或从所有记录中移除） |
| 全部标签 | 清除标签筛选，右侧是当前页签的条数 |
| 候选标签 | 评分最高的六个标签（含首位），每项右侧是条数；悬停说明评分的权重：访问频率 40、近期访问 30、条数 4、置顶 3 |
| 底部 | 一项「搜索标签」，打开搜索框并预填 `#`；候选之外还有标签时，右侧写「另有 N 个」（本次提出：现有应用在按钮旁写一句提示，文字太长，会把菜单撑宽） |

没有标签时，候选位置写「输入 #标签 创建分组」；有搜索词但没有匹配的标签时写「没有匹配的标签」。

### 1.6 新建卡片

- 平时只有一个编辑区，占位文字两行：「记一条… 支持 Markdown、#标签」与保存方式。获得焦点或有内容时，底部出现工具栏：添加图片、引用文件、字数（终端为 Ctrl+Enter 按键提示）、收起、保存。
- 获得焦点时与编辑中的卡片一样：底色换成编辑底色 `--sn-color-editing` 并浮起，层级提到列表之上；边框不变，不用强调色，磨砂玻璃保留边缘受光。
- 草稿与速记浮窗共用。

### 1.7 底栏

五套主题的底栏相同（本次提出）：

- 左下角是版本号「v0.7.2」，字号 `--sn-font-size-xs`、弱化文字色。检查到新版本时，版本号右上角出现更新角标：强调色的小圆点里一个向上的箭头。
- 点版本号：有新版本时打开「发现新版本」，列出这次即将更新的内容，可以「立即更新」或「稍后」，「稍后」之后角标保留；没有新版本时打开当前版本的更新日志。
- 右边是小号的设置按钮，快捷键 Ctrl+,。
- 读取或保存失败时，版本号左边出现警告图标，说明换成「未能读取本地记录」或「本地存储失败」。
- 其余位置留白，不放条数与快捷键：条数已经写在页签与列表顶栏上，快捷键写在各按钮的工具提示里。底色叠一层 `--sn-color-panel-band`，与列表之间一条浅色分隔线。

现有应用的版本号在标题区，底栏左边是表示本地存储状态的绿色圆点；圆点取消，这个位置改为版本号与更新提示。

## 二、记录卡片

### 2.1 结构

```text
┌───────────────────────────────────────────────┐
│ 📝  标题，最多两行……………………       📌 06:04      │  ← 标题行
│     ………………………………………                              │
│ 正文预览，超过最大高度时底部渐隐                    │
│ #标签  #标签                                    │  ← 只在有标签时显示
└───────────────────────────────────────────────┘
悬停、选中或聚焦时，标题行右侧换成：[置顶] [复制] [归档] [更多] [收起]
```

| 部位 | 规则 |
| --- | --- |
| Emoji | 点击更换；宽 `--sn-icon-size` 加 `--sn-space-3`，高 `--sn-control-height-sm` |
| 标题 | 正文的第一行，去掉标题标记；字体 `--sn-font-title`、字号 `--sn-font-size-lg`、字重 `--sn-title-weight`；最多两行，超出部分省略 |
| 右侧位置 | 时间与操作按钮叠放在同一格，格宽取两者中较宽的一个。平时显示置顶标记与创建时间；悬停、选中或键盘聚焦时换成操作按钮。标题的宽度因此在悬停前后不变 |
| 时间 | 创建时间，字号 `--sn-font-size-xs`，弱化文字色；悬停在时间上显示创建与修改时间；点击时间收起或展开正文 |
| 操作按钮 | 置顶（只在工作区与置顶中，排在最前）、复制、归档或恢复、更多、收起；已置顶时，置顶按钮的图标保持强调色文字色（`--sn-color-accent-text`），与平时的置顶标记同色，指针停在按钮上也不变；小号图标按钮，高 `--sn-control-height-sm` |
| 正文 | Markdown 渲染，字体 `--sn-font-note`、字号 `--sn-note-size`、行高 `--sn-note-line-height`；超过设置中的「卡片高度」时底部渐隐，双击查看全文 |
| 标签 | 小号胶囊，点击按标签筛选；没有标签时不占位置 |

Emoji、时间与按钮对齐标题的第一行。单行记录与收起的记录只剩标题行。

### 2.2 三种组织方式

| 结构 | 主题 | 做法 |
| --- | --- | --- |
| 窗格（panes） | 终端 | 标题行是带底色的标题栏（`--sn-color-card-head`），与正文之间一条分隔线 |
| 卡片（cards） | 杂志、记录纸、Windows 11 | 底色 `--sn-color-card`，边框 `--sn-color-border-subtle`，投影 `--sn-shadow-sm` |
| 玻璃块（tiles） | 磨砂玻璃 | 每块各自磨砂，边缘受光（`--sn-color-rim-top` 到 `--sn-color-rim-bottom`），顶部光泽（`--sn-color-sheen`） |

圆角 `--sn-card-radius`，内边距 `--sn-card-padding-x` 与 `--sn-card-padding-y`，卡片之间 `--sn-card-gap`。

### 2.3 状态

| 状态 | 表现 | 令牌 |
| --- | --- | --- |
| 默认 | 卡片底色、浅边框，右侧显示时间 | `--sn-color-card`、`--sn-color-border-subtle` |
| 悬停与选中 | 强调色边框加一像素外圈，叠一层选中色；终端的标题栏换成选中色，顶部一条 2px 的强调色线（画在背景层里，两侧不留细缝）；玻璃块去掉边缘受光，不加光晕；编辑中的卡片不用这些高亮 | `--sn-shadow-card-active`、`--sn-color-card-active`、`--sn-color-card-head-active` |
| 多选 | 叠一层强调色浅底，强调色边框 | `--sn-color-accent-subtle` |
| 键盘焦点 | 卡片内侧一圈焦点环 | `--sn-color-focus`、`--sn-focus-ring-width` |
| 编辑中 | 编辑底色并浮起；边框与终端的标题栏保持平时的样子，不用强调色，见 [editing.md](./editing.md) | `--sn-color-editing`、`--sn-shadow-editing` |
| 其余卡片变淡 | 有卡片在编辑时降到禁用透明度，悬停时恢复 | `--sn-opacity-disabled` |
| 收起 | 只剩标题行 | — |

悬停与单击共用同一种高亮，指针离开后最后高亮的一张保持高亮（现有行为 T66）；高亮的那一张就是 Ctrl+C 复制的对象。选中卡片中的时间与标签改用次要文字色，因为弱化文字在选中底色上达不到 4.5:1。

## 三、菜单、弹窗与提示

| 组件 | 规则 |
| --- | --- |
| 右键菜单 | 浮起的表面（`--sn-color-surface-raised`、`--sn-shadow-md`、`--sn-radius-md`），菜单项高 `--sn-menu-item-height`；右侧显示快捷键；危险操作用 `--sn-color-danger`，放在最后并用分隔线隔开。键盘按 WAI-ARIA 菜单模式 |
| 弹窗 | 宽 `--sn-dialog-width`，`--sn-shadow-lg`、`--sn-radius-lg`，遮罩 `--sn-color-overlay`；打开时焦点移入，Tab 在弹窗内循环，Esc 关闭，关闭后焦点回到打开前的位置 |
| 确认移入回收站 | 标题「将这条记录移入回收站？」，正文是记录的第一行；多选时标题写明条数 |
| 提示条 | 反色（`--sn-color-inverse`、`--sn-color-on-inverse`），可带「撤销」；位置取设置中的「通知位置」：顶部正中、右上角或底部正中 |
| 工具提示 | 浮起的表面，与菜单相同（`--sn-color-surface-raised`、`--sn-color-border`、`--sn-shadow-md`），文字用正文色：浅色模式下是浅色，深色模式下是深色；延迟出现，说明按钮用途与快捷键 |
| 发现新版本 | 第一行写新版本号与当前版本，下面按要点列出这次即将更新的内容；底部是「稍后」与「立即更新」（本次提出） |

## 四、速记浮窗

自上而下：

| 部位 | 内容 |
| --- | --- |
| 标题区 | 品牌标记、「速记」与问号说明；右侧是「在侧栏继续」与收起 |
| 编辑区 | 占位文字「随手记… 支持 Markdown 与 #标签」 |
| 底栏 | 左侧是添加图片、引用文件与字数；右侧是收起与保存（主要按钮） |

- 问号说明悬停、获得焦点或点击时显示：Ctrl+Enter 保存并收起，Esc 收起、草稿保留，支持 Markdown 与 #标签、草稿与侧栏的新建卡片共用。快捷键不常驻在界面上，手机形态不写快捷键（本次提出）。
- 不显示草稿的同步状态（本次提出）。字数紧跟在附件工具之后，字号 `--sn-font-size-xs`，弱化文字色。
- 面板为卡片底色叠在面板底色上：实心主题就是卡片底色，Windows 11 保留亚克力；`--sn-shadow-lg`、`--sn-radius-lg`。
- 磨砂玻璃的浮窗是一整块玻璃，材质与侧栏的玻璃块相同：背后模糊、边缘受光，不用顶部光泽。标题区、编辑区与底栏直接放在玻璃上，不加分隔线，也不再嵌一块带边框的编辑区（本次提出）。
- 编辑区填满标题区与底栏之间的空间，内容超出时只在编辑器里滚动，浮窗内不出现第二条滚动条。
- 编辑区里不画边框、强调线与行号；记录纸照常有每行下方的横线，见 [editing.md](./editing.md)。
- Playground 中按住标题区可以拖动浮窗，便于放到不同的背景上检查材质；现有应用的速记浮窗不能拖动。
- 窗口尺寸 560 × 420，不随字号变化，内容按字号缩放。

## 五、设置窗口

布局沿用现有应用 0.7.3（`src/components/settings/`）：窄的分类栏，页面由分组卡片组成，相关的设置放在同一张卡片里，一行可以放几项，尽量紧凑。

| 部位 | 规则 |
| --- | --- |
| 标题栏 | 只写「设置」，右侧是最小化与关闭；高 `--sn-header-height` |
| 分类栏 | 外观与交互、快捷键、数据与同步、回收站、关于，各带图标；上下方向键切换；当前项是浮起的一块（`--sn-color-surface-raised`、`--sn-shadow-sm`），图标用强调色文字 |
| 内容区 | 底色 `--sn-color-surface`，左上角圆角 `--sn-radius-lg`；页面最大宽度为弹窗宽度的 1.6 倍，居中 |
| 页面标题 | 左边是分类名；右边放作用于整页的操作，例如快捷键的「恢复默认」 |
| 分组卡片 | 底色 `--sn-color-surface-raised`，边框 `--sn-color-border-subtle`，圆角 `--sn-radius-md`；标题后可带问号说明。默认占满一行，快捷键页的「全局」与「应用内」两张半宽并排 |
| 设置项 | 名称在前，控件紧跟在后；一行放几项，放不下时折行。同一行的两项之间是一条竖线（`--sn-color-border`，高约一个字），位于间距正中；折行后每行开头不画竖线 |
| 问号说明 | 只给需要额外理解的设置，共 11 处：结果不直观的字体、宽度、卡片高度、整理提醒与链接快捷键；会动到数据的附件、迁移到、快照、本地备份与回收站保留策略；说明适用范围的全局快捷键。说明只写规则与影响：卡片高度写明它是卡片正文的最大高度、超出部分渐隐、调低时一屏放下更多卡片；快照只写何时创建、保留多久。名称已经说清楚的不加问号，例如主题、字号、出入动画、通知位置；云端自动备份的状态行已经写明尚未上传，不加问号；另外可用的按键写在按键的悬停提示里 |
| 滑块行 | 名称、占满剩余宽度的滑块、可以直接输入的数值与单位；输入的数值按步长取整。连续几条滑块共用三列，滑块起点对齐 |
| 数据行 | 名称一列，取值与操作紧跟在后；云端备份的几行输入框因此对齐。路径用代码字体，过长时省略，悬停显示全文 |

各页的分组与现有应用一致：

| 分类 | 分组卡片 |
| --- | --- |
| 外观与交互 | 显示（明暗模式、主题）；文字（字体、字号，下方是占满一行的预览）；侧栏（显示位置、移出后收起、编辑时保持展开一行，宽度、出入动画、卡片高度三条滑块）；其它（列表加载、整理提醒、通知位置排在一行，0.7.3 折成两行） |
| 快捷键 | 全局、应用内两张半宽卡片；格式一张，两列排列 |
| 数据与同步 | 数据目录（存储位置与附件一行，自定义目录、迁移到、当前目录各一行）；快照（快照目录一行，已有快照与「立即创建」一行，下方是快照列表）；导入与导出；云端自动备份 |
| 回收站 | 搜索框、标签与到期筛选；下一行是条数，紧跟保留天数（本次提出：现有应用放在页面标题右侧），右边是「恢复筛选结果」「清理到期项」；每条记录一张卡片，右侧是恢复与永久删除 |
| 关于 | 应用图标、名称、一句话介绍与版本号；项目、开源致谢两组链接，其中「检查更新」检查到新版本时打开「发现新版本」；调试只有一个「打开开发者工具」按钮（本次提出：现有应用为侧栏、速记浮窗、设置各放一个），桌面端打开侧栏窗口的开发者工具，Playground 中提示按 F12 |

其中几项的写法：

- **明暗模式与主题**：选项卡片，每个选项是用对应主题与明暗的令牌画出的迷你侧栏；选中的卡片为强调色边框。
- **字体**：可以输入筛选的组合框，候选用各自的字体显示，「跟随主题」在最前并写出当前主题名，「系统默认」在最后；输入的字体不在候选中时提示并恢复原值。
- **字体预览**：字体与字号下方占满一行的一块，保留凹陷底色，文字居中，三行依次是中文与标点、英文大小写、数字与符号（含 `2026-11-08` 这样的连字符与 `->`、`!=` 等编程连字），用当前选用的正文字体显示。
- **移出后收起、回收站保留天数**：组合框，可以从常用值中选，也可以直接输入，超出范围时提示并恢复原值；指针停在框上转动滚轮按 100 毫秒、1 天加减。
- **快捷键**：一行是名称与按键；点击按键后按下新的组合即可，冲突时在按键左侧说明原因；改过的按键旁有单独的恢复按钮。
- **云端自动备份**：与现有应用一致，桌面版尚未接入云端服务，只保存配置：自动备份开关；群晖 NAS（WebDAV）、Google Drive（OAuth）、OneDrive（Microsoft）三张选项卡片；地址（只有群晖 NAS）、账户、远程文件夹；状态与「云端备份」按钮；失败通知。

窗口尺寸 960 × 720，最小 720 × 560，不随字号变化，内容按字号缩放。0.7.3 为 880 × 720；加宽 80 是为了让「其它」一组的三项在默认字号下排在一行（本次提出）。

## 六、基础控件

| 控件 | 尺寸 | 状态与说明 |
| --- | --- | --- |
| 按钮 | 高 `--sn-control-height-sm`、`--sn-control-height`、`--sn-control-height-lg`，圆角 `--sn-radius-control` | 主要（强调色填充）、次要、文字、危险四种；悬停、按下叠加 `--sn-color-hover` 与 `--sn-color-pressed`；禁用为 `--sn-opacity-disabled`；可带快捷键（终端直接显示，其余写入工具提示与 `aria-keyshortcuts`） |
| 图标按钮 | 边长同控件高度，图标 `--sn-icon-size` 或 `--sn-icon-size-sm` | 必须有文字说明（工具提示与 `aria-label`）；可切换的按钮用按下态 |
| 输入框与搜索框 | 高同按钮 | 底色 `--sn-color-surface`，边框 `--sn-color-border-strong`；获得焦点的样式见下文「输入类控件的焦点」；凹陷的搜索框获得焦点时换成表面色 |
| 复选框、单选、开关 | 图标尺寸 | 选中为强调色；开关是 `role="switch"` 的按钮 |
| 分段控件 | 高同按钮 | 单选组，方向键切换并立即生效；当前项浮起 |
| 下拉选择框 | 高同按钮 | 列表框按 WAI-ARIA 模式：方向键移动、首字母跳转、Enter 选定、Esc 关闭；展开或用键盘移到上面时与输入框一样显示底边的强调线 |
| 组合框 | 高同按钮 | 输入框右侧是展开按钮；输入框获得焦点时同时展开候选，按 Esc 关闭后再点输入框重新展开（与现有应用一致）。候选列表的样式与下拉选择框相同；上下都放不下时放到空间较大的一侧，在列表里滚动，不盖住输入框。可以直接输入，Enter 或失去焦点时提交，不接受的值提示后恢复原值；取值为数字时居中显示，可以用滚轮加减 |
| 问号说明 | 边长 `--sn-icon-size-sm` 的圆形按钮 | 悬停、获得焦点或点击时显示说明框，与工具提示同样用浮起的表面（现有应用的问号说明同样是卡片底色加浅色边框）。说明框比工具提示多一点强调：叠一层很淡的强调色（`--sn-color-accent-subtle`），投影用 `--sn-shadow-lg`，不会和设置页同样浮起的分组卡片融在一起（本次提出）。Esc 关闭；说明可以分行，带按键 |
| 滑块与数值输入框 | — | 滑块右侧带数值输入框，数值居中显示（本次提出）；两者都可以用滚轮加减，规则见 [interactions.md](./interactions.md)；字号松开滑块或滚轮停下后才应用（现有行为是松开后应用） |
| 快捷键 | 字号 `--sn-font-size-xs` | 每个键一个小框，圆角 `--sn-radius-xs` |
| 徽标与标签 | 圆角 `--sn-radius-chip` | 计数徽标；标签胶囊悬停时换成强调色浅底 |
| 空状态 | — | 图标、标题、一句说明，按需带一个按钮 |

**输入类控件的焦点**（输入框、多行文本框、搜索框、数字框、组合框，展开或用键盘移到上面的下拉选择框，以及有搜索词的侧栏搜索框）：边框颜色不变，底边换成一条两倍边框宽（2px）的强调色线，与 Windows 的输入框相同，不加外圈（本次提出）。强调色只出现在底边，不围住正在输入的文字；线画在背景层里，随控件的圆角弯曲，杂志的胶囊形控件上随两端收窄。复合控件（搜索框、侧栏搜索框、组合框）里的原生输入框不画焦点环，焦点只由外层控件的底边强调线表示。快捷键按钮录入中同样只换底边的强调线，加一层浅强调色底。

**菜单项**：指针悬停时叠一层悬停色，用键盘移到时换成选中色 `--sn-color-selected`，不加焦点环。

其余控件（按钮、开关、复选框、页签、卡片等）的焦点环统一：`--sn-focus-ring-width` 宽、`--sn-focus-ring-offset` 间距、`--sn-color-focus` 颜色，只在键盘操作时显示。

## 七、应用图标与品牌标记

应用图标（`assets/app-icon.svg`，本次提出）：一张黄色便签从屏幕右边缘探出头来，两只眼睛看着屏幕上的内容。它画的就是 SideNotes 的用法：平时藏在屏幕边缘，需要时才探出来。

| 部分 | 画法 | 配色 |
| --- | --- | --- |
| 屏幕 | 64 × 64 的圆角方块，圆角 14；左侧三行内容，长短沿用现有品牌标记三根竖条的比例（55%、100%、75%） | `#4150b0` 渐变到 `#232c6c`；内容为白色，不透明度 16% |
| 便签 | 34 × 34，逆时针转 15°，从右边缘探进来，屏幕之外的部分裁掉；左下角折起一角，右下方有投影 | `#ffe36e` 渐变到 `#ffc53a`；折角 `#fff8d6` 渐变到 `#f1c24a`；投影为黑色，不透明度 30% |
| 眼睛 | 两个竖着的椭圆，左上各有一点高光，看向左边的内容；不画嘴 | `#2b1d06`，高光为白色 |

配色固定，不随主题变化。任务栏、托盘、程序坞、关于页、Playground 的网页图标，以及侧栏标题区、速记浮窗与设置窗口的品牌标记，都用同一个图标，只是尺寸不同：标题区为图标尺寸的 1.25 倍，速记浮窗与设置窗口最小化后的按钮与图标尺寸相同，关于页为大号控件高度的 1.5 倍。16px 时眼睛只剩两个小点，仍然认得出靛蓝底上探头的黄便签。组件页的「基础控件」一节列出 64、32、24、16px 的图标与两种尺寸的品牌标记。

现有应用的图标是灰绿色的两张纸片（`src/assets/favicon.svg`），标题区的品牌标记是三根竖条。本分支只在设计系统中使用新图标，桌面应用的图标文件尚未替换；替换时运行 `pnpm exec tauri icon design-system/assets/app-icon.svg` 生成 `src-tauri/icons` 中的各尺寸图标，并把 `src/assets/favicon.svg` 换成同一个文件。
