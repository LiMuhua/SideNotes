# 编辑模式

本文规定记录的编辑模式：怎样进入与退出、编辑中的卡片长什么样、Markdown 元素在编辑区与正文中的样式，以及五套主题的差异。编辑区是现有应用的实时 Markdown 编辑器（`src/core/editor.ts`）：显示 Markdown 原文，同时按格式渲染，光标所在处的标记显示出来，其余标记收起。

Playground 的「组件 › 编辑模式」一节用真实的编辑器渲染了一张编辑中的卡片，示例包含下文提到的全部元素，并列出当前主题下编辑模式用到的令牌。

## 一、进入与退出

| 操作 | 结果 | 来源 |
| --- | --- | --- |
| 双击卡片 | 进入编辑，光标放进编辑区 | 现有 |
| 卡片菜单「编辑内容」 | 同上 | 现有 |
| 选中卡片后按 Enter | 同上 | 本次提出 |
| Ctrl+Enter | 保存并退出编辑 | 现有 |
| Esc | 放弃修改并退出编辑，焦点回到这张卡片 | 现有 |
| 焦点离开整张卡片（例如点到卡片之外） | 保存并退出编辑；卡片内的工具按钮不打断编辑 | 现有 |
| 点编辑栏的保存或取消 | 保存或放弃；按下时不抢焦点，不会先触发失焦保存 | 现有 |

编辑期间，如果开启了「编辑时保持展开」（默认开启），侧栏不会自动收起。

## 二、编辑中的卡片

| 部位 | 规则 | 令牌 |
| --- | --- | --- |
| 卡片 | 底色换成编辑底色，略微浮起，层级提到其余卡片之上；边框保持平时的样子，不用强调色，也不响应悬停与选中的高亮 | `--sn-color-editing`、`--sn-shadow-editing` |
| 其余卡片 | 降到禁用透明度，悬停时恢复，方便对照着写 | `--sn-opacity-disabled` |
| 标题行 | 保留 Emoji、标题与时间；不显示操作按钮 | — |
| 编辑区 | 显示整条记录的 Markdown 原文（包括第一行）；最小高度 100px，最大高度 300px，超出后在编辑区内滚动 | `--sn-font-note`、`--sn-note-size`、`--sn-note-line-height` |
| 编辑栏 | 左侧：添加图片、引用文件；右侧：快捷键提示（只在终端主题显示）、取消、保存（主要按钮） | — |

新建卡片与速记浮窗使用同一个编辑器：新建卡片获得焦点时同样换成编辑底色并浮起，边框不变；速记浮窗的编辑区填满标题区与底栏之间的空间，内容超出时在编辑器内滚动。

编辑区里不画边框、强调线与行号，编辑中的卡片与新建卡片的边框也不换成强调色：正在写字的地方不被颜色框住（第七、八次反馈）。编辑状态靠编辑底色、浮起、其余卡片变淡与编辑栏表示。

## 三、编辑区的样式

| 部位 | 规则 | 令牌 |
| --- | --- | --- |
| 输入光标 | 对比度不低于 3:1 | `--sn-color-caret` |
| 选区 | 与正文中的选区一致 | `--sn-color-selection` |
| Markdown 标记 | `#`、`**`、`-`、`>`、反引号等标记；光标所在处显示，其余收起 | `--sn-color-syntax` |
| 占位文字 | 编辑区为空时显示，弱化文字色 | `--sn-color-text-muted` |
| 标签补全 | 输入 `#` 后以灰字补全已有标签，右侧一个「Tab」提示，Tab 选用 | `--sn-color-text-muted` |
| 每行下方的横线 | 只在记录纸主题显示 | `--sn-color-rule` |

Markdown 标记是要读的字符，对比度按正文要求，不低于 4.5:1。

## 四、Markdown 元素

| 元素 | 编辑区 | 正文（预览） | 令牌 |
| --- | --- | --- | --- |
| 标题 | 标题字体与字重，字号与正文相同；`#` 在光标处显示 | 标题字体与字重，一、二级标题放大到 1.08 倍 | `--sn-font-title`、`--sn-title-weight` |
| 加粗、斜体、删除线、下划线 | 按格式显示，标记在光标处显示 | 按格式显示 | — |
| 行内代码 | 代码底色、代码字体，字号 0.9 倍 | 同左 | `--sn-code-bg`、`--sn-code-text`、`--sn-font-code` |
| 链接 | 显示原文 `[文字](地址)`，光标离开后收起地址 | 强调色文字加下划线 | `--sn-color-accent-text` |
| 标签 | 原文 `#标签`，输入时补全 | 写在末尾独立行的标签显示为卡片底部的标签胶囊 | — |
| 列表 | 悬挂缩进，项目符号用标记色 | 常规列表 | `--sn-color-syntax` |
| 待办 | 小方框，点击切换；完成时强调色边框与浅底 | 同左 | `--sn-color-accent`、`--sn-color-accent-subtle` |
| 引用 | 左侧一条 2px 的竖线，次要文字色 | 同左 | `--sn-color-border-strong`、`--sn-color-text-secondary` |
| 代码块 | 代码底色、代码字体；光标不在块内时，围栏行收成一条细线 | 代码底色、代码字体，圆角 | `--sn-code-bg`、`--sn-code-size` |
| 分隔线 | 一条细线 | 同左 | `--sn-color-border` |
| 图片 | 缩略图，点击打开附件弹窗 | 同左 | `--sn-radius-sm` |
| 文件引用 | 带文件图标的小块，点击打开附件弹窗 | 同左 | `--sn-color-surface-sunken` |

## 五、五套主题的差异

| 主题 | 编辑底色 | 标记 | 光标 | 特有的做法 |
| --- | --- | --- | --- | --- |
| 终端 | 与窗格相同 | 琥珀色，像代码的语法着色 | 琥珀色 | 编辑栏的取消按钮前写出 Ctrl+Enter；标题栏保持平时的浅灰，不染色 |
| 杂志 | 纯白，像翻开的一页 | 暖灰 | 莓红 | 编辑区中的标题行同样用衬线字体；浮起最明显 |
| 记录纸 | 比纸片更白 | 弱化的墨色 | 墨绿 | 每行下方一条淡淡的横线，像写在横线纸上 |
| Windows 11 | 几乎不透明的白色 | 弱化文字色 | 与文字同色 | 编辑底色几乎不透出亚克力，长时间输入不累 |
| 磨砂玻璃 | 玻璃磨得更实，几乎不透出背景 | 弱化文字色 | 青色 | 只换成更实的玻璃并浮起，边框与边缘受光不变，不加光晕；速记浮窗的编辑器直接写在玻璃上 |

各主题的取值见主题文档的「编辑模式」一节与附录。

## 六、键盘

编辑区的快捷键沿用现有应用（`src/core/shortcuts.ts`），可以在设置中重新绑定：

| 操作 | 默认按键 |
| --- | --- |
| 保存记录 | Ctrl+Enter |
| 加粗、斜体、下划线 | Ctrl+B、Ctrl+I、Ctrl+U |
| 删除线 | Alt+S（也可以用 Alt+Shift+5） |
| 链接 | Ctrl+K |
| 行内代码 | Alt+C（也可以用 Ctrl+Shift+\`） |
| 代码块、引用 | Ctrl+Shift+K、Ctrl+Shift+Q |
| 有序列表、无序列表 | Ctrl+Shift+[、Ctrl+Shift+] |

固定不可改的按键：标题与正文 Ctrl+1 至 Ctrl+6、Ctrl+0，缩进与减少缩进 Tab、Shift+Tab，粘贴为纯文本 Ctrl+Shift+V。
