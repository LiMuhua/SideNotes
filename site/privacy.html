隐私政策

SideNotes · Privacy Policy · English

生效日期：2026 年 11 月 22 日。本政策变更时会更新此页与生效日期。

SideNotes 是开源的本地桌面应用（源代码）。SideNotes 没有自己的服务器，不收集使用数据，没有广告与统计，不出售、不出借你的任何数据。

本机的数据

记录、附件、设置与本机快照都存在你电脑上的数据目录里，只有你自己能访问。

云端同步（可选，默认关闭）

只有你在「设置 → 数据与同步 → 云端同步」里连接了某个服务，SideNotes 才会访问它。之后，只在你点「立即同步」或打开自动同步时，把记录数据库与附件的快照上传到你选的远程文件夹；只在你选择恢复时从那里下载。数据只在你的电脑与你选的服务之间直接传输，不经过任何其他服务器，也不提供给任何第三方。

  • Google Drive：只申请 https://www.googleapis.com/auth/drive.file 权限，只能看到和修改 SideNotes 自己建的文件与文件夹，看不到你网盘里的其他文件。另外通过 Drive API 读取登录账户的邮箱地址，只用来在设置里显示连接的是哪个账户。
  • OneDrive：申请 Microsoft Graph 的 Files.ReadWrite（SideNotes 只在你选的远程文件夹里读写）、User.Read（读取账户名，用来显示连接的账户）与 offline_access（保持登录，供自动同步使用）。
  • 群晖 NAS：用你填写的地址、用户名与密码通过 WebDAV 连接。

Google API 有限使用声明

SideNotes 对从 Google API 获得的信息的使用，以及向任何其他应用的传输，都遵守 Google API 服务用户数据政策，包括其中的有限使用要求。SideNotes 不用这些数据投放广告，也不用它们训练人工智能模型。

凭据的保存

登录令牌（OAuth 刷新令牌）、NAS 密码与 Resend 密钥用 Windows 的 DPAPI 加密后存在本机的应用数据目录，只有同一台电脑上的同一个 Windows 用户能解开；它们不写进设置，也不随本地备份导出。访问令牌只在用时向服务换取，只放在内存里。

失败通知邮件（可选）

你填写了收件邮箱与自己的 Resend API 密钥时，同步失败后 SideNotes 通过 Resend 给你发一封邮件，内容包括服务名称、账户、远程文件夹、失败原因与时间。

删除数据与撤销授权

  • 在设置里点「退出登录」或「断开连接」，删除本机保存的凭据；Google Drive 的令牌会同时撤销。
  • 云端的快照在你自己的网盘或 NAS 里，删除远程文件夹即可。
  • 也可以在 Google 账户的第三方应用与服务、Microsoft 账户的应用和服务 里撤销 SideNotes 的授权。

联系

有疑问请在 GitHub Issues 提出。

Privacy Policy (English)

Effective date: November 22, 2026. Changes to this policy will be published on this page with a new effective date.

SideNotes is an open-source desktop app that keeps your data on your computer (source code). SideNotes has no servers of its own, collects no usage data, has no ads or analytics, and never sells or rents any of your data.

Data on your computer

Notes, attachments, settings and local snapshots are stored in the data folder on your computer and are accessible only to you.

Cloud sync (optional, off by default)

SideNotes accesses a cloud service only after you connect it in Settings → Data & Sync → Cloud Sync. It then uploads snapshots of your notes database and attachments to the remote folder you choose, only when you click "Sync now" or turn on automatic sync, and downloads them only when you restore. Data travels directly between your computer and the service you chose; it does not pass through any other server and is not shared with any third party.

  • Google Drive: SideNotes requests only the https://www.googleapis.com/auth/drive.file scope, so it can see and change only the files and folders it creates, not any other files in your Drive. It also reads the email address of the signed-in account through the Drive API, solely to show in Settings which account is connected.
  • OneDrive: SideNotes requests Microsoft Graph Files.ReadWrite (it reads and writes only in the remote folder you choose), User.Read (to show which account is connected) and offline_access (to stay signed in for automatic sync).
  • Synology NAS: SideNotes connects over WebDAV with the address, user name and password you enter.

Google API Limited Use disclosure

SideNotes's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. SideNotes does not use this data for advertising or to train AI models.

How credentials are stored

Sign-in tokens (OAuth refresh tokens), the NAS password and the Resend API key are encrypted with Windows DPAPI and stored in the app data folder on your computer, readable only by the same Windows user on the same computer. They are not written to settings and are not included in local backups. Access tokens are obtained when needed and kept only in memory.

Failure notification email (optional)

If you enter a recipient address and your own Resend API key, SideNotes sends you an email through Resend when a sync fails. The email contains the service name, account, remote folder, the reason and the time of the failure.

Deleting data and revoking access

  • Click "Sign out" or "Disconnect" in Settings to delete the stored credentials; for Google Drive the token is revoked as well.
  • Cloud snapshots live in your own drive or NAS; delete the remote folder to remove them.
  • You can also revoke SideNotes's access in your Google Account's third-party apps & services or your Microsoft account's apps and services.

Contact

Please open an issue on GitHub Issues.
